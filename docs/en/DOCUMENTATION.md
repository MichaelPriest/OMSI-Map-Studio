# Documentation policy

**English** · [Português (Brasil)](../pt-BR/DOCUMENTATION.md)

## Required languages

Official OMSI Map Studio documentation must exist in:

- Brazilian Portuguese (`pt-BR`)
- English (`en`)

Additional languages may be added later.

## Structure

Translated documents must use mirrored paths:

    docs/pt-BR/NAME.md
    docs/en/NAME.md

## Contribution rule

When documentation is created or edited, the same change must be reflected in both `pt-BR` and `en` versions.

Technical terms, file format names, classes, commands and code paths should not be translated when doing so would reduce technical accuracy.

## Application UI

This policy will also provide the foundation for UI internationalization. User-facing strings should not remain scattered directly throughout the code once the UI localization system is introduced.
