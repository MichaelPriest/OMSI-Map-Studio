# OMSI Map Studio v0.2.0-alpha.5-test.10.15-native

Build **ALPHA 5 TEST 10.15 — compositor-frame-synchronized navigation**.

This Test continues Test 10.14 work to remove viewport stutter and input bottlenecks on loaded scenes.

## Pointer-event coalescing

Modern mice can generate `PointerMoved` events much faster than the monitor refresh rate.

Before this change, even with the lighter Test 10.14 render path, each pointer event could still immediately request another `Present(1)`.

Test 10.15 now:

- keeps only the latest pan cursor position;
- accumulates orbit deltas received between frames;
- uses `CompositionTarget.Rendering` for at most one navigation update per visual frame;
- coalesces intermediate pointer events;
- flushes any pending movement before final picking refresh on release;
- removes the compositor hook when navigation ends.

This reduces UI-thread event backlog and avoids trying to present more frames than the display can show.

## Carried from Test 10.14

Test 10.15 also preserves:

- absolute pan based on the camera start state;
- visual rendering without picking during pan/orbit;
- picking refresh after the gesture;
- no gizmo rebuild for each navigation frame;
- no auxiliary text update for every dragged pixel;
- executable startup smoke test;
- all tile and real-map fixes from earlier Tests.
