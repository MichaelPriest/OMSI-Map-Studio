# OMSI Map Studio v0.2.0-alpha.5-test.10.109-native

## Test 10.109 — physical scene clipping to the created map

This alpha fixes oversized scene elements and roads that could appear outside the real-map tiles after automatic reconstruction.

### Issue reproduced in the real test

The problem mainly affected large OSM features such as:

- parking areas;
- sidewalks;
- walls and fences;
- guard rails;
- roads crossing the selected area with source nodes outside it.

Infrastructure batching validated the feature **center**, but could still generate the full mesh when most of the geometry extended beyond the map. This allowed very large polygons and ribbons outside the created tiles.

### Infrastructure clipping

Before O3D generation:

- areas are clipped to the physical rectangle covered by the created tiles;
- lines are clipped at map boundaries;
- the center is recomputed after clipping;
- features with no remaining geometry are treated as outside the map;
- a small boundary inset prevents coordinates exactly at 300 m from falling into the neighboring tile.

### Road clipping

OSM roads are now clipped **before the road graph is built**.

This:

- preserves a road crossing the map even when both original nodes are outside;
- prevents external segments from influencing junctions and physical structures;
- keeps generated splines within the extent of existing tiles.

### Regression coverage

New tests cover:

- a parking polygon larger than the map;
- a sidewalk/line crossing the map;
- a road whose source nodes are both outside but crosses one tile;
- final coordinates constrained to the created extent.

### Includes Test 10.108

The keyless free Open-Meteo/Copernicus elevation fix remains included, with an optional customer API key.
