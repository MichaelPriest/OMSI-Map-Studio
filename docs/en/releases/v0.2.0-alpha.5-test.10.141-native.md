# OMSI Map Studio v0.2.0-alpha.5-test.10.141-native

## Test 10.141 — geometric hardening for nearby stock junctions

Test 10.141 is the safe follow-up to the already published 10.140 build. It keeps stock-first behavior while closing edge cases that could still leave an excessively short or inconsistent road segment between two nearby installed OMSI junctions.

### Nearby-junction trims

When two validated stock junctions trim both ends of the same segment, the runner now:

- applies only trims coming from geometrically validated matches;
- ignores invalid or non-finite trim values;
- never increases a trim beyond the physical junction-mouth distance;
- proportionally reduces both trims when necessary;
- preserves a real connector of up to 4 m between nearby intersections instead of consuming almost the entire segment.

### End-to-end `.map` regressions

Coverage now re-reads `tile_0_0.map` and verifies:

- an offset `.sco` origin resolves back to the exact OSM node at the fitted physical center;
- a physically oversized stock junction is rejected and only that node receives a generated fallback;
- two nearby stock intersections remain stock while the segment between them keeps a usable physical connector.

Selection remains:

1. physically compatible original OMSI asset;
2. compatible installed addon;
3. generated fallback only where required.
