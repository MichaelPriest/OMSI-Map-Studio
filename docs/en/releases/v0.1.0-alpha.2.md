# OMSI Map Studio v0.1.0-alpha.2

Second testable prerelease.

## Main fix

Opening the OMSI root directory has been optimized.

Previously, the application read every tile file from every map before releasing the interface.

Now:

- initial opening reads only `global.cfg` files;
- tile layout appears immediately from map references;
- `.map` files are read only for the selected map;
- each selected tile is read once for both statistics and objects;
- tile reads use limited concurrency;
- loaded maps remain cached in React when switching between them.

## Carried over from alpha.1

- object selection;
- `.sco` metadata;
- geometry preview for unencrypted O3D;
- self-contained Windows x64 package;
- read-only mode.

## Important

Saving and creating maps remain disabled in this alpha.
