# OMSI Map Studio v0.2.0-alpha.5-test.10.17-native

Build **ALPHA 5 TEST 10.17 — derived asset cache and lighter scene rebuilds**.

## Derived asset cache

The native renderer now reuses parsed OMSI asset data while the source files remain unchanged:

- `.sco` object metadata;
- `.sli` spline definitions;
- `.o3d` binary geometry;
- `.x` DirectX text geometry.

The cache fingerprints file existence, size, and last-write time. If a source is externally changed, removed, or created later, the cached entry becomes invalid automatically.

## Bounded memory

The cache uses LRU bounds to avoid unlimited memory growth:

- SCO metadata: up to 512 entries;
- SLI definitions: up to 512 entries;
- O3D/X geometry: up to 1024 entries.

The goal is to reduce repeated parsing on large maps without keeping every asset resident forever.

## Rebuilds, previews, and placement

Scenery and spline loaders now remain alive for the lifetime of the `NativeViewportRuntime`.

This lets the cache survive across:

- streamed scene rebuilds;
- revisiting previously loaded regions;
- Asset Library previews;
- repeated SCO/SLI placement;
- scene refreshes after editing operations.

No map format was changed and the Inspector remains optional.
