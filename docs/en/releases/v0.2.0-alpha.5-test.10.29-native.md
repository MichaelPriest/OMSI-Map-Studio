# OMSI Map Studio v0.2.0-alpha.5-test.10.29-native

Native preview with a more readable real-world reference and the first stage of modern direct road editing in the viewport.

## More visible CARTO reference

- default opacity increased to **80%**;
- opacity remains adjustable from 5% to 100%;
- reopening the dialog reuses the current opacity;
- automatic reference loading uses the same current opacity;
- Voyager, tiled streaming, terrain clipping and the coplanar depth-biased decal from Test 10.28 are preserved.

## Visual endpoint editing

A selected spline can now enter **Edit endpoints** mode without depending on the Inspector.

- **Edit endpoints** button in the Roads contextual toolbar;
- **Endpoints** action in the spline radial menu;
- green marker = start;
- orange marker = end;
- click and drag directly in the viewport;
- live geometry preview;
- end → free start and start → free end snapping to other splines;
- preserves terrain-relative height when not snapped;
- snapped endpoints inherit the target endpoint height;
- straight roads remain straight;
- curved roads preserve their visual curve side/offset while radius and length are recalculated;
- updates rotation, length, radius and gradient through the real transform-edit path;
- the start endpoint stays inside its original OMSI tile in this stage so a [spline] block is never silently moved between .map files without a dedicated transactional operation.
