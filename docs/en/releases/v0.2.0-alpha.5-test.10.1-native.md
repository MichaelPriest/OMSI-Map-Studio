# OMSI Map Studio v0.2.0-alpha.5-test.10.1-native

Build **ALPHA 5 TEST 10.1 — Startup hotfix + Test 10 UI/Paths**.

This build supersedes Test 10 for validation. Test 10 could fail during `App.OnLaunched/MainWindow` with:

`Cannot find a Resource with the Name/Key MapStudioWindowBackgroundBrush`

## Startup hotfix

- light/dark/high-contrast palette moved to **App.xaml**;
- `MainWindow` and `TimetableWindow` now consume global resources from first load;
- removed dependence on theme resources declared only inside the window content itself;
- release workflow now verifies startup-critical global brushes before publishing;
- WinUI `XamlControlsResources` remains loaded at application level.

## Also includes all Test 10 changes

- Windows light/dark theme support;
- adaptive windows and dialogs;
- minimizable translucent Project/Inspector panels;
- cached asset library, lazy thumbnails and debounced search;
- fast All/SCO/SLI/Models/Textures switching;
- OMSI-style traffic path ribbons;
- CAR/HUM/RAIL/AIR colors, arrows, nodes and labels;
- click endpoints to focus/isolate paths;
- Tiles moved out of Project into the global top toolbar;
- Project organized as Scene / Assets / Transport.
