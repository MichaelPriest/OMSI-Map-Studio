# OMSI Map Studio v0.2.0-alpha.3-native

Native Preview startup fix for the error:

`Cannot find a Resource with the Name/Key TabViewButtonBackground`

## Cause

The native `App.xaml` did not load the standard WinUI control resource dictionary. The main window uses controls such as `MenuBar`, `ListView`, `NumberBox`, and others that depend on these theme resources. Without `XamlControlsResources`, `MainWindow` creation failed before the UI could appear.

## Fix

- `App.xaml` now loads `XamlControlsResources` from `Microsoft.UI.Xaml.Controls`;
- the release workflow explicitly verifies that this resource loader is present before publishing;
- the `MapStudio.Native.pri` publish check remains enabled;
- startup diagnostics remain available under `%LOCALAPPDATA%\OMSI Map Studio Native Preview\Logs\startup.log`.

## Included in this build

Keeps the already migrated Native Preview features, including the Direct3D 11 viewport, selection, gizmos, Explorer, Inspector, asset library, 3D previews, object placement, sequential spline construction, fullscreen, shortcuts, and resizable panels.

The Native Preview remains installed separately from the React/WebView2 build.
