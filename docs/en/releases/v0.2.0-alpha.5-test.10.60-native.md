# OMSI Map Studio v0.2.0-alpha.5-test.10.60-native

## Test 10.60 — lane markings at procedural junction mouths

This preview improves the visual transition between Road Kit splines and generated junctions.

- every arm with multiple lanes receives short lane-divider marking stubs;
- markings stay near each junction mouth instead of crossing the intersection center;
- placement uses actual lane width rather than total width including sidewalks;
- markings are generated as O3D quads slightly above asphalt to prevent z-fighting;
- junction meshes now use a second dedicated marking material;
- when Road Kit is installed, its `ms_marking.bmp` texture is reused;
- otherwise Map Studio generates a compatible marking texture;
- Core regression coverage checks the exact marking triangle count;
- Renderer coverage validates both junction texture materials.

This reduces the visual break between spline lane lines and the junction surface while keeping the intersection center clean.
