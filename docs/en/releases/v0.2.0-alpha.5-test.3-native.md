# OMSI Map Studio v0.2.0-alpha.5-test.3-native

**ALPHA 5 TEST 3 — Standalone World Creator Preview** build of the WinUI 3 + Direct3D 11 architecture.

This is a **validation prerelease** from `feature/native-winui-d3d11`. PR #3 remains **DRAFT** and **unmerged**.

## Test 3 highlights

### Standalone Map Studio Workspace

- the editor starts and works without requiring OMSI 2 to be installed;
- its own `maps`, `Sceneryobjects`, `Splines`, `Texture`, `template/NewMap`, and `.mapstudio` structure;
- maps can be created directly in the Workspace;
- external maps and asset folders can be imported;
- **Open OMSI** remains available as an optional content source rather than a requirement.

### Original starter content

A new Workspace now seeds original Map Studio content:

- Road Kit;
- procedural tunnel;
- Bridge Kit and Bridge Creator;
- starter junction;
- starter building;
- tree and shrub;
- `light_enh` street lamp;
- bench;
- bus-stop sign;
- utility cabinet;
- editable traffic light with a real program and linked path.

### Library and previews

- native 3D previews for SCO, SLI, standalone `.o3d`, and `.x`;
- visual previews for BMP, PNG, JPG, TGA, and compatible DDS textures;
- explicit A8 DDS mask support;
- `[tree]` SCO preview;
- grouped library categories for roads, bridges/tunnels, buildings, vegetation, transit, street furniture, infrastructure, and other assets;
- more consistent classification/search for original and imported assets.

### Placement and creation

- scenery can snap/align to the nearest road;
- alignment uses the real tangent of straight and curved splines;
- configurable road-snap range;
- Easy Road keeps preview, snapping, and safe auto-linking;
- Bridge Creator opens the generated bridge directly in the Easy Road workflow;
- Tunnel Creator remains integrated.

### Traffic and transit

- starter traffic light with a real 60-second OMSI cycle and phases;
- path linked through `use_traffic_light`;
- **Add traffic light...** shortcut in the Traffic panel;
- programs, Traffic Rules, and paths remain available in the native flow;
- Tracks, Trips, Stops, StationLinks, and Lines/Tours remain integrated.

### Editor UI

- the viewport remains the primary editing surface;
- movable and horizontally scrollable bottom tool dock;
- tools visually grouped into **EDIT / CREATE / SCENERY / SYSTEMS**;
- visible active-tool state;
- F11 uses a compact toolbar for save, undo/redo, project actions, panels, Workspace switching, and **Open OMSI**;
- Explorer, Library, and Inspector remain part of the native workflow.

## Validate in this Alpha

1. Start the application without selecting an OMSI installation.
2. Create a new Workspace map and verify it opens normally.
3. Open the Library and verify the original starter assets.
4. Test SCO, SLI, O3D/X, and texture previews.
5. Place the lamp, bench, bus stop, vegetation, building, and traffic light.
6. Test scenery road snapping/alignment.
7. Create a bridge and tunnel, then draw them with Easy Road.
8. Open Traffic, use **Add traffic light...**, and test its program/phases.
9. Test F11 and the reorganized bottom tool dock.
10. Test **Open OMSI** separately, then switch back to Workspace.

## Known limitations

- this remains a validation Alpha;
- object/spline writes on `[worldcoordinates]` maps remain blocked until geographic conversion has full round-trip validation;
- addon-specific OMSI materials may still require refinements;
- OSM relations with holes/inner rings remain restricted for safety;
- Proton Bus, LOTUS, and other simulators do not yet have complete operational adapters;
- real subscription/license enforcement remains disabled in Development Preview.
