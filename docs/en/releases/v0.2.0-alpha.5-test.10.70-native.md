# OMSI Map Studio v0.2.0-alpha.5-test.10.70-native

## Test 10.70 — structural junctions keep layer elevation

This preview closes the vertical continuity gap between grade-separated splines and their junctions.

- homogeneous `layer > 0` junctions stay at the same elevated level used by connected arms;
- homogeneous `layer < 0` junctions stay at the same lowered tunnel level;
- the rule only applies when every junction arm shares the same `bridge/tunnel/layer` structural state;
- mixed-grade crossings keep the real terrain height instead of incorrectly joining incompatible levels;
- structural runs ending directly at a junction preserve structural elevation at the endpoint;
- the baseline remains approximately **4.8 m per layer level**, matching Test 10.65 fallback behavior;
- structural junctions still do not inherit ground-derived Pitch/Bank;
- no `.terrain` file is modified;
- real tests validate both connected spline endpoint elevation and the junction placement height.

This removes the step where an elevated bridge/layer road reached a junction that was still placed back on the ground.
