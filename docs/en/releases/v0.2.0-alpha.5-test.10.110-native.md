# OMSI Map Studio v0.2.0-alpha.5-test.10.110-native

## Test 10.110 — physical real-map terrain, spline and object correction

This alpha fixes the reproduced real-world issue where roads and objects appeared scattered/floating while terrain could form abrupt walls between OMSI tiles.

### Correct OMSI axes

Automatic reconstruction now respects the actual coordinate order stored by OMSI.

For objects:

- X = local X;
- Y = local ground-plane coordinate;
- Z = vertical height/offset.

For splines:

- X = local X;
- Z = spline start height;
- Y = local ground-plane coordinate.

Previous batch code mixed these fields in parts of reconstruction, turning horizontal coordinates into height and vice versa.

### Scene follows terrain once

Generated buildings, vegetation, street furniture and infrastructure now use zero vertical offset when the asset is terrain-relative. Terrain elevation is therefore applied once by OMSI/the renderer.

Junctions, bridge piers and tunnel portals keep only the vertical offset they actually need relative to terrain, avoiding double DEM elevation.

### DEM covers complete physical tiles

Google Elevation and Open-Meteo/Copernicus now resolve download bounds from the physical extent of the created OMSI tiles, with a safety margin.

If any terrain sample falls outside elevation coverage, the batch aborts before writing terrain and the pipeline preserves rollback behavior. A missing DEM edge is no longer silently left at zero, preventing tile-boundary cliffs.

### Includes Test 10.109 and Test 10.108

Still included:

- physical clipping of roads and infrastructure to existing map tiles;
- keyless free Open-Meteo/Copernicus elevation;
- optional Open-Meteo customer key.

### Added regressions

Tests now explicitly lock:

- generated OMSI object X/Y/Z ordering;
- OMSI spline X/Z/Y ordering;
- DEM spline height in the correct vertical field;
- bridge/tunnel elevation in the correct vertical field;
- ground junction terrain-relative offset;
- complete DEM coverage of OMSI tiles;
- abort-before-write when DEM coverage is incomplete.
