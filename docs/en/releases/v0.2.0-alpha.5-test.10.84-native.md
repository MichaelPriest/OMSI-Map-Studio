# OMSI Map Studio v0.2.0-alpha.5-test.10.84-native

## Test 10.84 — physical generation of reconstructed infrastructure

This preview moves OSM infrastructure from reconstruction planning into real OMSI assets.

### Implemented

- geographic-to-world projection for infrastructure geometry;
- duplicate/closed geometry normalization;
- rejection of degenerate lines and areas;
- O3D/SCO generation for walls, fences and guard rails;
- surface generation for sidewalks, driveways and parking;
- OSM width applied to sidewalk/driveway ribbons;
- area triangulation for parking and other surfaces;
- Map Studio generated local textures;
- asset packages with manifest data and world center for tile placement.

### Physical assets

Walls, fences and guard rails become volumetric geometry following the real mapped path.

Linear sidewalks and driveways become ribbons using mapped `width=*` values when available.

Closed parking areas are triangulated and exported as O3D surfaces.

### Safety

Empty or degenerate geometry is not exported. Parking still requires a valid closed area before reaching physical generation.
