# OMSI Map Studio v0.2.0-alpha.5-test.10.95-native

## Test 10.95 — transactional rollback for generated assets

This preview closes a gap in the real-world map pipeline: a late failure now restores not only tile files, but also physical assets generated during the session.

### Protected during rollback

- `Splines/MapStudio_RoadKit`
- `Sceneryobjects/MapStudio_Junctions`
- `Sceneryobjects/MapStudio_Buildings`
- `Sceneryobjects/MapStudio_Infrastructure`

Preexisting roots are copied before reconstruction and restored exactly. Roots created only by the failed session are removed.

Tile rollback and generated-asset rollback are attempted independently; rollback failures are aggregated without hiding the original error.

### Tests

- restores previous contents of an existing asset;
- removes a new asset created inside an existing root;
- removes a junction root created only during the session;
- removes newly created building and infrastructure roots.
