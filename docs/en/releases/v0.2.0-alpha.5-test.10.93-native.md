# OMSI Map Studio v0.2.0-alpha.5-test.10.93-native

## Test 10.93 — roads in the complete real-world map pipeline

This preview closes the largest gap in the unified pipeline: the OSM XML already contained roads, but through Test 10.92 only scenery was materialized by the Core pipeline.

### Batch roads

The new `MapStudioRoadBatchReconstructionRunner` performs:

`OSM highway -> projection -> Road Kit profile -> graph -> OMSI splines -> tiles`

It preserves:

- lane count;
- one-way direction;
- width;
- directional lanes;
- `layer`;
- bridge;
- tunnel;
- OSM topology as authoritative source metadata.

Physical profiles come from the standard Map Studio catalog, with structural bridge/tunnel variants where applicable.

### Batch spline writer

`OmsiTileSplineInserter.AppendMany` inserts every spline targeting the same tile in one serialization pass while preserving collision-free global IDs.

### Complete pipeline

The new `MapStudioRealWorldMapPipeline` performs in one call:

`bounds -> unified Overpass -> roads -> scenery -> result`

Progress stages:

1. OSM download;
2. road generation;
3. scenery reconstruction;
4. completed.

An outer session snapshot protects the whole operation: if scenery fails after roads were written, tiles are restored to their pre-run state.

### Current limit

Junction assets and detailed terrain elevation conformance still use the existing advanced generator and will be folded into the Core pipeline in following tests.
