# OMSI Map Studio v0.2.0-alpha.5-test.10.44-native

Third modular-workflow pass inspired by modern editors: Library Collections can now act as mixed vegetation presets.

## Vegetation presets

- the Vegetation module now has a Preset selector backed by existing Library Collections;
- only SCO files actually classified as Vegetation enter the preset;
- Area brush and Line modes can distribute multiple assets from the selected collection;
- distribution is stable and alternates preset assets across placement points;
- single-asset presets continue to work normally;
- Collections remain the single organization system instead of introducing a parallel preset database.

## Efficient insertion

When a mixed preset is active, placements are grouped by SCO path and persisted through `InsertSceneryObjectMultiBatchAsync`. Multiple species therefore use one native insertion flow with the same validation, tile handling and backup behavior.

## UX

The status reports both total inserted vegetation items and the number of distinct preset assets actually used.
