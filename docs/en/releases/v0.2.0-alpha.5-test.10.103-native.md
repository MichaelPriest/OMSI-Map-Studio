# OMSI Map Studio v0.2.0-alpha.5-test.10.103-native

## Test 10.103 — real-world map generation ViewModel

The session controller from Test 10.102 now has a WinUI-friendly binding layer.

### UI state

`RealWorldGenerationViewModel` implements `INotifyPropertyChanged` and exposes:

- `State`;
- `Stage`;
- `StatusText`;
- `IsBusy`;
- `CanStart`;
- `CanCancel`.

Buttons, loading HUDs and status surfaces can bind to these properties without duplicating concurrency rules in XAML or code-behind.

### Progress

The UI receives ready-to-display values for:

- indexed files;
- asset candidates;
- completed/total elevation samples;
- normalized elevation progress from 0 to 1;
- progress text.

### Result

The final summary includes roads, junctions, scenery objects, review items and total placed elements.

The ViewModel also exposes `StartAsync`, `Cancel` and `Reset`, preserving controller/pipeline rollback behavior.
