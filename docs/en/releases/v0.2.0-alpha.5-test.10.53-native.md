# OMSI Map Studio v0.2.0-alpha.5-test.10.53-native

## Test 10.53 — terrain follows the selected spline/road

This preview adds the inverse workflow to “Fit road to terrain”: the **terrain can now conform to the selected road spline**.

- uses the actual selected OMSI spline;
- respects length, rotation, curve radius and start/end gradients;
- reshapes real `.terrain` files for every intersected tile;
- configurable road half-width;
- configurable lateral feather/transition;
- configurable vertical terrain offset relative to the spline;
- works across tile boundaries;
- writes through the existing safe-backup mechanism;
- reloads the viewport after persistence;
- includes deterministic tests for elevation/gradient and curved-spline influence.

The action is available in the spline Inspector and directly in the **Roads** contextual toolbar as **Terreno ↕ via**.
