# OMSI Map Studio v0.2.0-alpha.5-test.10.101-native

## Test 10.101 — native bridge for automatic real-world generation

The complete real-world map pipeline now has a native layer ready to be invoked by the WinUI interface.

### Secure credential reuse

`NativeRealWorldMapGenerationService` reuses the Google key already stored by `NativeMapCredentialStore` in Windows PasswordVault.

The key is not duplicated into files, JSON or project configuration.

### Automatic mode

`RunBestAvailableAsync`:

- automatically uses Google Elevation when a saved key exists;
- runs asset indexing, DEM, OSM, terrain, roads, gradients, junctions and scenery;
- when no Google key exists, it continues with the complete no-DEM pipeline instead of blocking map creation.

The result explicitly reports whether the session used:

- `Google`;
- `None`.

### Required-elevation mode

`RunWithSavedGoogleElevationAsync` requires an already stored key and returns `googleMapsApiKeyRequired` when it is missing.

This lets the UI expose both a tolerant automatic flow and an explicit action requiring real terrain.
