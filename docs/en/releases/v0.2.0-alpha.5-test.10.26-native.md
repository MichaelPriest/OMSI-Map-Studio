# OMSI Map Studio v0.2.0-alpha.5-test.10.26-native

Native preview focused on the definitive CARTO/OpenStreetMap ground-reference fix.

## Real-world ground reference

- Fixes `.mapstudio/georeference.json` loading with the same JSON conventions used when saving, preserving latitude, longitude, anchor tile, local coordinates and especially the zoom selected in **Create real map by area**.
- Removes the path that could deserialize georeference values as default `0`, resulting in zoom 0 and about `156543 m/pixel`.
- Replaces the single 256×256 CARTO reference tile with a Web Mercator tile mosaic aligned to OMSI local coordinates.
- CARTO coverage is derived from the currently loaded OMSI tiles and remains aligned to the **300 × 300 m** OMSI grid.
- Keeps up to 81 CARTO tiles resident around the loaded/active region and refreshes the set as the loaded region changes.
- CARTO cache is organized by zoom/X/Y under `carto-keyed-v3`, with PNG validation and bounded concurrent downloads.
- Every reference tile has its own world anchor; the D3D11 renderer now accepts multiple reference textures at once.
- Reference sampling uses clamp at texture borders to avoid wrap/repetition and reduce seams.
- The visual mesh continues to follow terrain elevation and remains outside picking.
- Opacity and OpenStreetMap/CARTO attribution are preserved. The layer can also be toggled on/off without unloading the mosaic.
- Status text now includes zoom and loaded texture count so zoom-0 regressions are immediately visible.

## Streaming

When navigation changes the loaded map region, the CARTO reference is refreshed together with the OMSI snapshot. If the user enters a CARTO key only for the current session and chooses not to save it, the key stays in memory only so streaming can continue for that session.
