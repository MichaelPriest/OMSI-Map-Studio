# OMSI Map Studio v0.2.0-alpha.5-test.10.133-native

## Test 10.133 — persistent OMSI index without automatic rescans

The asset library was already stored in SQLite, but automatic real-map generation still performed a full scan of `Sceneryobjects`, `Splines` and `Texture` on every run. Test 10.133 now reuses the persistent index directly when a completed index is already available.

### New behavior

- first use creates `.mapstudio/cache/assets.sqlite` and indexes the installation;
- later runs load the existing SQLite catalog without walking every asset file again;
- real-map generation reports `Índice OMSI em cache reutilizado` when the cache is used;
- the existing `↻ Reindexar biblioteca` action still performs a full manual refresh;
- explicit Workspace asset imports still refresh the index;
- missing, invalid or never-completed indexes still fall back to the normal scan.

### Forced refresh

`MapStudioRealWorldAssetCatalogLoader.LoadAsync(..., forceRefresh: true)` forces a physical rescan. This keeps newly installed addons/assets discoverable whenever the user explicitly refreshes the catalog.

### Regression coverage

The regression verifies the initial SQLite build, cache reuse, exactly zero examined files on the second load, stale-cache behavior after adding a new asset, and discovery of that asset after a forced refresh.
