# OMSI Map Studio v0.2.0-alpha.5-test.10.102-native

## Test 10.102 — native real-world generation session with progress and cancellation

The native bridge from Test 10.101 now has a session controller ready for WinUI consumption.

### Session state

The new `NativeRealWorldMapGenerationController` explicitly tracks:

- `Idle`;
- `Running`;
- `Cancelling`;
- `Completed`;
- `Failed`;
- `Cancelled`.

A second generation cannot start while another session is active.

### Unified progress

The UI can consume a single progress stream containing:

- current pipeline stage;
- examined asset-index files;
- discovered asset candidates;
- Google Elevation sample progress;
- road, junction and scenery generation messages.

### Cancellation

`Cancel()` cancels the active session token. Cancellation still flows through the real-world pipeline rollback path so partially written maps are not left behind.

### Final summary

On completion the controller returns:

- elevation mode used;
- road splines;
- junctions;
- scenery objects;
- items still requiring review;
- total placed elements;
- session backup directory.

This keeps future XAML code independent from internal reconstruction runners.
