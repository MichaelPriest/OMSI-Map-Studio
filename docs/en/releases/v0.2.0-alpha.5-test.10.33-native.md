# OMSI Map Studio v0.2.0-alpha.5-test.10.33-native

Native preview focused on **clean completion of automatic real-map creation** and **visible application version identification**.

## Automatic real-map creation

Fixed the behavior that opened the Asset Library after automatic road/junction generation and could replace the map viewport with an asset 3D preview.

Now:

- **Open Library after creation** is unchecked by default;
- **Generate roads + junctions automatically** finishes directly in the map scene;
- an existing floating Library is closed when it was not explicitly requested for post-creation;
- the viewport exits any asset 3D preview and restores the map scene;
- the editor returns to **Selection** filtered to **splines/roads**;
- the camera returns to top view and fits the map;
- the Library can still be opened manually or explicitly requested after creation.

## Visible app version

The build version is now shown:

- in the window title;
- in the footer next to `WinUI 3 · Direct3D 11 · .NET 10`.

The value comes from the build's `AssemblyInformationalVersion`, so it follows every Alpha/Test automatically.

## Preserved from Test 10.32

- automatic roads and generated junctions;
- pedestrian-way filtering from the road-generation stage;
- procedural textures for Map Studio assets;
- CARTO fixes;
