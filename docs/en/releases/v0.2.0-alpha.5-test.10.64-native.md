# OMSI Map Studio v0.2.0-alpha.5-test.10.64-native

## Test 10.64 — continuous vertical profile for bridges and tunnels

This preview improves structural spline elevation without inventing a fixed offset.

- contiguous **bridge** or **tunnel** segments are treated as one structural run;
- terrain is sampled only at the two real run boundaries;
- internal vertices and segments receive distance-based interpolated heights;
- bridges across valleys no longer descend to intermediate terrain vertices;
- tunnels through hills no longer climb to the surface at intermediate vertices;
- junction-trimmed segments stay on the same elevation line;
- merged curves preserve vertical continuity;
- approach roads meet the structure at real boundary terrain height without an artificial step;
- no `.terrain` file is modified by this calculation;
- the Renderer regression keeps a real terrain valley and verifies the deck stays at boundary elevation.

A later step can infer clearance when OSM only provides `layer` over flat terrain.
