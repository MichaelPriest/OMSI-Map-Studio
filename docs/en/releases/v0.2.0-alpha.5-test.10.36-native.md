# OMSI Map Studio v0.2.0-alpha.5-test.10.36-native

Native preview focused on visual and topological fidelity of automatic real-world road generation.

## Complete OSM download

Test 10.35 could accept a partial Overpass response and generate only the road network portion that was received.

Now:

- the selected area is still split into smaller chunks;
- multiple Overpass fallback endpoints are available;
- a failed chunk is automatically subdivided into four smaller areas;
- recovery may continue recursively with smaller chunks;
- if any sub-area still fails, automatic generation stops before writing roads;
- an incomplete OSM area is never treated as a successful import.

## Real OMSI curves

Smoothing already followed the OSM trace, but every sample was still converted to a straight spline.

The placement pipeline now:

- recognizes consecutive segments from the same road;
- never builds a curve through a junction;
- creates arcs using the native OMSI spline Radius value;
- rejects curves whose radius is too tight for the physical road width;
- limits curve sweep to avoid loops and artificial bends;
- falls back to a straight spline when an arc is unsafe;
- writes curvedRequests to startup.log.

## Junctions and connections

Procedural junction geometry is no longer a generic circular disk.

Now:

- the surface is built from the actual intersection arms;
- the mesh uses the convex outline of road mouths;
- road splines are trimmed before reaching the junction center;
- spline endpoints meet the generated crossing surface;
- junction sizing uses the Road Kit profile's total physical width;
- total road width and individual lane width are separate values;
- internal paths use lane width rather than total width including sidewalks;
- actual terrain height remains respected;
- generated junction mesh paths now use the format expected by the OMSI loader, allowing the crossing mesh and its texture to load in the viewport.

## Physical Road Kit scale

Graph width is now normalized to the selected profile's full physical width:

- carriageway;
- sidewalks;
- median when present.

This prevents an 11 m visual spline from being treated as a 7 m road by the junction generator.

## Road Kit 1.2 textures

The built-in Road Kit has been updated to 1.2.0.

- procedural asphalt increased from 64x64 to 256x256;
- fine noise and aggregate are more visible;
- longitudinal wear variation was added;
- sidewalks now use 256x256 textures with clearer joints and paving;
- marking texture resolution was increased;
- the pack is regenerated automatically during road generation.

## OSM roundabouts

- `junction=roundabout` and `junction=circular` are treated as one-way unless OSM explicitly declares `oneway=no`;
- this keeps Road Kit profile selection and traffic paths coherent on real roundabouts.

## Added regressions

Tests now cover:

- rejecting incomplete OSM imports;
- recovering a failed Overpass chunk by subdividing the area;
- creating a real OMSI curve from a three-point bend;
- confirming the curve reaches its expected renderer endpoint;
- trimming road splines before junctions;
- separating physical road width from lane width;
- compact non-oversized junction geometry;
- generated junction mesh and texture loading;
- generated Road Kit rendering;
- 256x256 generated asphalt texture.
