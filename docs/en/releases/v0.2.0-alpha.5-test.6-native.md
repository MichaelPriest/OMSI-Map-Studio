# OMSI Map Studio v0.2.0-alpha.5-test.6-native

**ALPHA 5 TEST 6 — Creator Focus UI Fix** build of the WinUI 3 + Direct3D 11 architecture.

This prerelease fixes the F11 layout regression visible in Test 5.

## Fixes

- the F11 toolbar is now constrained to a horizontal top overlay;
- its three command groups no longer stretch vertically and cover the viewport;
- floating Explorer and Inspector remain independent;
- contextual palette and bottom dock remain available;
- keeps the Test 5 O3D assembly/orientation fix;
- keeps the Direct3D texture V-orientation fix;
- keeps loading animations and the new World Creator interface.

2. Press F11.

4. Test Explorer, Inspector, and Restore panels.
5. Exit F11 and verify the desktop layout is restored.
