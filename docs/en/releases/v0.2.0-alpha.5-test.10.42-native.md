# OMSI Map Studio v0.2.0-alpha.5-test.10.42-native

Native preview with the first visual/workflow reorganization pass inspired by modern 3D editors and the nEditor 1.0 workflow, without copying external branding or code.

## Modular workspace

- new compact vertical module rail on the left side of the viewport;
- direct access to Selection, Objects, Roads, Terrain, Vegetation, Crossings, Traffic and Transport;
- the active module automatically follows the existing real editor tool state;
- specialized commands remain in the contextual bottom palette;
- Project and Inspector shells are visually tighter to keep the viewport dominant.

## Visual

- dark theme moved from deep blue to a neutral graphite base;
- blue is now focused on actions and selection state;
- surfaces, borders and contrast were tuned toward a professional 3D-editor appearance;
- light theme also uses more neutral and less saturated tones;
- no editor functionality was removed.

## Compatibility

The architecture remains WinUI 3 + Direct3D 11. Library, favorites, thumbnails, AI, Road Kit, OSM, automatic generation, terrain, traffic, Route Studio and Inspector keep using the current native implementations.
