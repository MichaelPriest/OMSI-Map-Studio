# OMSI Map Studio v0.2.0-alpha.5-test.10.124-native

## Test 10.124 — manual tools audit

Test 10.124 audits native-editor manual tools from the UI button through the real persistence path.

### UI wiring audit

The audit checked every `Click` handler declared by the main XAML and confirmed there are no buttons pointing to a missing handler.

The release smoke now repeats that check automatically and requires the viewport completion-event wiring used by interactive edits:

- move/rotate transforms;
- scenery placement;
- spline placement;
- spline splitting;
- terrain point selection.

### Real persistence verified

The audit confirmed real write paths for:

- saving pending transforms;
- SCO object insertion;
- SLI spline insertion;
- spline splitting;
- Previous/Next link editing;
- spline mirroring;
- vehicle-path flow reversal;
- spline type replacement;
- terrain level/edit;
- terrain raise/lower;
- ground texture painting;
- Custom Shape terrain editing;
- tile water;
- Traffic Rules;
- `[path]` edit/create/duplicate/delete;
- traffic-light programs;
- TTData Tracks and StationLinks.

Manual vegetation area/line uses the shared scenery-placement writer, while Custom Shape uses real batch insertion.

### Fixes found during the audit

- **Roads → Terrain** now applies to an already selected spline; previously it only changed the mode for the next spline placement.
- **Copy/Duplicate** is now enabled on maps using `[worldcoordinates]`. The current runtime already works in world space and converts the destination back to tile + local coordinates before writing.
- **Add traffic signal** now searches using the `semaforo` synonym set so assets named `traffic light`, `traffic signal`, `Ampel`, or `Signalgeber` can also be found.

### Areas audited

Selection, Objects/Scenery, Roads/Splines, Bridges/Tunnels, Buildings, Vegetation, Junctions, Terrain, Water, Traffic/Signals, Paths, Transport/Route Studio, Tiles, Undo/Redo, and Inspector.
