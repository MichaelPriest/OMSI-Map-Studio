# OMSI Map Studio v0.2.0-alpha.5-test.10.78-native

## Test 10.78 — structural drainage and emissive tunnel lighting

This preview adds functional details to generated tunnel mouths and their inner transition.

- each portal now has **two physical drainage channels** along the carriageway edges;
- channels use their own material and `ms_tunnel_drain.bmp` texture;
- the inner transition receives **real light geometry**;
- lights use an O3D material with actual emission rather than only a bright texture;
- new `ms_tunnel_light.bmp` texture;
- the emissive material keeps renderer-compatible diffuse/specular values plus visible emission;
- drainage automatically follows the required portal/apron depth;
- lights scale with opening width and available transition depth;
- asset cache now requires concrete + lighting + drainage textures;
- portal asset version advances to **1.1.0**, safely forcing old generated assets to rebuild;
- no `.terrain` mutation is performed;
- Core regression validates emissive materials and drainage material indices.

Scope of this version: lighting for the **portal mouth and inner transition**. Automatic light distribution along the complete tunnel run is the next step.
