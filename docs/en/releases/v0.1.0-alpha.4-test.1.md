# OMSI Map Studio v0.1.0-alpha.4-test.1

Quick Alpha.4 follow-up build focused on validating the map flickering issue.

## Main fix

- stabilizes the active-tile callback passed to the viewport;
- selection, placement, and transform callbacks are now read through latest-value refs instead of participating in Babylon scene recreation dependencies;
- gizmo dragging and App state updates no longer recreate the viewport simply because a callback identity changed;
- existing picking, streaming, selection, Snap, transforms, and preservation-safe persistence remain unchanged.

## Automated validation

- 129 Core tests passed;
- TypeScript/Vite build passed;
- .NET 10 desktop host build passed.

This build is specifically intended to validate that the map no longer flickers during loading and editing.
