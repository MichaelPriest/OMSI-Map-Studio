# OMSI Map Studio v0.2.0-alpha.5-test.10.123-native

## Test 10.123 — loading screen rendered before heavy operations

Test 10.123 fixes a visual regression where the loading screen still existed in code but could fail to paint before a heavy operation started.

### Loading screen

The loading screen **was not removed**. It still contains:

- editor overlay;
- animated ProgressRing;
- current title and stage;
- operation detail;
- progress bar;
- percentage when known;
- **Cancel generation** button for the real-world pipeline.

The editor now explicitly yields a frame to WinUI after making the overlay visible and before heavy work starts. This is applied to:

- real-world map creation and reconstruction;
- map opening;
- full-map/region switching;
- tile navigation that requires loading;
- library refresh;
- Workspace initialization;
- batch duplication.

### Real-world map

During reconstruction, the screen continues consuming ViewModel progress and should show transitions such as:

`Building real-world map → OpenStreetMap → Roads → block X/Y → server → attempt`

followed by elevation, buildings, vegetation, furniture, map application and completion/rollback.
