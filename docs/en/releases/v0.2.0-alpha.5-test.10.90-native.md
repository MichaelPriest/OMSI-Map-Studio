# OMSI Map Studio v0.2.0-alpha.5-test.10.90-native

## Test 10.90 — unified Overpass capture for real-world scenery

This preview creates the single OSM source needed by the complete “Create real map” workflow.

### One scenery capture

The new `MapStudioOverpassSceneClient` queries the same area for:

- roads;
- buildings and building relations;
- trees and shrubs;
- tree rows, hedges and vegetation areas;
- street lights;
- utility poles/towers;
- traffic signs;
- bus stops/shelters;
- walls, fences and guard rails;
- explicitly mapped sidewalks;
- driveways;
- parking areas.

The returned XML can feed the existing road, building, vegetation, street-furniture and infrastructure importers.

### Robustness

The downloader keeps the protections already proven by road import:

- multiple HTTPS Overpass endpoints;
- automatic server fallback;
- large-area chunking;
- bounded 2x2 recovery subdivision;
- global time budget;
- incomplete-result rejection;
- node, way and relation deduplication across chunks.

### Tests

- query containing the main scenery families;
- the same XML accepted by five existing importers;
- fallback to a second endpoint;
- large-area chunking;
- cross-chunk deduplication;
- failed parent query recovered through four subareas.
