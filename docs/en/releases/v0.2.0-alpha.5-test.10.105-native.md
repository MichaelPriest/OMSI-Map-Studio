# OMSI Map Studio v0.2.0-alpha.5-test.10.105-native

## Test 10.105 — one-click real-world reconstruction in MainWindow

The **Create real map by area** flow now directly integrates `RealWorldGenerationPanel` and `NativeRealWorldMapGenerationController`.

### Integrated flow

In the default **Full automatic reconstruction** mode, a single click now:

- creates the map directory and selected tile grid;
- stores the georeference;
- automatically indexes available OMSI assets;
- runs the unified OpenStreetMap pipeline;
- generates roads and junctions;
- reconstructs buildings, vegetation, and street furniture;
- uses Google Elevation when automatic elevation is enabled, Google is selected, and a saved key is available;
- keeps the progress panel visible with cancellation support;
- reloads the map from disk after completion so the native viewport reflects the generated result;
- keeps the session backup path in the final summary.

### Cancellation and rollback

While reconstruction is running, the window cannot be closed or minimized in a way that hides the **Cancel** button.

When cancelled:

- the controller cancels the pipeline;
- the pipeline restores the session backup;
- `MainWindow` reloads the restored map;
- the viewport returns to a consistent state.

### Compatibility with previous modes

The simple map creation and road-guide import modes remain available.

The elevation preference is now propagated from the UI down to the generation service, preventing a saved Google key from enabling elevation when the option is disabled.

### Validation

Native Preview Release now includes a dedicated smoke check for:

- panel presence in `MainWindow`;
- the real `StartAsync` call;
- `useSavedGoogleElevation` propagation;
- `OperationCanceledException` handling;
- reload through `OpenMapAsync`.
