# OMSI Map Studio v0.2.0-alpha.5-test.10.127-native

## Test 10.127 — complete manual-tools audit

10.127 publishes the final state of the audit started in 10.124. Test 10.126 was produced from an intermediate HEAD while the audit was still distinguishing legacy hidden-palette buttons from routes actually reachable in the current UI. This build carries the completed fix without overwriting the earlier tag.

### Confirmed visible routes

- **Selection → Validate map** now provides a real visible entry point to Validation.
- **Objects → Infrastructure** opens Utilities.
- **Roads → More → Tunnel creator** opens the real tunnel generator.
- **Transport → Stops and terminals** opens Transit Assets.
- The old `MapToolPalette` remains intentionally hidden and is no longer accepted by CI as evidence of accessibility.

### Conditional controls audit

Collapsed and initially disabled controls were reviewed. The remaining conditional controls are intentional: Track/Trip/Stop/StationLink/Line editing, traffic-light programs, Validation repair, terrain layers, and procedural-road commands are enabled only when valid context exists.

Route Studio lane/path selection uses the visible `ComboBox`; the hidden `TransportPathIndexBox` is only synchronized backing state used for persistence.

### Persistence and reload

Start → interaction → write → reload was confirmed for:

- Transit/Utilities objects and junctions → transactional `.map` write and reload;
- placed splines/tunnels → `.map` write and reload;
- tunnel generator → real `.sli`, textures, backup and read-back;
- traffic-light programs → `.sco`, backup and reload;
- SCO/SLI paths → real patch, backup and reload;
- Track → `.ttr`, backup and reload;
- StationLink → `StnLinks.cfg`, backup and reload;
- Trip/Line/BusStop → real TTData persistence and catalog reload.

### Portuguese Library classification

The classifier now recognizes `ponto`, `parada`, `abrigo`, `garagem`, `estacao`, `energia`, `agua`, `saneamento`, `esgoto`, `infraestrutura`, and `tunel`, with regression coverage.

### Automated validation

The 10.127 gate checks the actual visible routes, handlers, writers/readers and round-trip coverage for tunnel generation, Track persistence and traffic-light SCO editing. The automated audit also found 229 XAML `Click` handlers and no empty/no-op manual handler.
