# OMSI Map Studio v0.2.0-alpha.5-test.10.35-native

Native preview focused on fixing **automatic road, avenue and junction generation after creating a real-world map**.

## More reliable OSM pipeline

- OpenStreetMap/Overpass downloading now uses a dedicated client;
- larger areas are split into smaller requests;
- public Overpass instances have fallback support;
- duplicate ways across chunks are consolidated by way ID;
- one failed chunk no longer discards chunks that were already downloaded successfully;
- automatic generation remains the fallback mode when the road-mode selector has no valid selection yet.

## Map bounds

OSM ways may continue far beyond the selected area. Projected traces are now clipped to the actual created OMSI tile bounds before graph construction.

This prevents an external section of a road from invalidating the complete placement batch.

## Spline generation

- short OSM segments are no longer subdivided unnecessarily;
- automatic spline batches support denser maps;
- diagnostics now record trace, node, segment, placement and persistence counts;
- generated Road Kit assets have an end-to-end rendering regression test covering SLI creation, texture loading and viewport triangle generation.

## Junctions

A failure mode that could remove every road after successful spline creation was fixed:

- scenery multi-batch insertion supports at most 512 placements per call;
- junction grouping could exceed that limit;
- a junction failure previously rolled back the already-written road splines.

Now:

- junctions are submitted in batches that respect the insertion limit;
- a junction failure does not undo generated roads;
- remaining junction batches continue to be attempted;
- the terrain height calculated by the junction plan is now persisted as the junction Z value, preventing crossings from being buried on elevated maps;
- final status reports inserted and failed junction counts.

## Diagnostics

Automatic generation stages are written to:

`%LOCALAPPDATA%\OMSI Map Studio Native Preview\Logs\startup.log`

The log includes OSM download results, graph size, placement counts, persisted splines and junction failures.
