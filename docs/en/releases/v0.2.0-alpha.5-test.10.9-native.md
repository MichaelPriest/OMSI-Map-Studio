# OMSI Map Studio v0.2.0-alpha.5-test.10.9-native

Build **ALPHA 5 TEST 10.9 — direct viewport manipulation, editor-style rotation and tool icons**.

## Interaction rule

The Inspector is explicitly treated as **optional**.

No primary editor function should depend on it. Primary operations must work directly in the viewport, quick bars or radial wheel.

## Rotate directly in the viewport

**Rotate** now supports a flow closer to the original editor:

1. select an object or spline;
2. click **Rotate** or press **E**;
3. drag the selected item itself;
4. watch the live rotation preview;
5. release to apply.

The rotation-ring gizmo remains available for precise visual control.

Direct object rotation uses the main vertical axis. Existing undo/redo history is preserved.

## Move without Inspector

**Move** now also works by dragging the selected object or spline itself directly in the viewport.

- drag the item itself for free movement across the map plane;
- use gizmo axes for precise movement;
- use the vertical gizmo axis to change height;
- Snap remains available;
- Inspector is not required.

Shortcut: **W**.

## F11 cursor-label fix

- the textual `F11` toolbar button was replaced by a fullscreen icon;
- floating-panel drag tooltips no longer contain `F11`;
- the Creator Focus exit action now uses an icon plus **Exit** text;
- F11 remains a keyboard shortcut/menu hint without being shown as a loose pointer label.
