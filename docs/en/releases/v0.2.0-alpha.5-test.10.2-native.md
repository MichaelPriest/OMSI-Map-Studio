# OMSI Map Studio v0.2.0-alpha.5-test.10.2-native

Build **ALPHA 5 TEST 10.2 — Map/Tiles Manager crash fix**.

This build supersedes Test 10 and Test 10.1 for validation. It keeps the adaptive UI, theme, asset-library performance and OMSI-style Paths work from those builds and adds a targeted fix for the unexpected process exit when opening the **Map/Tiles** flow.

## Priority fix

- the Tile Manager handler no longer lets a UI exception escape from an `async void` event and terminate the application;
- concurrent attempts to open the same dialog are blocked;
- duplicate tile coordinates no longer flow directly into `ToDictionary`, avoiding `ArgumentException` when a map/global.cfg contains repeated entries;
- repeated coordinates are consolidated for display and surfaced as a warning;
- `MainRoot.XamlRoot` is validated before showing the `ContentDialog`;
- recoverable Tile Manager failures are written to `startup.log` and reported in the status bar instead of closing the process.

## Also included

- global light/dark/high-contrast theme resources from Test 10.1;
- minimizable translucent Project/Inspector panels;
- Tiles shortcut on the global top toolbar;
- Project organized as Scene / Assets / Transport;
- cached asset index, lazy thumbnails and search debounce;
- OMSI-style CAR/HUM/RAIL/AIR path ribbons, arrows, nodes and labels;
- endpoint click focus/isolation;
- path create/edit/duplicate/delete;
- advanced Timetable/Route Studio.

## Validate in this build

3. Double-click Tiles quickly and confirm the app stays open.
4. Focus a loaded tile and a tile outside the 3×3 region.
5. Test a map with duplicate tile entries if available.
