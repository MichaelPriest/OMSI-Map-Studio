# OMSI Map Studio v0.2.0-alpha.5-test.10.27-native

Native preview focused on correctly clipping the CARTO/OpenStreetMap reference to OMSI terrain.

## Fix after Test 10.26

Test 10.26 fixed zoom/georeference loading and introduced the CARTO mosaic, but the reference could still appear as a large rectangular “carpet” outside the actual loaded terrain.

This version:

- draws each CARTO tile only where it intersects OMSI tiles that actually contain terrain;
- stops using fallback height outside the map for the reference layer;
- renders no reference imagery in areas without loaded terrain;
- keeps the mosaic following real terrain elevation;
- recalculates UVs after clipping so imagery remains aligned;
- clips exactly against the OMSI 300 × 300 m tile grid;
- preserves Test 10.26 zoom, streaming, opacity, visibility toggle and attribution behavior.

## Expected validation

When opening the same area shown in the screenshot sent after Test 10.26, the reference should appear only over existing OMSI terrain tiles, without the large flat rectangle extending outside the map.
