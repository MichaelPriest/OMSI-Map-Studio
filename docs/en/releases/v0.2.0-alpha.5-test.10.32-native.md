# OMSI Map Studio v0.2.0-alpha.5-test.10.32-native

Native preview focused on **automatic OSM road/junction creation** and **textures for Map Studio generated assets**.

## Real map: automatic roads and junctions

When creating a real map with the default **Generate roads + junctions automatically** option:

- the editor queries all OpenStreetMap `highway` ways inside the selected area;
- projects them automatically into map coordinates;
- classifies road profiles;
- smooths traces;
- detects geometric crossings and T intersections;
- splits segments at detected nodes;
- builds the full graph without manual road selection;
- creates splines using the Map Studio Road Kit;
- creates generated junction assets at degree 3/4+ nodes;
- keeps linear links only where safe;
- persists the result with transaction/backup;
- the confirmation dialog remains only for the manually-invoked procedural road generator.

Automatic generation failures are now preserved as post-create warnings instead of being hidden by a generic map-created status.

## Textures for generated assets

Map Studio procedural assets that previously relied only on O3D material colors now get locally generated textures:

- starter lamp, bench, bus stop and utility box;
- starter traffic light;
- automatic junctions;
- Building Studio generated buildings;
- buildings generated from OSM footprints.

The Workspace also upgrades old starter assets that are missing the new texture files.

Already textured assets remain unchanged:

- Road Kit;
- bridges;
- tunnels;
- vegetation;
- starter terrain.
