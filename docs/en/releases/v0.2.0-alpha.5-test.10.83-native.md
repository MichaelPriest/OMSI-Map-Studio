# OMSI Map Studio v0.2.0-alpha.5-test.10.83-native

## Test 10.83 — OSM urban infrastructure in Real World Reconstruction

This preview extends real-world scene reconstruction to linear and area-based urban features that complement roads, buildings, vegetation and street furniture.

### Implemented

A new OSM importer now recognizes:

- walls (`barrier=wall`);
- fences (`barrier=fence`);
- guard rails (`barrier=guard_rail`);
- separately mapped sidewalks (`highway=footway` + `footway=sidewalk`);
- property/garage driveways (`highway=service` + `service=driveway`);
- closed parking areas (`amenity=parking`).

The importer preserves:

- way-node geographic geometry;
- name;
- material/surface;
- width when provided;
- closed-area evidence.

### Reconstruction safety

Parking is accepted as an area only when the OSM way is actually closed. Incomplete geometries or ways with insufficient node references are not promoted into the reconstruction plan.

### Confidence

Features map into the existing planner categories:

- `Wall`;
- `Fence`;
- `GuardRail`;
- `Sidewalk`;
- `Driveway`;
- `Parking`.

Sparse OSM evidence remains reviewable. Independent aerial or street-level imagery can still raise confidence and unlock automatic generation.

### Tests

- recognition of all six supported feature types;
- width, surface and area preservation;
- rejection of open parking geometry;
- complete planner-category mapping;
- sparse fence evidence remaining under review;
- well-documented parking reaching automatic generation;
- OSM + aerial imagery confidence fusion for sidewalks.
