# OMSI Map Studio v0.2.0-alpha.5-test.10.31-native

Native preview focused on **visually joining road segments**.

## Join segments

The Roads toolbar now includes **Join**:

1. select the source spline;
2. click **Join**;
3. click the target spline directly in the viewport;
4. the editor solves and inserts the intermediate connection with real OMSI links.

The workflow reuses the safe **Complete to** solver:

- source end must be free (`Next = -1`);
- target start must be free (`Previous = -1`);
- this stage requires the same SLI to preserve compatible paths;
- creates a straight connector when tangents are already aligned;
- creates a tangent circular arc when a safe solution exists;
- refuses impossible geometry instead of writing a bad connection;
- visual mode uses a 200 m maximum radius;
- advanced **Complete to** remains available for a custom radius;
- real insertion updates `Previous/Next`, creates backups and uses construction history.

## Preserved

- 80% default CARTO reference opacity;
- draggable green/orange endpoints;
- yellow curve/radius handle;
- endpoint snapping;
- real undo/redo and transform edits;
- primary tools do not depend on the Inspector.

## Next

With endpoints, curve editing and visual joining stabilized, the next dependency is **automatic intersections/crossings**: detect encounters, split required segments and generate a compatible junction.
