# OMSI Map Studio v0.2.0-alpha.5-test.10.68-native

## Test 10.68 — live terrain Custom Shape preview

This preview completes the visual feedback before polygon-based terrain operations are applied.

- Custom Shape now gets a translucent viewport fill;
- **Level**, **Raise**, **Lower**, and **Paint** use distinct preview colors;
- hovering an action button changes the preview without modifying files;
- the HUD shows target height or Δ strength plus feather in meters;
- raise/lower strength drives fill intensity;
- paint alpha drives paint-preview intensity;
- radius, feather, target height, strength, and alpha update the shape live;
- feather gets a progressively stronger edge visualization;
- the polygon reprojects after pan, orbit, zoom, resize, and DPI changes;
- leaving the Terrain tool clears capture state and overlay;
- no `.terrain` or mask data is written during preview.
