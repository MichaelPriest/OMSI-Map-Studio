# OMSI Map Studio v0.2.0-alpha.5-test.10.49-native

Live traffic-light phase feedback directly inside the viewport.

## Viewport preview

- the selected real program drives a compact HUD in the viewport corner;
- red, yellow and green lamps follow the real phase `SignalCode`;
- red + yellow lights both lamps at the same time;
- program name, object, code, current time and cycle duration stay visible without leaving the map;
- the existing slider and Play/Pause remain the single source of preview time;
- switching away from the Traffic tool hides the HUD so stale visual state is not left behind.

## Integration

The implementation reuses `NativeTrafficLightProgramInfo.GetPhaseAt()` and `DescribeSignalCode()`. It does not create simulated signals, parallel programs or mock data.
