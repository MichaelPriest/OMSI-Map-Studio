# OMSI Map Studio v0.2.0-alpha.5-test.8-native

**ALPHA 5 TEST 8 — Roads, Rails & Route Studio** build of the WinUI 3 + Direct3D 11 architecture.

This prerelease combines road/rail rendering fixes with the expanded Transport workspace before the next visual validation round.

## Road and rail rendering

- `.sli` spline surfaces are rendered double-sided in the native pipeline so roads, rails, curbs, and vertical profile faces do not disappear due to back-face culling;
- picking follows the same visible-surface rule;
- spline material `AlphaMode` is preserved;
- previews and selection keep using real OMSI geometry;
- previous O3D, UV/texture, outward-face, and F11 fixes remain included.

## Route Studio / Transport

- safe creation of Track `.ttr`, Trip `.ttp`, Stop, StationLink, and Line/Tour `.ttl`;
- visual Track, Trip, StationLink, and Line/Tours preview on the map;
- real `ID:pathIndex` segment list;
- viewport focus per segment;
- add, remove, and reorder Track segments;
- **Record path** mode: select splines/objects on the map in route order and append them to the Track;
- editing for existing Trips, stops, StationLinks, Lines/Tours, and time profiles;
- optional OMSI Paths overlay;
- validation for Trip→Track, StationLink→Stop, and Line→Trip references;
- backup-based writes for existing files and atomic creation for new TTData files.

## Validate

1. Open the map where roads/rails were previously missing.
2. Check roads, rails, curbs, and vertical spline profile faces.
3. Open Transport → Route Studio.
4. Create or select a Track.
5. Enable **Record path** and click the route segments in order.
6. Reorder/remove segments and verify the route preview.
7. Create Trip, Stops, StationLink, and Line/Tour and inspect the route overlay.
8. Test **OMSI Paths** and **Validate**.
9. Close and reopen the map/TTData to confirm round-trip.
10. Test selection, F11, and save normally.
