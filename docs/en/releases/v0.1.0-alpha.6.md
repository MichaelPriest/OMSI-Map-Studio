# OMSI Map Studio v0.1.0-alpha.6

Prerelease focused on **classic OMSI editor selection** and **Explorer readability**.

## Selection

- **Select / Q** always returns to **All**, preventing the editor from accidentally remaining locked to “Splines” or “Objects”;
- picking uses Babylon's own canvas pointer coordinates, avoiding click drift in WebView2/Windows display scaling;
- the item under the pointer is highlighted blue;
- the selected item is highlighted red, matching the classic OMSI editor visual language more closely;
- left click selects real objects or splines;
- clicking empty map space clears selection;
- repeated clicking keeps focus/centering behavior;
- Objects, Splines and Terrain filters remain available when the restriction is intentional;
- Move/Rotate and Snap remain integrated with the editing layer decoupled from the structural scene.

## Explorer

- wider desktop panel;
- larger text, names, metadata, search, categories and controls;
- more readable Library and asset cards;
- 3D preview and asset information tuned for Windows displays using scaling above 100%.

## Behavior reference

The workflow follows documented OMSI editor behavior: an unselected item under the cursor is blue, the selected item is red, left click selects and clicking empty space deselects.
