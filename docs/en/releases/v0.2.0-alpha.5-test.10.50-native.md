# OMSI Map Studio v0.2.0-alpha.5-test.10.50-native

More direct path editing from inside the viewport.

## Path on the map

- clicking a real path node still selects its SCO/SLI owner and focuses the matching path index;
- a compact viewport HUD shows path index, kind, direction and width;
- the HUD also reports whether the clicked node is the start or end;
- **← Path** and **Path →** update the same visual focus;
- hiding paths clears the HUD so stale state is not left behind.

## Double-click to edit

- double-clicking a path node hit-tests the real visible node;
- owner selection and focused path index are synchronized before editing;
- the viewport event directly reuses `OnEditSceneryPathClick`;
- SCO objects continue through `SceneryPathEditorDialog`;
- SLI splines continue through `SplinePathEditorDialog`;
- persistence, backup and reload stay in the existing real workflow.

No parallel editor or mock data was introduced.
