# OMSI Map Studio v0.2.0-alpha.5-test.10.4-native

Build **ALPHA 5 TEST 10.4 — Map mode freeze fix**.

This build supersedes Test 10.3 and specifically targets freezing when opening **Project > Map**.

## Fixes

- clicking **Map** no longer runs `Viewport.RestoreSceneView()`;
- switching to Map no longer cancels/reinitializes the 3D scene;
- tile grouping/sorting now runs off the UI thread;
- stale tile-list refresh jobs are cancelled when superseded;
- the final legacy **Map > Tile Manager...** entry path was removed;
- every Map/Tiles entry point now opens the embedded panel;
- no visible UI entry point calls the old `ContentDialog`;
- inline map-list failures are logged to `startup.log`.

## Layout kept

- Project: **Scene / Assets / Map / Transport**;
- map navigation **← ↑ ↓ →** stays outside Project in the top toolbar;
- panel/toolbar drag grips remain;
- Tiles/Map remains inside Project.

## Validation

The workflow fails if:
- any XAML entry point calls `OnTileManagerClick`;
- Map mode calls `RestoreSceneView()`;
- tile aggregation returns to the UI thread;
- the global Tiles button is restored.

PR #3 remains **DRAFT** and not merged.
