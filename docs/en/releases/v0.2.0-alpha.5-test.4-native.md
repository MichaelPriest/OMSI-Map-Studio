# OMSI Map Studio v0.2.0-alpha.5-test.4-native

**ALPHA 5 TEST 4 — Native Orientation & Loading Validation** build of the WinUI 3 + Direct3D 11 architecture.

This is a **validation prerelease** from `feature/native-winui-d3d11`. PR #3 remains **DRAFT** and **unmerged**.

## Test 4 highlights

### Scenery orientation fix

- OMSI geometry now consistently respects the original coordinate convention with **Z as height**;
- conversion into the native Y-up renderer is centralized;
- O3D/X scenery no longer depends on the previous axis interpretation that could place meshes sideways or upside down;
- triangle winding is preserved after axis conversion;
- per-mesh transforms use the same conversion;
- native Library 3D previews now use the same orientation rules as the map viewport.

### Textures

- fixes O3D texture V orientation in the Direct3D 11 pipeline;
- Core UV values remain preserved for editing/export and are converted only at the renderer boundary;
- regression coverage was added for vertical axis, normals, transforms, and UV conversion.

### Visual loading feedback

- new native loading overlay and animation;
- feedback while opening full maps;
- feedback while switching between full-map and 3×3 modes;
- feedback while navigating tiles;
- feedback while starting/indexing the standalone Workspace;
- feedback during asset Library refresh.

### Standalone Workspace

Still included:

- editing without requiring OMSI to be installed;
- Workspace map creation/import;
- original starter content;
- native asset Library;
- Easy Road;
- Bridge and Tunnel creators;
- traffic, traffic lights and paths;
- Tracks, Trips, Stops, StationLinks, and Lines/Tours;
- F11 and native editing layout;
- **Open OMSI** as an optional content source.

## Validate in this Alpha

1. Open a known map and compare object orientation against the OMSI Editor.
2. Check trees, buildings, junctions, roads, and tall scenery that previously appeared tilted/upside down.
3. Verify O3D textures are not vertically inverted.
4. Compare the Library 3D preview with the same asset placed in the map.
5. Open a full map and verify the loading animation.
6. Switch to 3×3 mode and navigate tiles while checking progress feedback.
7. Refresh the Library and verify the indexing animation.
8. Test selection, move/rotate, and save after the map has loaded.
9. Test the standalone Workspace and then **Open OMSI**.
10. Report any specific asset that still uses a different orientation convention.

## Known limitations

- this remains a validation Alpha;
- older addons may contain meshes exported with unusual conventions and can still require specific handling;
- writes on `[worldcoordinates]` maps remain blocked until full geographic round-trip conversion is validated;
- OSM relations with holes/inner rings remain restricted for safety;
- Proton Bus, LOTUS, and other simulators do not yet have complete operational adapters;
- real subscription/license enforcement remains disabled in Development Preview.
