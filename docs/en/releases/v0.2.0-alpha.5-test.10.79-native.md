# OMSI Map Studio v0.2.0-alpha.5-test.10.79-native

## Test 10.79 — Real World Reconstruction: confidence-aware scene planner

This preview starts the complete real-world reconstruction pipeline.

### Goal

Combine geographic data, aerial imagery, street-level imagery and user-supplied imagery to reconstruct:

- buildings and houses;
- walls and fences;
- utility poles and street lights;
- trees;
- signs;
- bus shelters;
- guard rails;
- sidewalks;
- driveways;
- parking areas;
- other scenery elements.

### First implemented stage

A new `MapStudioSceneReconstructionPlanBuilder` has been added.

Each reconstructed feature keeps:

- feature kind;
- evidence source;
- source reference;
- per-source confidence;
- fused confidence;
- known dimensions;
- optional building-footprint association;
- automatic generate/review decision.

Modeled sources:

- OSM;
- aerial imagery;
- street-level imagery;
- user-supplied imagery;
- digital elevation model.

Independent evidence increases confidence. Features above **0.82** may be auto-generated; results between **0.55 and 0.82** are queued for review; lower results are not treated as reliable geometry.

### Street-level imagery

The pipeline is designed for providers whose licensing permits processing and derived content, including user-owned imagery and compatible street-level sources. Google Street View will not be used to automatically generate derived assets.
