# OMSI Map Studio v0.2.0-alpha.5-test.10.21-native

Build **ALPHA 5 TEST 10.21 — CARTO key integrated into the real-map creator**.

## Fix for “API KEY REQUIRED”

CARTO Basemaps now requires an API key for external tiles. Test 10.21 keeps CARTO and adds the proper credential flow.

The **Create real map by area** panel now includes:

- **CARTO Basemaps key** field;
- **Save key** / **Update key** button;
- **How to get** button opening CARTO's official request page;
- local storage in **Windows Credential Manager**;
- automatic map reload after saving the key.

CARTO URLs used by Leaflet and the terrain reference now include `?key=` and use the official `/rastertiles/light_all/` path.

## Fallback

When no CARTO key is stored, the interactive area picker temporarily uses OpenStreetMap so area selection keeps working without the “API KEY REQUIRED” watermark.

The CARTO terrain reference still requires the user's CARTO key.

## Cache

CARTO reference images now use a new `carto-keyed-v1` cache namespace so old watermarked tiles are not reused.

## Carried forward

Test 10.20 navigation improvements, tile/asset/GPU caches, and the real EXE startup smoke test remain included.
