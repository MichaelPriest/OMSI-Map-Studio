# OMSI Map Studio v0.2.0-alpha.5-test.10.57-native

## Test 10.57 — smoother internal junction traffic paths

This preview improves traffic movement inside procedural junctions.

- straight-through movements remain a single `[path]`;
- turns are now composed from multiple connected `[path]` segments;
- segments approximate a quadratic Bezier using the true junction origin as control point;
- the entry tangent follows traffic arriving from the source road;
- the exit tangent follows the destination road;
- segment count scales with turn angle and is capped to avoid excessive path counts;
- only the existing OMSI `[path]` syntax already parsed by the project is used;
- path width still follows connected lane widths;
- inbound/outbound and one-way rules are preserved;
- a real regression test verifies continuity across a 90-degree turn.

This prevents buses and traffic from cutting turns across the junction as one diagonal chord.
