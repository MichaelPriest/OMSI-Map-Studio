# OMSI Map Studio v0.2.0-alpha.5-test.5-native

**ALPHA 5 TEST 5 — O3D Assembly Fix** build of the WinUI 3 + Direct3D 11 architecture.

This is a **validation prerelease** from `feature/native-winui-d3d11`. PR #3 remains **DRAFT** and **unmerged**.

## Main Test 5 fix

The Test 4 screenshot exposed partially disassembled models: roofs detached from buildings, very tall scenery planes/vegetation, and meshes with incorrect-looking orientation.

The native renderer was applying a second axis conversion even though O3D vertices already arrive in the runtime **Y-up** coordinate system.

Test 5:

- restores native Y-up O3D vertex axes;
- keeps original triangle winding;
- restores normals without an extra axis swap;
- preserves per-mesh `new_pos`, `rot_x`, `rot_y`, `rot_z`, and `scale` transforms on model axes;
- applies the same rule to native Library 3D previews;
- keeps the Direct3D texture V-orientation fix separately;
- keeps the new UI and loading animations.
