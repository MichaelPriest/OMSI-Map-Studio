# OMSI Map Studio v0.1.0-alpha.7

Prerelease focused on **selection reliability** and the evolution of **auto-adaptive Explorer/Libraries**.

## Selection

- **Select / Q** returns to **All**, allowing direct object and spline selection;
- picking uses Babylon's native canvas pointer coordinates to avoid Windows DPI/scaling drift;
- hover on an unselected item is highlighted **blue**;
- the selected item is highlighted **red**;
- left click selects and clicking empty space clears selection;
- repeated clicking keeps focus/centering behavior;
- in addition to real mesh raycasting, objects now use an approximate **visual selection volume** computed from O3D geometry, mesh transforms and tree dimensions;
- clicking a facade, roof or another visible part of a large object no longer depends only on its placement origin;
- fallback prioritizes the first approximate surface reached by the ray to reduce distant-object stealing;
- protected assets or assets without usable rendered meshes remain selectable;
- meshless fallback now also displays a blue hover guide;
- spline surfaces keep real picking with axis fallback.

## Explorer and libraries

- Map Explorer, Object Library and Spline Library use different automatic widths according to content;
- grids automatically switch between one, two and three columns;
- filters and metadata reorganize according to available width;
- the drawer remains inside the usable editor area in desktop and fullscreen;
- a manual resize handle was added;
- chosen width and height are stored locally;
- double-clicking the resize handle restores automatic sizing;
- typography, search, cards and metadata remain enlarged for readability.

## Automated validation

- **129 Core tests** passed;
