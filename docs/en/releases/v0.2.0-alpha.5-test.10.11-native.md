# OMSI Map Studio v0.2.0-alpha.5-test.10.11-native

Build **ALPHA 5 TEST 10.11 — natural pointer movement, multi-selection, floating tools and real-map area creation**.

## Direct movement

**Move** now follows the actual pointer position on the selected item's plane.

- select the item;
- activate **Move**;
- drag the object/spline itself;
- the ghost follows the pointer in the dragged direction;
- release to apply;
- Inspector is not required.

Map panning now behaves like **grabbing and pulling the ground**, reducing inverted-feeling movement from angled camera views.

## Multi-selection

- **Ctrl+click** adds/removes objects or splines;
- the last selected item remains primary for Move/Rotate;
- additional selections are highlighted;
- Delete can remove the selected group with one confirmation;
- the dialog reports object/spline counts.

## Right-click radial wheel

Radial actions now show icon + text for Move, Rotate, Duplicate, Delete, Focus, Inspector, Curve, Split, Parallel, Raise, Level, Lower, Replace, Mirror and Flow.

## More compact Project panel

- Project actions are collapsible;
- Map/Tiles can be collapsed;
- Tile X/Y was removed from the Project card;
- a new **Tile XY** shortcut opens an internal floating window;
- Tile XY can be dragged and resized inside the editor.

## Create real map by area

New **Map > Create real map by area...** flow.

The movable/resizable window works like mobile offline-area selection:

1. choose OpenStreetMap or Google Maps;
2. pan/zoom the map under a fixed selection frame;
3. Map Studio calculates north/south/east/west bounds;
4. shows approximate dimensions;
5. calculates the required 300 m OMSI tile grid;
6. creates the selected area.

OpenStreetMap requires no key for interactive browsing and vector data.

Google Maps only uses the API key stored by the user in Windows Credential Manager. No Google key is bundled with the project.

### Options

- automatically generate OpenStreetMap roads;
- apply Google Elevation when a key is available;
- keep a visual reference on terrain;
- open the advanced coordinate flow.

Google elevation is disabled by default because API use can incur user-account charges.

This Alpha limits one area operation to **400 tiles** to prevent accidental freezes.

## Automatic OSM roads

When enabled:

- queries the selected bounding box through Overpass;
- reads `highway` ways;
- projects geographic coordinates into OMSI map space;
- selects procedural road profiles;
- previews the road graph;
- automatically starts spline/junction generation.

The public OpenStreetMap tile service is not bulk-downloaded for offline use.
