# OMSI Map Studio v0.2.0-alpha.5-test.10.52-native

## Test 10.52 — Custom Shape terrain texture painting

This preview extends the viewport-first editing flow to terrain:

- polygon capture directly in the viewport;
- real `groundtex` fill inside the shape;
- concave polygon support;
- painting across multiple OMSI tiles;
- edge feathering driven by the existing radius/feather controls;
- real DDS mask persistence and map reload;
- Core regression coverage for concave cutouts.

The implementation reuses real map data and the existing OMSI writers. No mocks are used.
