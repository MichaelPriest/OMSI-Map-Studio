# OMSI Map Studio v0.2.0-alpha.5-test.1-native

**ALPHA 5 TEST 1 — Native Feature Preview** build of the WinUI 3 + Direct3D 11 architecture.

This version is a **validation prerelease**. It combines the latest native migration work with several new capabilities that still need testing on real maps before any stability claim.

## Major changes

### Native editor and library

- WinUI 3 + Direct3D 11 remains the primary architecture;
- smart library with categories, search, favorites, recent/frequent assets, and collections;
- drag-and-drop from the library into the viewport;
- native 3D preview;
- persistent/cached geometry thumbnails;
- native workflows for selection, transforms, splines, terrain, Tracks, Trips, Stops, StationLinks, Lines/Tours, signals, paths, lights, and validation.

### Easy Road and procedural generation

- Easy Road with start/end points, curve offset, and editable preview before saving;
- level selected spline to real terrain height;
- original Map Studio Road Kit with generated splines/textures;
- non-destructive manual road tracing;
- procedural graph with X and T intersection detection;
- D3D11 graph preview over terrain;
- graph-to-OMSI placement conversion;
- transactional batch persistence with backup;
- linear auto-link foundation that does not cross junction nodes.

### Real maps, OSM, and terrain

- georeferencing and Google reference support;
- georeferenced Google overlay in D3D11;
- Google Elevation terrain workflow;
- local CSV/ESRI ASCII elevation-grid import;
- safe OMSI tile creation/deletion;
- Tile Manager;
- OSM road import into the procedural preview;
- OSM building-footprint import and projection;
- footprint preview over terrain;
- batch generation of OSM buildings;
- roof-shape support for quadrilateral footprints and self-intersection validation.

### Building Studio

- real procedural SCO + O3D generation;
- native O3D writer;
- houses/buildings by dimensions and floor count;
- flat, gable, hip, and shed roofs;
- optional reference/facade image;
- procedural windows and doors;
- editing of AI-suggested facade openings;
- backup before replacing an existing generated asset.

### Provider-neutral AI

- vendor-neutral Core contracts;
- OpenAI-compatible provider configuration;
- connection probing from WinUI;
- foundation for cloud providers, custom endpoints, and local models;
- AI returns structured parameters while final O3D/SCO geometry remains generated and validated locally by Map Studio.

### OMSI attachments

- object and spline attachment parsing;
- native inspection;
- conservative editing of validated attachments;
- safe persistence while preserving untouched data.

### Commercial and multi-simulator foundation

- subscription/license and entitlement layer prepared but **not enforced in this Alpha**;
- current Development Preview remains unlocked;
- Stripe is planned through a secure backend only, with no secret key in the desktop app;
- simulator adapter boundary is in place;
- OMSI 2 remains the only real adapter today;
- Proton Bus and LOTUS are future targets and are not advertised as supported yet.

## Known limitations

- this is an Alpha validation build, not a final release;
- procedural auto-link does not replace real junction assets at degree-3/4 nodes yet;
- automatic crossing/junction-object generation is still evolving;
- current thumbnails represent real geometry, while fully textured D3D11 thumbnail capture can still be improved;
- addon-specific OMSI materials may still need refinements;
- Proton Bus, LOTUS, and other simulators do not yet have complete adapters;
- real subscription/license enforcement is not enabled.
