# OMSI Map Studio v0.2.0-alpha.5-test.10.59-native

## Test 10.59 — lane-aware internal junction connections

This preview makes internal junction paths follow the actual lanes of connected roads.

- each arm resolves separate lane centers for inbound and outbound traffic;
- one-way roads distribute their lanes around the road centerline;
- two-way roads keep inbound/outbound lanes on opposite sides;
- movements use proportional lane pairing when source and target lane counts differ;
- multi-lane turns no longer share exactly the same center path;
- quadratic Bezier turns now use the intersection of the real lane tangents as their control point, preserving entry and exit alignment;
- existing one-way, inbound/outbound, lane-width and smooth segmentation rules remain in place;
- a real regression test validates two distinct lanes through a 90-degree turn.

This moves Road Kit junction behavior toward modern lane-aware road editing, with buses and traffic using separate trajectories.
