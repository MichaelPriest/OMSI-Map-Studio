# OMSI Map Studio v0.2.0-alpha.5-test.10.43-native

Second workspace reorganization pass inspired by the modular workflow of modern 3D editors and nEditor 1.0, while keeping our own identity and implementation.

## Viewport-first workspace

- the large duplicated bottom module palette is now hidden;
- primary modules remain in the compact vertical rail;
- the contextual bottom shelf now uses the space previously consumed by the duplicate module palette;
- a new floating viewport command strip exposes the active module, Perspective, Top, Frame, Grid and Reference;
- the viewport command strip automatically hides in fullscreen to avoid competing with the fullscreen HUD.

## Context-driven tools

- Objects now exposes Library, Buildings, Street furniture and Infrastructure;
- Roads keeps creation/editing actions and moves Bridges/Tunnels into its contextual menu;
- Terrain directly exposes Pick point, Raise, Lower, Level, Paint, Water, Real map and Reference;
- Traffic directly exposes OMSI Paths;
- Vegetation gains real Area brush and Line actions, reusing the existing placement modes and enabling varied rotation.

## Vegetation

The new buttons are not placeholders: Area brush selects the existing area placement workflow and Line selects the existing line placement workflow. Both continue using real indexed assets and the current spacing/radius/count placement settings.
