# OMSI Map Studio v0.2.0-alpha.5-test.10.82-native

## Test 10.82 — OSM street furniture in Real World Reconstruction

This preview expands the reconstruction pipeline to point-based urban scenery.

### Implemented

A new OSM importer supports:

- utility poles;
- street lights;
- traffic signs;
- bus stops and shelters.

Recognized explicit tag combinations include:

- `highway=street_lamp`;
- `power=pole` / `power=tower`;
- `traffic_sign=*` / `highway=traffic_sign`;
- `highway=bus_stop`;
- `public_transport=platform`;
- `amenity=shelter`;
- `shelter=yes`.

Each item preserves ID, coordinates, name, operator, reference and shelter type when available.

### Confidence

The adapter maps these elements into the same planner introduced in Test 10.79:

- `UtilityPole`;
- `StreetLight`;
- `TrafficSign`;
- `BusShelter`.

A single explicit OSM source may remain in review when no visual confirmation exists. Independent street-level imagery evidence raises confidence and may allow automatic generation.

### Tests

- recognition of all four supported types;
- scene-planner category mapping;
- isolated OSM furniture entering review;
- OSM + street-image evidence crossing the automatic-generation threshold.
