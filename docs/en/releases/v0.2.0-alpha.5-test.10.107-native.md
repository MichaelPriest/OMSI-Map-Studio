# OMSI Map Studio v0.2.0-alpha.5-test.10.107-native

## Test 10.107 — one-click real-world reconstruction + visual evidence

This alpha consolidates the WinUI **Create real map** flow and expands Real World Reconstruction with unified elevation, physical structure fixes, more faithful buildings and optional visual refinement.

### Create + reconstruct

The complete flow now runs through `RealWorldGenerationPanel` and the Session Controller:

- real OMSI asset indexing;
- unified OSM download;
- Google or Open-Meteo/Copernicus elevation;
- terrain, roads, junctions, bridges and tunnels sharing the same elevation datum;
- buildings, vegetation, infrastructure and street furniture reconstruction;
- cancellation with session rollback;
- overall progress, current stage, errors and final summary.

### Elevation and structures

Open-Meteo/Copernicus now feeds the same elevation surface used by the rest of the reconstruction pipeline.

Tunnel portal placement was also fixed: portals now follow the actual underground spline elevation, while portal wings account for the road-to-terrain cut.

Regression coverage was added for physical junction elevation over DEM and tunnel portals.

### Buildings and facades

Procedural facades now follow the actual floor count and building use:

- per-floor window patterns;
- glazed commercial ground floors;
- industrial/warehouse treatment;
- entrance detail on houses;
- facade and roof materials refined from visual evidence when available.

### Optional visual evidence

Two opt-in sources are available in Create real map:

- **Local images + AI** under `.mapstudio/references/buildings/<OSM id>`;
- **OpenAerialMap + AI for roofs**.

OpenAerialMap is restricted to imagery explicitly licensed **CC BY 4.0**, selected by coverage and best GSD. AI attempts are bounded, and nadir imagery is only allowed to refine visible roof information. Height, floor count, doors, windows and facade details are not inferred from aerial imagery.

Visual-source attribution and license information are preserved in `mapstudio-osm-building.txt`.

### Vegetation and assets

Vegetation selection no longer accepts an unrelated vegetation asset merely because it is present in the catalog. Missing matches are kept for review.

The pipeline also advanced OSM vegetation line/area planning, including tree rows, forests and scrub.

### Validation

- the previous baseline Native Windows CI completed successfully;
- the stale Preview Release smoke marker was updated to validate the current full-reconstruction UI without removing the check;
- new tests cover OpenAerialMap licensing/catalog selection, DEM junctions, tunnel portals and building appearance;
- no mocks were added and no smoke tests were weakened.
