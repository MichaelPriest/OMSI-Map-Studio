# OMSI Map Studio v0.2.0-alpha.5-test.10.31.1-native

Test 10.31 hotfix focused on **real-map creation** and the **CARTO/OpenStreetMap reference layer**.

## Real-map creation fixes

- core map/tile creation is now separated from optional post-create steps;
- CARTO, elevation, OSM import, or Library failures no longer get reported as map-creation failures;
- when a folder already exists after a previous attempt, the message explains that the map may have been created before an optional step failed;
- genuine creation failures now report the stage where they happened;
- after creating a multi-tile area, the active tile is restored to the central anchor tile.

## CARTO/OpenStreetMap fixes

- in full-map mode, CARTO streaming now prioritizes the center of the loaded coverage instead of the last tile created;
- 3×3 navigation mode continues to follow the active tile;
- the UI no longer reports a reference as active when zero GPU batches were produced;
- status now reports how many reference textures really reached the GPU and how many overlay triangles were rendered;
- if reference geometry/textures do not reach the GPU, attribution is hidden and an explicit rendering error is shown.

## Preserved from Test 10.31

- visual **Join** workflow using the safe Complete To solver;
- real `Previous/Next` updates;
- backup and construction history;
- green/orange endpoint handles;
- yellow curve/radius handle;
- terrain-coplanar reference layer with D3D11 depth bias;
- PR #3 remains DRAFT and unmerged.
