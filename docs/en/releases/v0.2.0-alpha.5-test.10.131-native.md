# OMSI Map Studio v0.2.0-alpha.5-test.10.131-native

## Test 10.131 — junction mouths detected from real `[path]` tangents

Test 10.130 introduced fitting of original OMSI junction objects from their real path geometry and trimming connected splines back to the object mouths. Test 10.131 hardens mouth detection for oblique intersections and closely spaced arms.

### What changed

Previously, lanes belonging to the same mouth were clustered from the radial angle of each endpoint position. On compact junctions, lateral lane offsets can spread those angles enough to chain two different mouths into one cluster.

The resolver now:

- calculates the real `[path]` tangent at each endpoint;
- includes real curve geometry using `rotation + arc`;
- orients the tangent outward from the object center;
- clusters lanes by `OutwardHeadingDegrees` instead of endpoint radial position;
- keeps mouth width based on the real lateral lane distribution;
- preserves the final 15-degree maximum angular fitting error against the OSM topology.

### Added regression coverage

A synthetic five-arm stock junction now covers two neighboring arms only 45 degrees apart. The regression verifies that all five mouths remain distinct, the correct object rotation is recovered and per-segment trimming remains available.

This prevents a physically compatible original OMSI junction from being rejected or interpreted with the wrong arm count solely because of lane offset geometry.

The procedural `MapStudio_Junctions` asset remains the fallback whenever no installed stock junction passes the compatibility checks.
