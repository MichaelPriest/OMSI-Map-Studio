# OMSI Map Studio v0.2.0-alpha.5-test.10.122-native

## Test 10.122 — no floating F11 label and persistent OMSI path

Test 10.122 includes 10.121 and fixes two recurring native UI issues.

### F11 / fullscreen

- **F11 remains functional** for entering and leaving fullscreen;
- the root Grid now hides automatic `KeyboardAccelerator` visual placement;
- this prevents the `F11` text from appearing as a floating hint near the pointer;
- other registered shortcuts remain available.

### OMSI installation path

After the first valid OMSI installation selection:

- the OMSI 2 root path is persisted in user settings;
- settings are stored in `%LOCALAPPDATA%\OMSI Map Studio\settings\user-settings.json`;
- writes are atomic to avoid partially written settings;
- subsequent **Open OMSI** actions show the stored path;
- the user can **Use saved path**, **Choose another folder**, or cancel;
- if the stored path no longer exists or does not contain `maps`, it is ignored and the normal folder picker is used;
- selecting another valid installation updates the stored path.

A preferences-write failure does not invalidate an OMSI installation that was already opened successfully; the UI reports the settings error instead.
