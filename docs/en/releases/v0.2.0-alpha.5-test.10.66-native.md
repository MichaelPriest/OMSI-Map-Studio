# OMSI Map Studio v0.2.0-alpha.5-test.10.66-native

## Test 10.66 — protect terrain below bridges and tunnels

This preview closes an important safety gap in the **terrain follows road** workflow.

- structural **bridge** and **tunnel** splines generated by the Road Kit can no longer invoke terrain conforming;
- `*_bridge.sli` and `*_tunnel.sli` variants are detected automatically;
- standalone `MapStudio_Bridges` and `MapStudio_Tunnels` packs are protected as well;
- selecting a structural spline disables the **Terrain ↕ road** action;
- the influence-band preview is cleared so the UI does not imply terrain will be modified;
- even if invoked through another path, `OmsiNativeSession` blocks the write before any `.terrain` file is touched;
- ordinary road splines continue to support terrain following;
- ordinary approach/ramp splines can still conform terrain when they are not structural assets;
- Core regression coverage validates Road Kit and standalone structural paths without mocks.

This prevents terrain from being pulled up to a bridge deck or into a tunnel volume.
