## Road elevation

The Roads quick bar now provides:

- **↓ Lower**;
- **Level**;
- **↑ Raise**;
- **0.5 / 1 / 2 / 5 m** steps;
- elevation indicator;
- **Terrain** command to return to terrain-following height;
- configurable recommended maximum gradient.

These modes affect the actual spline geometry:

- **Raise**: the endpoint rises relative to the start elevation, producing a real gradient;
- **Level**: keeps the starting elevation;
- **Lower**: the endpoint drops relative to the start elevation;
- **Terrain**: returns to following the real terrain height.

Examples:

- start 0 m → end +6 m = real ramp;
- start +6 m → end +6 m = level bridge/viaduct section;
- start 0 m → end -5 m = descent/tunnel ramp.

## Drag preview

During road creation the viewport reports:

- length;
- start elevation;
- end elevation;
- gradient percentage;
- radius for curved sections;
- current elevation mode.

Example:

`52.4 m · 0 → +5 m · 9.5%`

A warning is shown when the configured gradient recommendation is exceeded.

## Existing road editing

For a selected spline:

- raise by the current step;
- lower by the current step;
- level at the current elevation;
- conform start/end to terrain;
- changes use the existing undo/redo transform history.

## Spline radial wheel

The right-click spline wheel now exposes 12 actions:

- Move;
- Curve;
- Duplicate;
- Split;
- Parallel;
- Raise;
- Level;
- Lower;
- Replace;
- Mirror;
- Flow;
- Delete.

Road-specific extra actions remain hidden when an object is selected.
