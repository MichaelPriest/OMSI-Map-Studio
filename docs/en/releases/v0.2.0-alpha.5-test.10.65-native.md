# OMSI Map Studio v0.2.0-alpha.5-test.10.65-native

## Test 10.65 — adaptive clearance when OSM only provides layer

This preview improves grade-separated roads when OSM provides `layer` but omits complete `bridge` or `tunnel` tags.

- `layer > 0` can automatically use the Road Kit **bridge** variant;
- `layer < 0` can automatically use the **tunnel** variant;
- original `SourceBridge` and `SourceTunnel` fields still preserve exactly what came from OSM;
- the vertical profile samples real terrain to determine whether enough clearance/cover already exists;
- bridges already spanning a valley correctly are not given an unnecessary extra arch;
- on flat terrain, the target is approximately **4.8 m per layer level**;
- inferred offset ramps in and out gradually and is capped around an **8% approach grade**;
- structural run boundaries still meet access roads without an artificial step;
- no `.terrain` file is modified;
- a real regression test validates inferred bridge/tunnel placement on flat terrain and confirms terrain remains untouched.
