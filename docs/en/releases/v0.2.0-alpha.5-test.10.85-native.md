# OMSI Map Studio v0.2.0-alpha.5-test.10.85-native

## Test 10.85 — automatic infrastructure placement into OMSI tiles

This preview closes the path from real-world reconstruction through physical asset generation to actual OMSI map placement.

### Implemented

- automatic tile selection from the asset world center;
- world-to-local OMSI tile coordinate conversion;
- tile catalog loading directly from `global.cfg`;
- full-map object/spline scan to allocate a collision-free global ID;
- insertion through the editor's existing `OmsiTileObjectInserter`;
- SCO path normalization from the OMSI root;
- automatic tile backup before modification;
- temporary-file write followed by replacement to avoid partially written tiles;
- explicit failure when reconstructed geometry falls outside existing tiles.

### Pipeline now

`OSM -> import -> confidence -> projection -> O3D/SCO -> correct tile -> [object]`

Reconstructed infrastructure is no longer only an available generated asset: it can now be written directly into the OMSI map.
