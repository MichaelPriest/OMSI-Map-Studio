# OMSI Map Studio v0.2.0-alpha.5-test.10.23-native

Build **ALPHA 5 TEST 10.23 — definitive CARTO ground-reference fix**.

## Fixed issue

Fixes the error seen when using **Map > Map reference over terrain...** with CARTO:

`NullReferenceException: Object reference not set to an instance of an object.`

The previous Test 10.22 still converted the CARTO PNG to TGA through `Windows.Graphics.Imaging`; that conversion could return null objects on some machines.

## New path

Test 10.23 removes the WinRT/TGA conversion from the CARTO flow:

- the downloaded CARTO PNG signature is validated;
- the validated PNG is handed directly to the renderer;
- the renderer uses Map Studio's own PNG decoder before WIC;
- the CARTO reference no longer depends on `BitmapDecoder`/WinRT;
- WIC remains only as a fallback for other formats.

## Tests

Regression coverage now verifies:

- RGBA PNG decoding without WIC;
- rejection of non-PNG payloads;
- the CARTO path cannot return to `EnsureReferenceTgaAsync`.

## Carried forward

The build keeps:

- CARTO key storage in Windows Credential Manager;
- OSM fallback in the area picker;
- PNG cache validation;
- staged reference diagnostics;
- previous navigation and cache improvements.
