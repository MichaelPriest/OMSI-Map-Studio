# OMSI Map Studio v0.2.0-alpha.5-test.10.89-native

## Test 10.89 — batch OSM street furniture with real assets

This preview connects OpenStreetMap street-furniture points to the transactional scenery writer.

### Supported types

- street lighting / street lamps;
- utility and power poles/towers;
- traffic signs;
- bus stops and shelters.

### Asset selection

The new `MapStudioStreetFurnitureAssetSuggester` restricts candidates to the proper OMSI library groups and requires kind-specific path tokens.

This prevents unrelated scenery, such as benches or fences, from being used when OSM calls for a street light.

Metadata such as `ref`, operator, name and `shelter_type` further boosts more specific matches.

### Placement

High-confidence items follow:

`OSM -> classification -> confidence -> OMSI asset -> projection -> batch writer -> tile`

IDs are allocated globally, multiple items targeting one tile are written together, and each modified tile is backed up before replacement.

### Tests

- OSM lamp selecting a street-lamp asset;
- power pole selecting a utility/power-pole asset;
- BR:R-1 sign selecting a matching traffic-sign asset;
- bus shelter selecting a bus-stop/shelter asset;
- unrelated bench asset correctly ignored;
- IDs accounting for another tile;
- missing asset reported without modifying the map.
