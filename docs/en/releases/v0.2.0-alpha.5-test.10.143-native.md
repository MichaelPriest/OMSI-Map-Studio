# OMSI Map Studio v0.2.0-alpha.5-test.10.143-native

## Test 10.143 — resilient OpenStreetMap recovery

This build fixes real-map generation failures when the **Roads** layer receives timeouts and HTTP 503 responses from multiple Overpass sources at the same time.

### Changes

- each chunk can now try **all configured Overpass endpoints** before giving up;
- a timeout on a large parent chunk no longer hard-quarantines that endpoint before smaller recovery chunks can try it;
- explicit `429 Too Many Requests` responses still honor `Retry-After` and real cooldowns;
- partially failed layers get up to **two additional recovery passes**;
- successful child chunks are reused from persistent cache so only missing coverage is requested again;
- the direct OpenStreetMap map API remains available as a fallback;
- acquisition stays transactional: the Roads layer is accepted only after all required coverage has been validated.

### New regression coverage

- all configured endpoints are attempted before subdivision;
- a timed-out parent request can recover through smaller child chunks;
- rate-limit cooldown behavior remains intact;
- validated persistent cache continues to avoid redundant network requests.
