# OMSI Map Studio v0.2.0-alpha.5-test.10.86-native

## Test 10.86 — batch infrastructure reconstruction

This preview turns the real-world infrastructure pipeline into one safe operation for multiple features.

### One-click pipeline

The new runner executes:

`OSM -> import -> confidence -> automatic selection -> projection -> O3D/SCO -> tile grouping -> OMSI write`

Only features that reach automatic-generation confidence are materialized. Features that still require confirmation remain explicitly listed for review.

### Efficiency

- `global.cfg` is opened once;
- each tile is read once;
- the highest object/spline ID is calculated across the whole map;
- new IDs are allocated sequentially without collisions;
- multiple objects targeting the same tile use `AppendMany`;
- each modified tile is written only once.

### Safety

- backups are created before any tile modification;
- all temporary files are prepared before replacement;
- write failures restore tiles from backups;
- features outside the existing tile grid are skipped and reported;
- degenerate projected geometry is reported separately;
- low-confidence features remain under review and are not generated.

### Tests

- global next ID accounting for another map tile;
- one backup/write for two objects targeting the same tile;
- real O3D/SCO asset existence;
- non-target tile preserved;
- outside-grid automatic feature reported without modifying the map.
