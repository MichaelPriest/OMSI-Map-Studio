# OMSI Map Studio v0.2.0-alpha.5-test.10.56-native

## Test 10.56 — road-fitted junction/crossing footprints

This preview improves the geometry of procedural Road Kit junctions.

- removes the main **convex hull** fill that could over-expand outside intersection corners;
- derives the footprint from a radial union of the real connected road arms;
- respects each road's physical width;
- cuts asphalt back between adjacent mouths on cross, T, Y and oblique junctions;
- keeps a small safe central pad for unusual topologies;
- triangulates from the true junction origin so concave cut-backs remain safe and consistently wound;
- preserves existing internal traffic paths and lane/direction logic;
- adds regression coverage for the diagonal outside-corner cut-back of a four-arm crossing.

The expected result is less boxy/oversized junction asphalt and a cleaner visual fit against connected splines.
