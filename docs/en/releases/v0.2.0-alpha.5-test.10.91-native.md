# OMSI Map Studio v0.2.0-alpha.5-test.10.91-native

## Test 10.91 — full real-world reconstruction session with rollback

This preview adds the coordinator that joins the scenery runners into one reconstruction session.

### Coordinated pipeline

The new `MapStudioRealWorldSceneReconstructionRunner` executes against the same XML and geographic anchor:

1. urban infrastructure;
2. buildings;
3. vegetation;
4. street furniture with additional evidence when available.

Each stage reuses the generators and writers validated in previous previews.

### Session snapshot

Before the first modification:

- every tile referenced by `global.cfg` is copied into a session snapshot;
- the snapshot is stored under `.mapstudio/backups/real-world-scene-session`;
- if any later stage fails or is cancelled, all tiles are restored;
- already generated assets may remain on disk, while the map itself returns to its previous state.

This prevents a partially reconstructed map when, for example, buildings were already written and a later street-furniture asset selection fails.

### Tests

- building + tree + street light reconstructed in one session;
- global IDs advancing correctly across categories;
- session snapshot creation;
- deliberate furniture failure after a building write;
- byte-for-byte restoration of the original tile after failure.
