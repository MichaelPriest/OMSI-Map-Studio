# OMSI Map Studio v0.2.0-alpha.5-test.10.45-native

First functional Custom Shapes implementation in the native editor.

## Vegetation Custom Shape

- the Vegetation module now exposes a `Shape` command;
- every terrain click adds a vertex using real viewport picking;
- with three or more vertices the shape is visually closed in preview;
- fill spacing is configurable in meters;
- `Fill shape` distributes vegetation only inside the polygon, including concave shapes;
- fill respects map tiles and caps the batch at 256 positions;
- when a vegetation Collection/Preset is active, the shape uses the collection's multiple assets;
- without a preset, the currently selected vegetation SCO is used;
- persistence uses the native batch or multi-batch path with backup.

## Preview

The outline temporarily reuses the D3D11 procedural preview pipeline so vertices and the closed shape remain visible while editing. On completion or clear, an existing procedural-road preview is restored when present.

## Geometry foundation

`MapStudioWorldPolygonScatterer` adds point-in-polygon handling, concave polygon support, duplicate-vertex normalization and an explicit point cap.
