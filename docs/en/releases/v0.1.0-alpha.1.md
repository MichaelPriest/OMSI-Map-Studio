# OMSI Map Studio v0.1.0-alpha.1

First testable prerelease of the project.

## Included

- real OMSI 2 installation selection;
- map and tile discovery;
- preservation-oriented OMSI file reading;
- real objects from `.map` files;
- object selection in the viewport;
- real `.sco` metadata;
- `.o3d` mesh detection and structure inventory;
- geometry preview for unencrypted O3D meshes;
- React/TypeScript/Babylon.js UI inside the desktop host;
- self-contained Windows x64 package.

## Important

This alpha is **read-only**. Saving, creating or modifying maps is still disabled.

See `docs/en/TESTING.md` for known limitations and the test checklist.
