## Startup smoke test

The native executable now has an internal `--startup-smoke-test` mode used only for automated validation.

Before creating the ZIP/installer or publishing the prerelease, the workflow:

1. runs the published self-contained `MapStudio.Native.exe`;
2. constructs `App` and `MainWindow`;
3. activates the WinUI window;
4. requires the `STARTUP_SMOKE_TEST_PASSED` marker in `startup.log`;
5. fails on any `FATAL stage=` entry;
6. requires a normal exit within the smoke-test timeout.

This prevents publishing a Preview that compiles successfully but immediately fails to open because of XAML, PRI resources, WinUI initialization, or main-window construction.
