# OMSI Map Studio v0.2.0-alpha.5-test.9-native

Build **ALPHA 5 TEST 9 — Detached Timetable + Path CRUD** for the WinUI 3 + Direct3D 11 architecture.

This prerelease includes the latest Route Studio/Timetable work and completes the basic editing flow for SCO/SLI internal traffic paths before the next visual and operational validation round.

## Timetable / Route Studio

- detachable **Timetable** window;
- direct **Line/Tour** editing;
- full **Trip** editing from the Timetable window;
- **Profile** editing with stop timing;
- visual departure reordering;
- duplicate and sort-by-time actions;
- awaited saves with concurrent-save protection;
- catalog refresh after save while preserving current selection;
- Trip focusing in Route Studio and on the map.

## Traffic paths

- native SCO `[path]` editing;
- native SLI `[path]` editing;
- duplicate current path without shifting existing indexes;
- **safe deletion** of the focused path with confirmation and backup;
- **new path creation**, including assets with no existing path sections;
- initial type selection: vehicle, pedestrian, rail, or air;
- editable width, direction and basic geometry;
- newly created/duplicated path remains focused for refinement;
- edits operate on real OMSI files without introducing a proprietary format.

> Warning: paths belong to the shared SCO/SLI asset. Editing them affects every instance using that file.

## Safety / round-trip

- backup before edit, duplicate or delete operations;
- creation/removal use preservation-safe Core patchers;
- SCO and SLI round-trip tests;
- CI validates Core, Renderer and WinUI x64 build.
