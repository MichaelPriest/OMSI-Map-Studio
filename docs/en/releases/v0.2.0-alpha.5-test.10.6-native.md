# OMSI Map Studio v0.2.0-alpha.5-test.10.6-native

Build **ALPHA 5 TEST 10.6 — resizable Project panel + visible HUMAN paths**.

## Project panel

- In **Creator Focus / F11**, Project now has a **bottom-right resize grip**.
- The floating panel can be resized vertically and horizontally.
- Its maximum usable height was increased.
- Leaving F11 restores the normal desktop layout behavior.
- The **Asset Library** filter area now has internal vertical scrolling so lower controls and the asset list remain reachable on shorter panels.

## OMSI paths / HUMAN

- The viewport default preset now uses **TransportOverview**.
- **Vehicles, Pedestrians/HUM, Rails and Air** are enabled in the overview.
- Traffic and Transport no longer start with pedestrian paths filtered out.
- “Selected only” starts disabled in Transport.
- HUMAN paths now use a high-contrast ribbon instead of a near-white strip.
- **HUM** labels, direction arrows and endpoint nodes remain enabled.
- Renderer tests explicitly verify pedestrian path inclusion.

## Validate

1. Enter **F11**.
2. Drag the bottom-right corner of **Project** to resize it.
3. Open **Assets** and verify the filter area scrolls while lower content stays reachable.
4. Load a map containing HUMAN paths.
5. Enable **Traffic** or **Transport > Show Paths**.
6. Confirm CAR, HUM, RAIL and AIR are visible and HUMAN is easy to identify.
