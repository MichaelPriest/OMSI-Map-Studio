# OMSI Map Studio v0.2.0-alpha.5-test.10.135-native

## Test 10.135 — stock OMSI signs from explicit OSM evidence

Test 10.135 expands automatic road-sign reconstruction without inventing signs. Map Studio now requests explicitly mapped priority signs from OpenStreetMap and only selects an installed stock asset when its code/semantics actually match the OSM evidence.

### OpenStreetMap

The furniture layer now includes:

- `traffic_sign=*`;
- `highway=traffic_sign`;
- `highway=stop`;
- `highway=give_way`.

The OSM cache schema is raised to `osm-layers-v3`, correctly invalidating older chunks that did not contain STOP/GIVE_WAY nodes. The historical `osm-layers-v2` marker remains present for compatibility with older release gates, but v3 is the active schema.

### Safe stock selection

For an explicit sign, the suggester requires a real match:

- `stop` can select STOP/`206` families;
- `give_way`/yield can select `205` families;
- `DE:206` requires `206` in the asset;
- `DE:274-30` requires both `274` and `30`;
- unknown codes such as `BR:R-1` do not fall through to an arbitrary `VZ_*`.

A genuinely matching custom asset remains eligible when its normalized filename contains the explicit sign reference.

### Sign direction

Numeric and cardinal directions remain supported. Test 10.135 additionally resolves:

- `direction=forward/backward`;
- `stop:direction=forward/backward`;
- `give_way:direction=forward/backward`.

Relative direction is converted into an absolute bearing from the geometry/order of the `highway=*` way that contains the sign node.

If the same node belongs to multiple ways whose candidate bearings disagree by more than 25 degrees, direction intentionally remains unresolved and the sign stays in review. A pseudo-random rotation is not used.

### Conservative auto generation

An explicit OSM traffic sign reaches automatic generation confidence only when it has:

1. an explicit compatible sign reference/code;
2. a resolved direction.

Otherwise it remains a review candidate.

### Regression coverage

Coverage verifies STOP/GIVE_WAY Overpass selectors, OSM cache v3, stop/give_way/traffic_sign importing, specific direction tags, east-west forward/backward bearing resolution, ambiguous multi-way rejection, STOP → `VZ_206`, GIVE_WAY → `VZ_205`, `DE:274-30` matching, incompatible-code rejection, and a real stock STOP round-trip into `tile_0_0.map`.
