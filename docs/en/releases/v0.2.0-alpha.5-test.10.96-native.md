# OMSI Map Studio v0.2.0-alpha.5-test.10.96-native

## Test 10.96 — automatic asset indexing in the real-world map pipeline

The complete pipeline can now be called without the UI manually preparing an asset list.

### New flow

`RunAutoIndexedAsync` performs:

1. refreshes the persistent OMSI installation asset index;
2. loads only scenery objects required by reconstruction;
3. downloads roads/scenery from Overpass;
4. generates roads, junctions and real-world scenery;
5. keeps the existing transactional rollback behavior.

### Persistent cache

The index is stored at:

`.mapstudio/cache/assets.sqlite`

Unchanged files are reused on later runs, avoiding unnecessary reprocessing.

### Progress

A new `IndexingAssets` stage was added to pipeline progress, with optional detailed progress from the asset indexer itself.

### Tests

- indexes two scenery objects and one spline;
- returns only scenery objects needed by the pipeline;
- creates the persistent database under `.mapstudio/cache`;
- the second run reuses all three files as unchanged.
