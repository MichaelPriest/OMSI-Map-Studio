# OMSI Map Studio v0.2.0-alpha.2-native

Corrected native preview for the issue where the first Native Preview could install successfully and then exit immediately on startup.

## Startup fix

The first preview was published as an unpackaged/self-contained WinUI 3 application. The package included the Windows App SDK runtime, but the application's own resource file, `MapStudio.Native.pri`, was missing from the publish directory.

This version:

- explicitly adds the project PRI to published files;
- enables the required Windows App SDK tooling path;
- fails the workflow if `MapStudio.Native.pri` is missing from the final package;
- adds startup logging under `%LOCALAPPDATA%\OMSI Map Studio Native Preview\Logs\startup.log`;
- attempts to show a native error message if XAML/MainWindow fails before the UI appears.

## Also included

In addition to the alpha.1-native feature set, this build includes:

- sequential spline construction with OMSI links;
- native fullscreen;
- editor shortcuts;
- resizable Explorer and Inspector panels.

## Installation

The Native Preview remains installed separately from the React/WebView2 build. The React version is not removed or replaced.
