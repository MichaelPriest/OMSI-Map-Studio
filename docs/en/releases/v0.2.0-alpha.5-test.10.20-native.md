# OMSI Map Studio v0.2.0-alpha.5-test.10.20-native

Build **ALPHA 5 TEST 10.20 — visible-first navigation in 3×3 mode**.

## Neighboring tiles appear first

When navigating one tile at a time in performance mode, the destination is normally already part of the 3×3 snapshot currently shown in the viewport.

This Test uses that fact directly:

- if the target tile is already loaded, the camera focuses it immediately;
- Map Studio then completes the new surrounding 3×3 region;
- the Test 10.19 tile cache reuses overlapping tiles instead of rereading unchanged content.

This reduces the perceived pause before the editor moves into the next area.

## Larger jumps

When the user selects a tile outside the current snapshot, loading now happens in two stages:

1. load and render the center tile first;
2. load the neighboring tiles required to complete the 3×3 region.

The second render preserves the navigation/camera state within the same map.

Pending transform edits still block region changes until they are saved, matching the previous safety behavior.
