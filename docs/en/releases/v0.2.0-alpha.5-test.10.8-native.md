# OMSI Map Studio v0.2.0-alpha.5-test.10.8-native

Build **ALPHA 5 TEST 10.8 - spline construction fix, easier selection, visible AI connection and PDF manual**.

## Critical fix - Build spline

The main drag-to-create road workflow was incomplete.

Previously, the start point and live preview worked, but releasing the mouse cleared the drag state without finishing the spline.

Now:
1. select a SLI;
2. click **Build spline**;
3. press at the start;
4. drag with live preview;
5. release at the endpoint;
6. the spline is finalized and submitted for insertion.

Startup failures now show explicit status messages. Valid SLI files without a renderable graphic profile can use a simple guide preview instead of failing silently.

## Easier selection

- larger object and spline picking proxies;
- more tolerant hover;
- larger circular candidate search around the cursor;
- repeated clicks at nearly the same point cycle overlapping candidates;
- status reports positions such as `1/3 overlapping`;
- simplified All / Objects / Roads-splines / Terrain-tile selection strip.

## AI connected to the map

AI setup is now exposed directly in the editor:
- **AI: connect** top-bar button;
- **AI > Connect / test AI on map...**;
- active-profile indication;
- direct connection test for the profile used by map AI tools;
- credentials remain protected in Windows Credential Manager.

## PDF User Manual

The build generates formatted PDF manuals:
- `Docs/Manual-pt-BR.pdf`;
- `Docs/Manual-en.pdf`;
- Markdown remains as a fallback.

The **Help** menu prefers PDF.

The manual now documents overlapping selection, drag spline construction and AI connection in addition to current editor tools.
