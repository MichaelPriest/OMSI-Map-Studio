# OMSI Map Studio v0.2.0-alpha.5-test.10.46-native

Third modular workspace pass, now focused on traffic and path editing directly from the viewport workflow.

## Traffic module context

- Previous and next path actions in the contextual bar;
- path focus uses the actual selected object/spline;
- Isolate toggles path geometry for the current selection/focus;
- Edit path opens the real SCO/SLI [path] editor;
- + Path reuses the real path insertion workflow;
- Traffic light opens the real selected traffic-light program editor;
- clicking path nodes in the viewport continues to synchronize the focused path index.

## Goal

Reduce dependence on side windows while editing and move toward a 3D-editor workflow: select in the map, focus a path, isolate it, edit it and validate without leaving the viewport.
