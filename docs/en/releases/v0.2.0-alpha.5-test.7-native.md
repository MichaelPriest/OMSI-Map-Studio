# OMSI Map Studio v0.2.0-alpha.5-test.7-native

**ALPHA 5 TEST 7 — O3D Front-Face Fix** build of the WinUI 3 + Direct3D 11 architecture.

This prerelease fixes the inward-facing object surfaces seen after restoring the correct O3D axes.

## Main fix

O3D geometry was assembled in the correct position, but its triangle winding did not match the native Direct3D 11 front-face convention. Walls and other surfaces could therefore look open or visible mainly from the inside.

Test 7:

- keeps native Y-up O3D axes without another axis conversion;
- reverses only O3D triangle winding;
- makes visible faces agree with stored vertex normals;
- applies the same rule to native Library 3D previews;
- adds regression coverage comparing geometric face normal against stored normal;
- keeps the texture/UV fix;
- keeps the F11 layout correction;
- keeps the new interface and loading animations.
