# OMSI Map Studio v0.2.0-alpha.4-test.3-native

**TEST 3 — Native Stable Test** build of the WinUI 3 + Direct3D 11 architecture.

This is the first build in this native sequence treated as a **stable candidate for real-world testing**. It is still an alpha prerelease: “Stable Test” means the current development round passed automated renderer tests and the WinUI host build, not that the entire editor migration is complete.

## Build focus

Test 3 consolidates fixes for materials and objects that were still rendered incorrectly.

### Trees and legacy textures

- native support for scenery objects defined only by `[tree]`;
- crossed billboards preserving placed height and aspect ratio;
- alpha cutout and double-sided foliage rendering;
- built-in 24/32-bit TGA decoder including RLE TGA, reducing white objects caused by missing WIC codecs.

### Materials and complex objects

- `[matl]` now targets the correct occurrence of a repeated texture in the mesh;
- `[matl_alpha]`, `[matl_transmap]`, night/light maps, and Z flags remain attached to the native material pass;
- external transmaps are evaluated by the shader;
- culling is corrected for alpha materials, legacy DirectX `.x` meshes, and mirrored transforms;
- bump maps now use real per-triangle normals and tangents;
- environment maps use camera-relative reflection;
- advanced bump/environment state is reset before the sky pass to prevent state leaking between frames.

### Native UI

A new viewport tool palette inspired by city-building editor workflows provides direct entries for:

- Selection;
- Objects;
- Roads/Splines;
- Crossings;
- Terrain;
- Water;
- Traffic;
- Transport;
- Validation.

Selection, Objects, Roads/Splines, and Terrain already invoke existing native tools. Water, Traffic, Transport, and Validation have their native UI entry points prepared, while their dedicated editors are still being migrated.

## Validate first

1. Open Grundorf and one larger map you know well.
2. Check trees for orientation, alpha cutout, height, and white rectangles.
3. Check walls, houses, and objects that previously rendered white.
4. Check crossings and objects with multiple materials.
5. Toggle day/night.
6. Inspect glass/reflections and assets using bump/environment maps.
7. Test selection, focus, move/rotate, filters, and the new visual shortcuts.
8. Test both full-map and 3×3 performance modes.

## Compatibility still being refined

We are not yet claiming 100% visual compatibility with every OMSI material command. Dynamic cases such as `[matl_change]`, `[alphascale]`, advanced environment masks, and addon-specific material behavior will continue to be refined.

The Water, Traffic, Transport, and Validation buttons do not mean those four dedicated editors are complete yet.
