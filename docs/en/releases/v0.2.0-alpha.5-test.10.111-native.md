# OMSI Map Studio v0.2.0-alpha.5-test.10.111-native

## Test 10.111 — request-scoped OSM timeouts and multi-tile placement regression

This alpha focuses only on the two defects found in real testing and adds no new feature work.

### OpenStreetMap import no longer has a global 120-second deadline

The two-minute global scene-download deadline was removed.

Now:

- each endpoint attempt is still limited to 20 seconds;
- the complete reconstruction is no longer artificially cancelled at 120 seconds;
- primary chunks target roughly 750 m instead of 1,500 m to reduce dense queries;
- at most two Overpass HTTP calls are active at once, including subdivision recovery;
- endpoint fallback remains enabled and the four recovery subchunks may advance concurrently under the same global two-request limit;
- the user cancellation token still cancels requests and the pipeline;
- OpenStreetMap stage progress reports completed chunks and accumulated attempts.

Existing rollback behavior is preserved.

### Coordinate and placement audit

The Test 10.110 correction was audited end to end:

- geographic projection produces world X/Z coordinates;
- tile ownership is resolved from world coordinates;
- persistence converts world coordinates to tile-local coordinates exactly once;
- the renderer reconstructs world coordinates by adding the tile origin exactly once;
- terrain-relative objects store zero vertical offset and receive terrain elevation once;
- splines use the correct OMSI vertical field without adding DEM again in the renderer;
- generated building and infrastructure meshes are local to their object center, avoiding double translation.

A multi-tile regression now covers negative, central and positive tile coordinates. It reconstructs world coordinates from persisted OMSI data, verifies every stored placement remains inside the physical tile rectangle, and rejects a placement outside the map.

### Tests

In addition to the existing smoke coverage, this build adds regressions for:

- bounded concurrent OSM chunk processing;
- per-chunk progress;
- removal of the reconstruction-wide deadline;
- multi-tile placements constrained to the physical bounding box.

Test 10.109/10.110 clipping, OMSI axis and DEM coverage regressions remain active.
