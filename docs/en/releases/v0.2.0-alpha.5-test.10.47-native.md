# OMSI Map Studio v0.2.0-alpha.5-test.10.47-native

Traffic module improvement connecting traffic-light program selection directly to the viewport.

## Visual locating

- selecting a traffic-light program while in Traffic mode selects and frames the corresponding real scene object;
- a new Locate button can repeat the focus manually;
- resolution uses the program's real ObjectId and Tile X/Y;
- focusing reuses the editor's existing picking/Explorer path rather than creating a parallel representation.

## Workflow

Users can now select a signal program, locate its controller in the map, inspect nearby paths and open the signal editor without losing visual context.
