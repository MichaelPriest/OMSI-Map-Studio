# OMSI Map Studio v0.2.0-alpha.5-test.10.3-native

Build **ALPHA 5 TEST 10.3 — inline Map mode + movement shortcut layout fix**.

This build supersedes Test 10.2 and targets the reported **Map** button runtime failure plus the correct Project-panel organization.

## Map button fix

- **Map** is back inside the **Project** panel;
- the Map button no longer opens the Tile Manager through a `ContentDialog`;
- Map now opens its own embedded Project surface, removing the UI path that could still fail at runtime;
- the panel lists map tiles, coordinates, loaded/out-of-region state and duplicate references;
- double-click or **Focus** navigates to the selected tile;
- create/delete tile actions remain available in Map mode.

## Requested layout correction

- **Tiles stays inside Project**;
- the global **Tiles** button was removed from the top toolbar;
- the quick movement group **← ↑ ↓ →** was removed from Project;
- quick tile navigation now lives in the global top toolbar;
- Project again exposes four areas: **Scene / Assets / Map / Transport**.

## Kept from Test 10.2

- Tile Manager exception protection;
- duplicate-coordinate handling;
- light/dark/high-contrast theme;
- minimizable translucent panels;
- optimized asset library;
- OMSI-style Paths;
- advanced Timetable/Route Studio.

## Validate first

1. Start the application.
2. Open/create a map.
3. Click **Map** inside Project and confirm the application stays open.
4. Select and focus tiles from the embedded Map panel.
5. Confirm **← ↑ ↓ →** is no longer inside Project.
6. Confirm quick tile navigation is in the global toolbar.
7. Switch Scene / Assets / Map / Transport repeatedly.
