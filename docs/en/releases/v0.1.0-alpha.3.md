# OMSI Map Studio v0.1.0-alpha.3

Third testable OMSI Map Studio prerelease, now with experimental preservation-safe editing.

## Highlights

- full-map mode by default, with optional 3×3 performance mode;
- React UI inside the desktop host consuming real C# state;
- real `.sco` objects and O3D geometry loaded progressively;
- select, move, rotate and numeric X/Y/Z/rotation/pitch/bank editing;
- unsaved previews with undo/redo and discard;
- preservation-safe transform saving with tile reread, conflict detection, backup and atomic replacement;
- real splines with `.sli`, `[profile]` / `[profilepnt]` parsing, preview extrusion, persistent numeric editing, and W/E move/rotate gizmos;
- real `Sceneryobjects` Library with on-demand search;
- object placement with real preview and safe persistence when a compatible template of the same `.sco` exists;
- **Place copy** to reuse the selected object's `.sco`, initially preserving Z/rotation/pitch/bank while choosing new X/Y in the viewport;
- preservation-safe persistent object deletion with ordinal + ID + `.sco` validation, confirmation and automatic backup;
- new global ID allocation across objects, attachments and splines;
- dedicated application icon.

## Write safety

Alpha.3 does not reserialize the whole tile when saving a transform or inserting an object. The host reopens the current file, validates element identity, preserves unknown sections/comments, creates a backup under `.mapstudio-backups/<timestamp>/`, and uses atomic replacement.

## Current limitations

- spline creation and previous/next link editing are not implemented yet;
- persistent insertion of a `.sco` never used in the map remains blocked when no safe template is available;
- binary `.terrain` is not interpreted yet;
- spline/O3D image textures are not applied yet;
- `[worldcoordinates]` maps remain limited for editing.

See `docs/en/TESTING.md` for the validation checklist.
