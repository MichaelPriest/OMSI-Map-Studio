# OMSI Map Studio v0.1.0-alpha.3

Third testable OMSI Map Studio prerelease, now with experimental preservation-safe editing.

## Highlights

- full-map mode by default, with optional 3×3 performance mode;
- React UI inside the desktop host consuming real C# state;
- real `.sco` objects and O3D geometry loaded progressively;
- select, move, rotate and numeric X/Y/Z/rotation/pitch/bank editing;
- unsaved previews with undo/redo and discard;
- preservation-safe transform saving with tile reread, conflict detection, backup and atomic replacement;
- real splines with `.sli`, `[profile]` / `[profilepnt]` parsing, preview extrusion, persistent numeric editing, W/E move/rotate gizmos, detached-copy creation, and transactional deletion of detached or connected splines;
- transactional `previous/next` link editing with reciprocal old/new neighbor updates and multi-tile rollback-safe writes;
- real `Splines` Library with on-demand search and safe Normal/Height creation from an installed `.sli` when a real neutral template of the same type exists;
- real `Sceneryobjects` Library with on-demand search;
- object placement with real preview and safe persistence when a compatible template of the same `.sco` exists;
- **Place copy** to reuse the selected object's `.sco`, initially preserving Z/rotation/pitch/bank while choosing new X/Y in the viewport;
- preservation-safe persistent object deletion with ordinal + ID + `.sco` validation, confirmation and automatic backup;
- new global ID allocation across objects, attachments and splines;
- dedicated application icon.

## Write safety

Alpha.3 does not reserialize the whole tile when saving a transform or inserting an object. The host reopens the current file, validates element identity, preserves unknown sections/comments, creates a backup under `.mapstudio-backups/<timestamp>/`, and uses atomic replacement.

## Current limitations

- installed-file creation requires a real neutral template of the same type in the map;
- persistent insertion of a `.sco` never used in the map remains blocked when no safe template is available;
- binary `.terrain` is not interpreted yet;
- real O3D and spline-profile textures loaded on demand for selections/previews, with BMP/PNG/JPG/GIF/WebP/DDS/TGA support and a 16 MiB cap;
- `[worldcoordinates]` maps remain limited for editing.

See `docs/en/TESTING.md` for the validation checklist.


### Texture prefetch

- real textures also fill progressively for resources near the active tile;
- automatic budget of 16 O3D textures + 8 spline textures;
- nearby `.sli` profiles are prepared sequentially;
- selection/preview remains priority outside the automatic budget;
- the status bar exposes `X/24` usage.


### SCO material overrides

- mesh-ordinal-preserving parsing for static `[matl]`;
- `[matl_alpha]` 0/1/2 mapped to opaque/cutout/blend;
- `[matl_noZwrite]` and `[matl_noZcheck]` applied in Babylon;
- `[matl_change]` is deliberately not frozen as static state;
- material inspector shows the SCO override that was actually matched.


### Bump maps

- static `[matl_bumpmap]` parsed per SCO material;
- real texture loaded through the existing safe resolver;
- explicit factor applied to Babylon `bumpTexture.level`;
- state/name/factor visible in the inspector.


### Night maps

- static `[matl_nightmap]` per material;
- manual **Nightmap** viewport layer;
- loaded only when enabled for selection/preview and within the automatic map budget;
- no fake time/script simulation.


### Environment maps

- static `[matl_envmap]` with file + strength;
- real texture applied as spherical reflection;
- strength clamped to 0–1;
- state and strength visible in the inspector.


### Material diagnostics

- recognized but not-yet-simulated material commands are now preserved in Core and shown in the inspector;
- initial coverage: `[matl_envmap_mask]`, `[alphascale]`, and `[matl_allcolor]`;
- no approximate/fake visual effects are introduced for these commands.


### Texture cache

- LRU cache capped at 64 assets;
- pending requests are no longer permanent history;
- evicted assets can be loaded again;
- **Clear cache** button in the viewport;
- `Cache: X/64` status.


### Object LOD

- per-mesh `[LOD]` preserved through Core/host;
- automatic switching by projected screen size;
- updates every 6 frames;
- global meshes remain always active;
- LOD labels in the Geometry tab.


### Spline surfaces on the map

- real nearby `.sli` profile extrusion;
- 3×3 window around the active tile;
- cap of 120 splines per scene;
- real textures reused from cache;
- **Spline profiles** layer toggle.


### Terrain diagnostics

- per-tile `[terrain]` marker detection;
- `<tile>.map.terrain` sidecar detection;
- real sidecar byte size in tile summary;
- terrain state exposed in the inspector;
- binary remains read-only/not decoded.
