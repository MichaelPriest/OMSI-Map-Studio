# OMSI Map Studio v0.1.0-alpha.3

Third testable prerelease, still read-only.

## Highlights

- redesigned UI based on the approved concept;
- **Open OMSI → Open map** workflow;
- active-tile + 3×3 region streaming for large maps;
- session tile cache;
- neutral editor base surface;
- real spline axes using position, rotation, length, radius and gradients;
- direct spline selection and inspection;
- safe `.sli` reader restricted to the `Splines` directory;
- declared texture and `[profile]` / `[profilepnt]` parsing;
- extrusion of the selected spline's real profile with neutral material;
- object selection and O3D preview;
- embedded per-triangle O3D materials.

## Important

Saving, map creation and modification remain disabled. Spline image textures and real terrain are not rendered yet.

See `docs/en/TESTING.md` for the validation checklist.
