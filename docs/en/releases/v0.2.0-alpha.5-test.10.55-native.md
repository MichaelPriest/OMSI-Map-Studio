# OMSI Map Studio v0.2.0-alpha.5-test.10.55-native

## Test 10.55 — Custom Shape terrain elevation and leveling

This preview expands the Terrain module **Custom Shape** workflow so it can edit real OMSI `.terrain` meshes as well.

- the same viewport-captured polygon can now **level**, **raise**, or **lower** terrain;
- existing groundtex polygon painting remains available;
- concave polygons are supported without incorrectly filling their cutouts;
- one operation can cross multiple OMSI tiles;
- world-space coordinates preserve continuity on shared tile borders;
- the shape edge gets an inward feather using `brush radius × smoothing`;
- real `.terrain` files are persisted through the existing safe backup/transaction writer;
- modified tiles are reloaded in the viewport;
- Core regression coverage includes concave shapes and adjacent-tile edge continuity.

Terrain panel flow:

`Draw shape` → `Level shape` / `Raise shape` / `Lower shape` / `Paint shape`.
