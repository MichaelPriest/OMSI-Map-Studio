# OMSI Map Studio v0.2.0-alpha.5-test.10.75-native

## Test 10.75 — continuous structural tunnel lining

This preview brings tunnel splines into alignment with the automatic portals introduced in Test 10.74.

- Road Kit upgraded to **1.5.0**;
- `*_tunnel.sli` variants now use the dedicated procedural `ms_tunnel_lining.bmp` texture;
- the clear opening gains approximately **0.50 m of lateral margin per side**, keeping lining away from the road/sidewalk edge;
- internal clear height is now **4.50 m**, aligned with automatic portals;
- walls and roof gain an additional structural shell approximately **35 cm** thick;
- lower side returns close the lining thickness without replacing the road/asphalt floor;
- geometry remains a real OMSI spline and follows straights, curves and gradients;
- traffic/pedestrian paths remain inherited from the base road profile;
- no `.terrain` file is modified;
- Core regression coverage validates the dedicated material, shell thickness, useful width and portal-compatible height.

Together with the Test 10.74 portals, this continuous shell makes the road ↔ tunnel transition structurally consistent. Next steps: terrain-adaptive mouths/slopes and optional internal lighting/details.
