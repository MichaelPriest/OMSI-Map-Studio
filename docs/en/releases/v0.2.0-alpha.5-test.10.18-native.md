# OMSI Map Studio v0.2.0-alpha.5-test.10.18-native

Build **ALPHA 5 TEST 10.18 — bounded GPU warm cache to reduce texture reloads**.

## Less texture reload when changing regions

Before Test 10.18, the renderer immediately disposed every GPU texture no longer requested by the current region. Returning to a recently visited area required decoding and uploading those textures again.

Test 10.18 temporarily retains the most recently used stale textures to reduce that repeated work.

## Memory bound

Retention is intentionally limited. The warm cache keeps at most:

- **64 stale textures**; or
- **128 MiB of estimated GPU memory**;

whichever limit is reached first.

When the limit is exceeded, least-recently-used stale textures are disposed. Textures required by the current scene remain protected.
