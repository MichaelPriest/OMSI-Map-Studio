# OMSI Map Studio v0.2.0-alpha.5-test.10.81-native

## Test 10.81 — real vegetation in the reconstruction pipeline

This preview connects the editor's existing OSM vegetation support to the **Real World Reconstruction** pipeline.

### Implemented

- point trees from OSM now enter the scene planner;
- shrubs remain a distinct category and are not converted into trees;
- tree rows enter as linear features;
- hedges enter as fence features;
- confidence increases when the source includes:
  - species;
  - genus;
  - leaf type;
  - multi-point line geometry;
- strong evidence can cross the automatic-generation threshold;
- incomplete evidence remains subject to the planner review threshold;
- every candidate preserves its OSM ID and notes describing which metadata supported the decision.

### Safety

No object is invented when evidence is insufficient. Reconstruction keeps using the same confidence system introduced in Test 10.79.

### Tests

Regression coverage was added for:

- a tree with known species;
- shrub preservation;
- hedge-to-fence mapping;
- tree-row automatic-generation confidence.
