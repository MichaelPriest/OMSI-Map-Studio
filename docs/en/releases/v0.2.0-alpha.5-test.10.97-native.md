# OMSI Map Studio v0.2.0-alpha.5-test.10.97-native

## Test 10.97 — expanded real-world street furniture

The real-world reconstruction pipeline now also recognizes public benches, waste baskets, bollards and fire hydrants from OpenStreetMap.

Dedicated planner kinds, OMSI asset selection tokens, hydrant asset classification and unified Overpass coverage were added.

Supported tags:

- `amenity=bench`;
- `amenity=waste_basket`;
- `barrier=bollard`;
- `emergency=fire_hydrant`.

These elements use the existing transactional pipeline with confidence gating, real installed assets, collision-free global IDs, tile grouping, backup and rollback.
