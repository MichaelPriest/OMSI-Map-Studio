# OMSI Map Studio v0.2.0-alpha.5-test.10.139-native

## Test 10.139 — OMSI stock first in automatic reconstruction

Test 10.139 fixes the case where Map Studio indexed original OMSI assets but still used generated assets in important parts of reconstruction.

### Roads: original OMSI is a hard priority

Road spline selection now follows this order:

1. strict physical match from original OMSI;
2. nearest original OMSI spline within a broader fallback tolerance;
3. compatible installed addon spline;
4. Map Studio Road Kit only as the final fallback.

This prevents ordinary OSM roads from falling back to Road Kit merely because the mapped width does not exactly match a stock spline's nominal width.

A regression covers a 7 m `service` road where the closest available original spline is `Splines\Marcel\str_2spur_11m...`. The final OMSI tile must contain the original spline and report zero Road Kit fallbacks.

### Road Kit only when actually required

Road Kit is no longer installed or refreshed on every reconstruction.

When every road segment resolves to an installed spline:

- `MapStudio_RoadKit` is not created or changed;
- `RoadKitFallbackSplineCount` stays zero;
- the runner reports no fallback spline installation.

Road Kit remains available where no usable installed asset exists or a structural variant still requires a generated fallback.

### Buildings: original objects before procedural generation

The building reconstruction runner now receives the indexed OMSI library.

For every automatically reconstructed building it first tries objects classified as original OMSI `BuildingObject`, including families such as:

- `Sceneryobjects\Buildings_MC\...`;
- `Sceneryobjects\Buildings_RUE\...`;
- `Sceneryobjects\Buildings_DDR_RUE\...`;
- `Sceneryobjects\Buildings_JHY\...`.

The selected stock object is deterministic and aligned to the main axis of the OSM footprint.

Only when no usable original building is available does the system call `MapStudioFootprintBuildingAssetGenerator`.

### Tile verification

A regression reads `tile_0_0.map` back and requires the stock building path:

`Sceneryobjects\Buildings_MC\bw_50s_01.sco`

with:

- `InstalledOmsiBuildingCount = 1`;
- `ProceduralBuildingCount = 0`;
- no `MapStudio_Buildings` path.

### Visible diagnostics

The reconstruction completion message now reports separately:

- OMSI stock road splines;
- Road Kit fallbacks;
- OMSI stock buildings;
- procedural buildings.

This makes it possible to verify directly whether reconstruction is really using the installed original content.
