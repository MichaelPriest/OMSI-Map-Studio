# OMSI Map Studio v0.2.0-alpha.5-test.10.62-native

## Test 10.62 — OSM bridge/tunnel/layer metadata in native placement

This preview fixes an important metadata loss between the OSM road graph and generated spline placement.

- every `NativeSplinePlacementRequest` now preserves whether its source segment is a **bridge**, **tunnel**, and its **layer**;
- placement results expose bridge, tunnel, and non-zero-layer request counts;
- two segments are no longer merged into a single curve when their `bridge/tunnel/layer` states are incompatible;
- automatic-generation diagnostics now record `bridgeRequests`, `tunnelRequests`, and `layeredRequests`;
- this stage deliberately does **not** apply an arbitrary fixed vertical offset, avoiding fake steps at bridge/tunnel portals;
- Renderer regression tests validate real metadata propagation and grade-transition merge protection.

This provides the foundation for automatic bridge/tunnel asset selection and ramp/elevation planning without deforming terrain underneath grade-separated roads.
