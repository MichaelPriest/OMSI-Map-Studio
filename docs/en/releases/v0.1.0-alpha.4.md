# OMSI Map Studio v0.1.0-alpha.4

Fourth testable OMSI Map Studio prerelease, focused on the editing UI, visual selection, asset library, and fullscreen workflow.

## Highlights

- new editor visual language inspired by modern city-building tools while keeping Map Studio's own identity;
- original Map Studio SVG icon pack applied across navigation, tools, Library, Inspector, viewport, and diagnostics;
- reorganized fullscreen mode with categories, compact tools, and movable panels;
- redesigned Explorer and Inspector to preserve more viewport space and clarify the active item;
- `.sco` and `.sli` Library with visual cards, real thumbnails generated by the editor, favorites, recent items, most-used items, and collections;
- larger real 3D asset preview;
- Inspector tabs for properties, transform, geometry, materials, path, and profile;
- standardized copy, delete, save, terrain-level, link-edit, discard, and preview actions;
- object and spline selection with a stronger active outline and visually distinct hover state;
- compact viewport selection card showing the selected item, active tool, and Snap state;
- slightly larger Babylon gizmos for easier axis acquisition without changing transform math;
- clearer visual hierarchy for tile grid, active spline, and active tile;
- compact desktop controls for camera, Snap, and layers;
- collapsible technical selection diagnostics to preserve editing space;
- automatic streaming, local Asset Index, construction tools, and preservation-safe editing remain connected to the same real C# host state.

## Safety and real data

Alpha.4 keeps the no-production-mocks principle. Assets, geometry, textures, splines, terrain, selection, previews, and persistence remain based on real OMSI content loaded by the application.

Preservation-safe writes continue to use element validation, backup, and safe file replacement where supported.

## Validation

Before preparing this version, CI passed:

- Core tests;
- UI dependency installation;
- TypeScript/Vite build;
- .NET 10 desktop host build.

See `docs/en/TESTING.md` for the in-OMSI functional validation checklist.
