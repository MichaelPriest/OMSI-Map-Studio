# OMSI Map Studio v0.2.0-alpha.5-test.10.19-native

Build **ALPHA 5 TEST 10.19 — tile cache for lighter 3×3 navigation**.

## Reusing overlapping tiles

In performance mode, moving from one 3×3 region to a neighboring region normally leaves **6 of the 9 tiles unchanged**.

Before this Test, those tiles were read from disk again. Full tile content can now be reused when its source files remain unchanged.

## Safe invalidation

The tile cache fingerprint tracks:

- the `.map` file;
- `.terrain`;
- `.water`;
- `.terrain_0.rdy`;
- tile-specific `.dds` masks under `texture/map`.

If any dependency changes, appears, or disappears, the cached tile is invalidated and read normally again.

## Bounded memory

The cache keeps up to **32 recent tiles** per session and evicts least-recently-used entries.

Editing paths continue to read directly after writes. The cache is used by map open/region navigation to reduce repeated I/O without delaying visible edit results.
