# OMSI Map Studio v0.2.0-alpha.5-test.10.113-native

## Test 10.113 — responsive real-map wizard + OSM fallback

This build reorganizes the Create real map window, which had become too dense and could be clipped on smaller displays.

### New window organization

The workflow is now split into four pages inside the same floating window:

1. Area — folder, name, search, selection size and a large map;
2. Sources — basemap, CARTO, Open-Meteo/Google elevation and visual evidence;
3. Reconstruction — OSM mode, library/assets and Create + reconstruct;
4. Progress — status, cancellation, result and errors.

The window now fits itself to the available workspace when opened, supports a smaller footprint, and uses vertical scrolling on configuration pages. Full reconstruction automatically switches the wizard to Progress.

Long error messages now live in a height-limited scroll area instead of pushing the rest of the interface off screen.

### OpenStreetMap / Overpass

The fallback rotation now uses three distinct global backends:

- overpass-api.de;
- VK Maps / maps.mail.ru;
- Private.coffee.

overpass.kumi.systems was removed from the rotation because it is the former name of the Private.coffee infrastructure and did not provide real fallback diversity.

Per-request timeouts, smaller chunks, the two-request concurrency limit, subdivision recovery, per-chunk progress, cancellation and rollback remain enabled.
