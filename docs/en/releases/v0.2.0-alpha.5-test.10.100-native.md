# OMSI Map Studio v0.2.0-alpha.5-test.10.100-native

## Test 10.100 — Google Elevation integrated into the Core pipeline

A Google elevation backend already existed in the native host for manual single-tile terrain editing. DEM download is now promoted into Core and can directly feed the complete real-world map pipeline.

### Elevation client

`MapStudioGoogleElevationSurfaceClient`:

- accepts south/west/north/east bounds;
- builds a configurable grid;
- sends coordinates in batches of up to 64 locations;
- validates HTTP, API status and result counts;
- directly returns a `MapStudioGeoreferencedElevationSurface`;
- uses the returned minimum altitude as the local datum by default;
- reports progress by completed samples.

### Automatic pipeline

New entry point:

`RunAutoIndexedWithGoogleElevationAsync`

It performs:

1. OMSI asset indexing;
2. Google Elevation grid download;
3. unified OSM download;
4. real terrain application;
5. roads and gradients;
6. junctions;
7. buildings, vegetation, infrastructure and street furniture.

The new progress stage is `DownloadingElevation`.

### Tests

- north-to-south grid ordering;
- resulting surface interpolation;
- grids larger than 64 samples split across multiple requests;
- `REQUEST_DENIED` handling.
