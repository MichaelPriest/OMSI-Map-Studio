# OMSI Map Studio v0.2.0-alpha.5-test.10.88-native

## Test 10.88 — batch OSM vegetation with real OMSI assets

This preview connects point trees and shrubs from OpenStreetMap to the transactional scenery pipeline.

### Asset selection

The runner reuses the OMSI asset library/index:

- only scenery objects classified as vegetation are considered;
- species, genus and leaf type influence the best asset match;
- generic tree/shrub tokens provide fallback selection;
- no synthetic asset is invented when the installation has no valid option;
- stale index entries pointing to missing files are reported as missing assets.

### Confidence

Only vegetation reaching the automatic-generation threshold is placed.

Detailed OSM trees with species/genus metadata can be generated automatically. Generic points and lower-confidence shrubs remain under review.

### Placement

- geographic projection into world coordinates;
- stable ID-based rotation to reduce visual repetition;
- collision-free global IDs;
- tile grouping;
- backup and rollback through the shared writer from Test 10.87.

### Tests

- Tipuana tree metadata selecting a real Tipuana OMSI asset;
- global ID accounting for another tile;
- generic tree remaining under review;
- shrub remaining under review below the confidence threshold;
- missing asset reported without modifying the map.
