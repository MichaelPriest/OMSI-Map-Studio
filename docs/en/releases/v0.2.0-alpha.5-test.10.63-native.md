# OMSI Map Studio v0.2.0-alpha.5-test.10.63-native

## Test 10.63 — automatic Road Kit bridge and tunnel assets

This preview turns the Test 10.62 `bridge/tunnel` metadata into real structural splines.

- each standard drivable road profile now has **base**, **bridge**, and **tunnel** variants;
- the Road Kit grows from 10 to 28 generated splines;
- bridge variants add an underside structure and side guards;
- tunnel variants add side walls and a roof;
- structural surfaces reuse the Road Kit's generated gray material;
- OSM placement automatically selects `*_bridge.sli` or `*_tunnel.sli`;
- external/custom splines remain untouched;
- base traffic/pedestrian paths are preserved;
- Road Kit is updated to **1.3.0**;
- tests load the variants through the real OMSI reader and validate automatic Renderer selection.

Vertical elevation and approach ramps remain separate in this step to avoid arbitrary offsets.
