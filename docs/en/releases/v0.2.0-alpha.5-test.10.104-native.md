# OMSI Map Studio v0.2.0-alpha.5-test.10.104-native

## Test 10.104 — WinUI automatic real-world generation panel

Real-world generation now has a reusable visual control for the native interface.

### Panel

`RealWorldGenerationPanel` displays:

- current stage;
- status message;
- OMSI library examined/candidate counts;
- Google Elevation progress;
- Cancel button;
- final summary;
- session backup path.

### Integration

The panel directly consumes the `RealWorldGenerationViewModel` introduced in Test 10.103.

It exposes simple methods:

- `StartAsync`;
- `Cancel`;
- `Reset`.

The `MainWindow` can therefore host the control without duplicating pipeline or progress logic.

### UI thread

ViewModel changes are forwarded through `DispatcherQueue` when they arrive outside the WinUI thread.

This allows asset indexing, elevation download and scenery-generation progress to safely update the panel.
