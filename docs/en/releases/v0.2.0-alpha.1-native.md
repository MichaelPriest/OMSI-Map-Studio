# OMSI Map Studio v0.2.0-alpha.1-native

First public test prerelease of the new **WinUI 3 + Direct3D 11** architecture.

It installs separately as **OMSI Map Studio Native Preview** and does not replace the existing React/WebView2 build.

## Available for testing

- open a real OMSI installation and maps;
- native Direct3D 11 viewport;
- perspective camera, orbit, pan and zoom;
- OMSI terrain with elevation;
- real SCO/O3D objects;
- splines using real SLI profiles;
- depth buffer and ID Buffer;
- blue hover and red selection;
- physical-pixel/DPI-aware picking;
- native move and rotate gizmos;
- movement and rotation snapping;
- editable native Inspector;
- transform Undo/Redo;
- transactional save with backups;
- native Explorer;
- SQLite-backed asset library;
- SCO/O3D and SLI 3D previews;
- SCO object placement on terrain;
- straight and curved spline construction;
- snapping to existing spline endpoints;
- sequential construction and segment linking.

## Preview limitations

This is not yet a complete replacement for either the React editor or the original OMSI editor. Advanced terrain editing, complete textures/materials, advanced deletion/copy operations, procedural tools, geodata/real-map tools, Map Health, and several OMSI operational editing systems still need to be migrated.

Prefer testing on copies of maps. Implemented writes use safe backups, but this remains an alpha build.
