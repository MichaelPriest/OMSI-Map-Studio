# OMSI Map Studio v0.2.0-alpha.5-test.10.76-native

## Test 10.76 — terrain-adaptive tunnel mouths

This preview improves the terrain/portal/structural-lining transition without deforming the map.

- the portal planner now samples real terrain on both sides of each tunnel mouth;
- left and right retaining wings receive independent heights based on the slope;
- heights are quantized in **0.50 m** increments so generated assets can be reused;
- portal geometry now creates asymmetric wings plus small upper retaining shoulders;
- asset names encode width + left/right heights for safe caching/reuse;
- a minimum height avoids visually weak portals on flat terrain;
- a maximum height prevents exaggerated geometry on extreme relief;
- terrain probes crossing into unavailable terrain fall back to center height instead of treating missing data as zero;
- the main opening remains aligned to the Road Kit 1.5.0 **4.50 m** clearance;
- no `.terrain` file is modified;
- Core/Renderer regressions cover asymmetric geometry, real slope sampling and terrain preservation.

Next steps: extend retaining wings according to slope direction, add optional drainage/lighting and improve terrain-over-roof visual transition.
