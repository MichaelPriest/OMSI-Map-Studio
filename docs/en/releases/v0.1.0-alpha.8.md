# OMSI Map Studio v0.1.0-alpha.8

Test prerelease focused on another structural fix for the **viewport selector**.

## Selector

Alpha.8 adds a second selection path independent from Babylon triangle raycasting:

- real OMSI mesh bounding boxes are projected directly into CSS viewport coordinates;
- the pointer is tested against the projected visual area of the mesh;
- this removes differences between Windows DPI, WebView2 and internal framebuffer resolution;
- objects can be selected by clicking a facade, roof, pole, tree or another visible part;
- for splines, the real axis is projected to screen space and pointer-to-segment distance is calculated in pixels;
- real raycasting remains the first priority;
- visual-volume and geometric fallbacks remain available for incomplete/protected assets;
- selection is now committed on **left-button press**, using pointer capture;
- hovered items remain blue and selected items red;
- clicking empty space still clears selection.

## Explorer/Libraries

Keeps the Alpha.7 improvements:

- automatic sizing by content and resolution;
- manual resizing;
- locally persisted size;
- double-click on the resize handle to restore automatic sizing;
- larger typography.

## Version identification

The application footer now shows the real build version, fixing the old hard-coded `alpha.3` text.
