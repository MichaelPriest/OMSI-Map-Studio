# OMSI Map Studio v0.2.0-alpha.5-test.10.61-native

## Test 10.61 — sidewalk continuity at junction mouths

This preview fixes the visual transition between Road Kit roads with sidewalks and procedural junctions.

- total road width is still used for the junction footprint and physical fit;
- actual carriageway width is derived from `LaneCount × LaneWidth`;
- when total width exceeds carriageway width, the remaining width is treated as side sidewalk space;
- each road mouth receives two sidewalk surfaces, one on each side of the carriageway;
- sidewalk overlays sit slightly above asphalt and below lane markings to avoid z-fighting;
- when Road Kit is installed, junctions reuse `ms_sidewalk.bmp`;
- otherwise a compatible generated sidewalk texture is created automatically;
- roads whose total width equals carriageway width do not receive fake sidewalk overlays;
- Core regression coverage validates sidewalk triangle generation;
- Renderer coverage validates Road Kit sidewalk texture reuse.

This removes the visual break where a spline sidewalk abruptly turned into asphalt at the junction mouth.
