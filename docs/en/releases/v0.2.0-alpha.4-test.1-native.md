# OMSI Map Studio v0.2.0-alpha.4-test.1-native

**TEST** build of the new native WinUI 3 + Direct3D 11 architecture.

This release is intended to validate what has already been migrated from the React/WebView2 version into the native host. It **does not fully replace the OMSI Editor yet**, and PR #3 remains DRAFT and unmerged.

## What to test

- opening the OMSI 2 installation and maps;
- full-map loading and 3×3 performance mode;
- tile navigation;
- perspective and top cameras;
- native ID-buffer selection;
- focus selection and fit map;
- object, spline, and terrain selection filters;
- move/rotate gizmos and snapping;
- numeric Inspector;
- saving changes with backup;
- transform undo/redo;
- Explorer and asset library;
- 3D asset preview;
- placement of real SCO objects;
- straight/curved SLI construction and continuous segments;
- spline endpoint snapping;
- Previous/Next link editing;
- object/spline delete and copy;
- terrain leveling and painting;
- real O3D textures;
- real SLI spline textures;
- terrain base texture and painted layers;
- terrain detail texture;
- OMSI day/night sky;
- SCO night/light overrides;
- material transparency/depth;
- grid, guides, and real spline profiles;
- fullscreen and resizable panels;
- migrated viewport shortcuts.

- `Q` select;

- `E` rotate;
- `F` focus selection;

- `2` top;
- `N` snap;
- `T` terrain;

- `L` splines;

- `Ctrl+D` copy;
- `F11` fullscreen.

## Not complete yet

Full migration and OMSI Editor parity still require advanced tile/terrain tools, paths/traffic, public transport, signals/rail, environment/chronology, geodata/DEM, and complete Map Health diagnostics.

Global asset replacement/dependency repair is being migrated after this build and **is not included in this TEST**.

## Installation

Native Preview installs separately from the React/WebView2 version at:

`%LOCALAPPDATA%\Programs\OMSI Map Studio Native Preview`

The installer includes its own uninstaller.

A portable ZIP is also published.

## Startup diagnostics

If the application does not open after installation, send:

`%LOCALAPPDATA%\OMSI Map Studio Native Preview\Logs\startup.log`

## File safety

Migrated write operations use `.mapstudio-backups` plus `MapStudio.Core` safe transactions.

Because this is still a TEST build, validate editing workflows on a copy of a map first.
