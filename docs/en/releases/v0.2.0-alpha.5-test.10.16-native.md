# OMSI Map Studio v0.2.0-alpha.5-test.10.16-native

Build **ALPHA 5 TEST 10.16 — compact UI, real-map 403 fix, direct AI credential and asset flow**.

## More compact editor

The native editor now uses less screen space:

- smaller main map tools;
- shorter toolbar;
- more compact explorer mode buttons;
- shorter status bar;
- smaller AI assistant window;
- smaller Asset Library;
- smaller real-map area window;
- smaller Asset Library cards.

The goal is to give the viewport more room without removing functionality.

## Real-map 403 fix

The embedded area picker no longer uses the public `tile.openstreetmap.org` raster endpoint directly, which was returning **403 Access blocked** in WebView.

The interactive basemap now uses **CARTO with OpenStreetMap data**, keyless, with proper attribution.

The terrain reference overlay also uses the same CARTO/OSM source with a separate cache.

Vector road data still comes from OpenStreetMap/Overpass.

## AI assistant

The floating AI panel now directly exposes:

- **Token / API key**;
- **Save**;
- **Clear**.

The credential is stored in Windows Credential Manager for the active profile. Opening the Providers dialog is no longer required just to update the key.

## Map assets

The real-map creation flow now explicitly exposes:

- **+ Asset folder**;
- **Open Library**;
- **Open Library after creation**, enabled by default.

After the map is created the Asset Library can open automatically. Select an SCO/SLI and use **+ Place on map** to insert it into the viewport.

## Carried forward

This Test includes every 10.15 navigation improvement:

- compositor-frame pointer coalescing;
- stable absolute pan;
- deferred picking during navigation;
- no gizmo rebuild on every camera move;
- real EXE startup smoke test.
