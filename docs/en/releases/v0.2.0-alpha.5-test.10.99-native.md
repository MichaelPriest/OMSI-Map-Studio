# OMSI Map Studio v0.2.0-alpha.5-test.10.99-native

## Test 10.99 — DEM-driven real road gradients

Test 10.98 moved road splines to the correct starting elevation, but a segment could still remain flat between endpoints at different heights.

This preview uses OMSI's native spline gradient fields to follow the terrain profile.

### Calculation

For every road segment:

1. sample DEM height at the start;
2. sample DEM height at the end;
3. calculate percent grade: `(endHeight - startHeight) / length * 100`;
4. write the value to both `GradientStart` and `GradientEnd`, producing a constant grade between endpoints.

### OMSI coordinates

The runner explicitly preserves OMSI's native `X, Z, Y` field order together with the starting height and gradient.

The round-trip regression introduced in Test 10.98 continues to ensure local Z is never confused with vertical Y.

### Result

Uphill/downhill roads now follow the DEM between OSM nodes rather than using only the starting elevation.

Junctions remain positioned from the DEM height at their own node.
