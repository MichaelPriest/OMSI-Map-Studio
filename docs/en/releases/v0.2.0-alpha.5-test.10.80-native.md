# OMSI Map Studio v0.2.0-alpha.5-test.10.80-native

## Test 10.80 — OSM building reconstruction with street-image refinement

This preview connects the existing OSM building infrastructure to the new **Real World Reconstruction** pipeline.

### Implemented

- each `MapStudioProjectedBuildingFootprint` can now become a reconstruction-planner candidate;
- the candidate preserves the real OSM ID/footprint;
- width and depth are measured from the projected footprint;
- total height includes wall + roof;
- OSM confidence increases when levels, height, roof, type and address metadata are available;
- strong OSM evidence can already cross the automatic-generation threshold;
- a new street-level building refiner was added;
- high-confidence analyses may update:
  - floor count;
  - total height;
  - roof type;
  - roof height;
- footprint and geographic center remain **immutable** during refinement;
- analyses below the confidence threshold cannot overwrite existing geometry;
- minimum street-image refinement confidence: **0.82**.

### Geometry safety

Reference imagery cannot automatically move or resize the OSM footprint. At this stage it only refines vertical and architectural attributes.

### Tests

Regression coverage was added for:

- footprint-derived dimensions;
- strong OSM evidence;
- height/roof refinement while preserving the footprint;
- rejection of low-confidence visual analysis.
