# OMSI Map Studio v0.2.0-alpha.5-test.10.10-native

Build **ALPHA 5 TEST 10.10 — visual ghost, selectable AI, OSM/Google map reference and Auto connect**.

## Visible item while moving/rotating

Move and Rotate now display a **filled ghost of the selected item's real geometry** following the pointer.

- the original stays at the starting position during preview;
- the ghost follows Move and Rotate in real time;
- releasing applies the transform;
- works with objects and splines;
- Inspector is not required.

## AI profile selector

The top toolbar now includes an **AI Profile** selector.

- choose the active profile directly;
- selection is persisted immediately;
- the **AI** button tests the active profile;
- reopening provider settings is no longer required just to switch profiles.

## Map reference

Under **Map → Map reference over terrain...**:

- **OpenStreetMap** is the default and requires no key;
- only the required tile is downloaded on demand;
- local cache is kept for at least 7 days;
- requests identify OMSI Map Studio with a User-Agent;
- **© OpenStreetMap contributors** attribution remains visible in the viewport;
- **Google Maps** remains available through Maps Static API;
- the user's Google key can be stored in Windows Credential Manager;
- the saved key can also be reused by Google Elevation.

No private Google API key is embedded in Map Studio.

## Road / spline Auto connect

A new **Auto connect** command is available in the Roads bar.

For the selected spline it:

- searches nearby endpoints using snap distance;
- fills missing Previous/Next links;
- detects neighbor IDs that no longer exist;
- replaces broken links with valid nearby connections;
- updates reciprocal neighbor links;
- preserves valid connections;
- creates a backup before writing.

New spline insertion also treats broken links as repairable.

## Project panel

The visual summary card containing map name, root and load mode was removed from Project to free space.

Tile navigation and New/Open/Import/+Assets remain available.
