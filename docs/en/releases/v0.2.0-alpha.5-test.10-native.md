# OMSI Map Studio v0.2.0-alpha.5-test.10-native

Build **ALPHA 5 TEST 10 — Adaptive UI + OMSI-style Paths + Library performance** for the WinUI 3 + Direct3D 11 architecture.

This prerelease packages the UI, performance and traffic-path visualization work completed after Test 9.

## UI and windows

- **Windows light/dark theme** support;
- high-contrast resources;
- large dialogs adapt to the available area and scroll instead of clipping;
- Main and Timetable windows respect the monitor work area;
- **Project** and **Inspector** panels can be minimized/restored;
- translucent side panels;
- restore shortcuts appear over the viewport when panels are collapsed;
- the **Tiles** shortcut was moved out of Project into the global top toolbar;
- Project is now organized as **Scene / Assets / Transport**.

## Asset library

- cached global asset index;
- **All / SCO / SLI / Models / Textures** switching is performed in memory;
- reduced cascading `SelectionChanged` work;
- thumbnails are loaded only for realized/visible tiles;
- short search debounce avoids rebuilding the grid on every keystroke;
- primary goal: reduce UI stalls while switching asset type.

## OMSI-style traffic paths

- paths are no longer thin lines only;
- translucent ribbon/strip over roads and sidewalks;
- type colors:
  - red **CAR**;
  - light **HUM**;
  - cyan **RAIL**;
  - violet **AIR**;
- repeated direction arrows along the path;
- border/center lines for contrast on bright and dark textures;
- focused path is wider and highlighted;
- visible **start/end nodes**;
- repeated `CAR`, `HUM`, `RAIL`, `AIR` labels;
- optional **Nodes** and **Labels** toggles;
- clicking an endpoint selects its SCO/SLI owner, isolates the path and focuses its index;
- node hit-testing is screen-space based to keep normal D3D picking lightweight.
