# OMSI Map Studio v0.2.0-alpha.5-test.10.58-native

## Test 10.58 — live terrain-follow-road preview

This preview completes the visual stage of the **terrain follows road** workflow.

- selecting a spline shows the affected band before anything is persisted;
- a cyan centerline follows the real straight or curved spline geometry;
- white lines show the main road-underlay boundaries;
- outer cyan lines show the total influence including transition/feather;
- preview uses the spline's real height, start/end gradients, radius and rotation;
- vertical terrain offset is represented as well;
- changing **half width**, **transition**, or **vertical offset** refreshes the preview immediately;
- the overlay reprojects during pan, orbit, zoom, resize and DPI changes;
- no `.terrain` file is changed until **Follow road** is applied;
- Core regression coverage verifies centerline, road width and feather in world space.
