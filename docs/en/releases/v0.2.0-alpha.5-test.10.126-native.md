# OMSI Map Studio v0.2.0-alpha.5-test.10.126-native

## Test 10.126 — deeper manual-tools audit

This build continues the audit started in 10.124 and fixes cases where a tool could exist in code but remain hidden or appear empty in the Library.

### Manual tools are directly reachable

These main toolbar buttons are no longer permanently `Collapsed`:

- **Tunnels**;
- **Stops / Transit Assets**;
- **Infrastructure / Utilities**.

Existing alternate entry points remain available, while all three tools can now also be opened directly from the main toolbar.

### Portuguese asset classification

The Library now recognizes Portuguese asset names that could previously fall into **Other**:

- transit: `ponto`, `parada`, `abrigo`, `garagem`, `estacao`;
- utilities: `energia`, `agua`, `saneamento`, `esgoto`, `infraestrutura`;
- tunnels: `tunel`.

Regression cases were also added for **Stops / shelters**, **Water / sanitation**, and **Tunnels** subcategories.

### End-to-end persistence checked

The audit verified start → interaction → write → reload for the remaining focus areas:

- Transit Assets/Utilities scenery placement → real `.map` write through `OmsiTileObjectInserter`, transactional save and tile reload;
- spline/tunnel placement → real `.map` write through `OmsiTileSplineInserter`, transactional save and reload;
- tunnel generator → real `.sli`, textures, backup and read-back by `OmsiSplineDefinitionReader`;
- junction target → SCO placement → real tile commit;
- Track → `.ttr` + backup + reload;
- StationLink → `StnLinks.cfg` + backup + reload;
- traffic-light program → `.sco` + backup + reload;
- SCO/SLI paths → real asset patch + backup + reload;
- Validation remains an analysis tool; repair actions continue through real writers.

### Regression protection

Native Windows CI and Native Preview Release now fail if Tunnels, Transit Assets, Utilities or Validation become permanently hidden again, or if persistence/reload wiring disappears.
