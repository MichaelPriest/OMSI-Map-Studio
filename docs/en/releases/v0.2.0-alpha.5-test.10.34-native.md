# OMSI Map Studio v0.2.0-alpha.5-test.10.34-native

Native preview focused on **physical road scale** and consistent use of the Map Studio **standard Road Kit assets**.

## Physical scale

The editor keeps OMSI scale:

- 1 tile = 300 × 300 m;
- 1 spline width unit = 1 meter in OMSI world space;
- OSM metadata is used to select the most appropriate standard profile;
- after selection, persisted width, lanes and direction follow the chosen asset so visual geometry and junction geometry cannot disagree.

## Road Kit 1.1

The standard profile catalog is now shared by generation and automatic import instead of duplicating physical values across the codebase.

New profiles:

- compact local road: 5.5 m carriageway;
- local road with sidewalks: 5.5 m carriageway + 1.5 m sidewalk on each side = 8.5 m total.

Existing standard profiles remain available for one-way roads, 7 m roads, avenues, divided avenues and pedestrian paths.

## Improved OSM classification

- `service` and `track` prefer the compact local-road asset;
- `residential`, `living_street` and `unclassified` prefer the local-road-with-sidewalk asset unless metadata indicates a larger road;
- tertiary/secondary roads use intermediate profiles;
- primary roads become avenues only when lanes/width justify it;
- one-way roads use dedicated one-way assets based on lanes/width;
- non-one-way motorway/trunk roads use the divided avenue.

## Junctions

Generated junctions now use the **actual carriageway width of the selected asset**, not the total surface width including sidewalks.
