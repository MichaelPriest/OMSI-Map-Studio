# OMSI Map Studio v0.2.0-alpha.5-test.10.72-native

## Test 10.72 — richer structural guard rails for bridges

This preview improves the structural appearance of automatically generated Road Kit `_bridge.sli` variants.

- Road Kit upgraded to **1.4.0**;
- new procedural `ms_guardrail.bmp` texture generated by Map Studio itself;
- the deck keeps its approximately **30 cm** structural underside;
- deck sides now close the fascia up to the guard-rail base;
- each side gains a concrete curb/base with real profile thickness;
- each side gains **two longitudinal metal rails** with a closed section instead of relying only on a simple vertical wall;
- geometry remains a real OMSI spline and preserves curves, traffic paths and automatic `bridge/layer` selection;
- no external asset dependency was introduced;
- no `.terrain` file is modified;
- Core regression coverage validates the dedicated texture, increased surface geometry and structural rail height.

The next structural iteration is intended to add automatic piers based on span/height and tunnel portals at transition boundaries.
