# OMSI Map Studio v0.2.0-alpha.5-test.10.112-native

## Test 10.112 — final build for coordinate and OSM-timeout validation

This build supersedes 10.111 for real testing. The 10.111 publication hit a workflow race: its tag was created by an intermediate SHA and its assets were later refreshed by the final SHA. Test 10.112 is published cleanly and adds a guard so this cannot silently happen again.

### Priority fixes included

- removed the global 120-second OpenStreetMap import deadline;
- each endpoint attempt keeps its own 20-second timeout;
- OSM chunks target roughly 750 m;
- no more than two Overpass HTTP calls are active at once;
- the four recovery subchunks may advance concurrently under the same global limit;
- endpoint fallback remains enabled;
- user cancellation still propagates through requests and the pipeline;
- per-chunk progress is surfaced during the OpenStreetMap stage;
- existing rollback behavior is preserved.

### Coordinate audit

- latitude/longitude -> world X/Z projection;
- world -> OMSI 300 m tile ownership;
- world -> local conversion only when persisting;
- renderer local -> world reconstruction adds tile origin exactly once;
- terrain-relative objects store zero vertical offset and receive DEM once;
- splines use the OMSI vertical field without a second DEM addition;
- generated building and infrastructure assets use geometry local to their object center.

A multi-tile regression covers negative, central and positive tiles and rejects placements outside the physical map bounding box.

### Release integrity

The preview workflow now refuses to clobber an existing release when its tag SHA differs from the current workflow SHA. This prevents tags and binaries from silently representing different commits.

All prior regressions and smoke tests remain enabled; no test coverage was weakened.
