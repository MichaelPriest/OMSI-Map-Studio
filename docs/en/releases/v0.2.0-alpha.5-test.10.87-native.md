# OMSI Map Studio v0.2.0-alpha.5-test.10.87-native

## Test 10.87 — batch OSM buildings into the OMSI map

This preview extends the automatic transactional pipeline from Test 10.86 to real-world buildings.

### Shared scenery writer

A generic writer now handles Map Studio generated scenery assets:

- reads the map and tiles once;
- finds the highest used ID across objects, attachments and splines;
- automatically selects the tile from world coordinates;
- converts to local OMSI coordinates;
- groups multiple objects per tile with `AppendMany`;
- creates one backup per modified tile;
- uses temporary writes and rollback on failure.

The component is reusable for buildings, vegetation, street furniture and other generated scenery.

### Building reconstruction

A new batch runner performs:

`OSM building -> footprint -> projection -> confidence -> O3D/SCO -> scenery batch writer`

Buildings with strong OSM evidence are generated and inserted automatically. Generic buildings with insufficient evidence remain under review.
