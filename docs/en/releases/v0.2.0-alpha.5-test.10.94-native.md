# OMSI Map Studio v0.2.0-alpha.5-test.10.94-native

## Test 10.94 — physical junctions in the real-road pipeline

Test 10.93 moved OSM road generation into Core. This preview also materializes intersections detected by the same graph.

### Generation

For every real junction with at least three road arms:

- connected graph segments become junction arms;
- angles come from OSM geometry;
- width uses the larger of OSM metadata and the physical Road Kit profile width;
- lane count and one-way metadata are preserved;
- pedestrian profiles do not create road junction arms;
- junctions fully on bridges/tunnels preserve the structural kind.

Assets are created by `MapStudioJunctionAssetGenerator`, including geometry, markings and internal traffic paths, then placed through the transactional scenery writer.

### Safety

If any junction generation or placement fails after road splines were written, road tiles are restored from the batch backups.

### Complete pipeline

`MapStudioRealWorldMapPipeline.PlacedElementCount` now includes:

- road splines;
- physical junctions;
- reconstructed scenery objects.

### Test

An OSM crossing made from two ways sharing one node must produce:

- a junction candidate;
- a real SCO/O3D junction asset;
- an object placed into the tile;
- road splines preserved in the same map.
