# OMSI Map Studio v0.2.0-alpha.5-test.10.125-native

## Test 10.125 — manual tools audit closure

Test 10.125 includes the 10.124 audit and closes the last accessibility issue found in the manual editor surface.

### Map validation is now accessible

The **Validate** module already had real implementation for checking:

- SCO/SLI dependencies;
- broken references;
- TTData;
- links;
- map structure;
- validation errors and warnings.

However, its main button was `Collapsed` and there was no equivalent access path. The **Validate** button is now visible on the editor tool rail.

### Audit result

The complete button → viewport → session → persistence/backup cycle was reviewed for:

- selection, move, rotate, focus, duplicate and delete;
- scenery objects and placement patterns;
- roads/splines: straight, curve, endpoint editing, split, join, parallel, snap, continuous and links;
- raise, lower, level and terrain-follow road controls;
- mirror, reverse flow and replace type;
- bridges and tunnels;
- buildings and Building Studio;
- vegetation item/line/area/Custom Shape;
- junction detection and placement target;
- terrain point/level/raise/lower/ground texture/Custom Shape;
- water;
- Traffic Rules, signals and signal programs;
- SCO/SLI `[path]` create/edit/duplicate/delete;
- Route Studio / TTData: Track, Trip, Stop, StationLink, Line, profiles, path recording, removal and reordering;
- tiles, Inspector and validation.

### Audit fixes carried forward

- **Roads → Terrain** also works on the currently selected spline;
- **Copy/Duplicate** works on `[worldcoordinates]` maps;
- manual traffic-signal search uses multilingual synonyms;
- **Validate** is no longer hidden.
