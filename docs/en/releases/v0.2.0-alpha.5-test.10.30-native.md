# OMSI Map Studio v0.2.0-alpha.5-test.10.30-native

Native preview focused on advanced curve/radius editing directly in the viewport.

## Visual curve handle

**Edit curve** now uses a real yellow handle instead of making the curve follow every mouse movement.

- yellow handle located at the curve's lateral offset;
- click the handle to begin editing;
- drag sideways to increase/decrease curvature;
- release to apply;
- movement along the road axis is ignored: the handle controls lateral sagitta/offset only;
- radius is recalculated continuously;
- live status shows radius and offset;
- with Snap enabled, offset uses the same 0.25 m move step;
- dragging the handle to the center straightens the segment;
- dragging across the center reverses curve direction;
- uses the existing real transform-edit/undo/redo path.
