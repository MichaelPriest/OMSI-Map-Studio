# OMSI Map Studio v0.2.0-alpha.5-test.10.14-native

Build **ALPHA 5 TEST 10.14 — smoother and lighter map navigation**.

This Test prioritizes the reported viewport stutter and bottleneck during pan/orbit.

## Stable pan

The previous grab-pan path recalculated the pointer world point using an already-moved camera and compared it with the point captured before movement. That feedback could introduce small oscillations while dragging.

Pan now:

- captures the camera state when the gesture starts;
- captures the initial pixel;
- restores the mathematical start state for each update;
- computes total pixel displacement from the gesture start;
- applies pan once from that stable base.

Successive pointer events therefore do not accumulate navigation error, while the map still follows the cursor naturally.

## Less work per navigation frame

During pan and orbit, the viewport no longer redraws the complete picking surface every frame.

Picking is refreshed when navigation ends.

The hot path also no longer performs:

- gizmo geometry rebuild on every camera movement;
- gizmo/picking GPU buffer recreation while panning;
- coordinate/status text updates for every dragged pixel.

Gizmos are still refreshed when actually required, such as zoom, selection, or manipulation changes.

## Regression protection

Tests now cover:

- absolute pan not accumulating previous events;
- natural grab direction;
- visual-only rendering during navigation;
- picking refresh after the gesture ends.
