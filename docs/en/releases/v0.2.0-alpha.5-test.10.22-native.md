# OMSI Map Studio v0.2.0-alpha.5-test.10.22-native

Build **ALPHA 5 TEST 10.22 — CARTO ground-reference loading fix**.

## Main fix

Fixes a failure when using **Map > Map reference over terrain...** with CARTO that could end with:

`Object reference not set to an instance of an object.`

The downloaded CARTO PNG now:

- validates the PNG signature before entering the cache;
- is converted to a local TGA using the native Windows image decoder;
- is handed to the renderer through the TGA loader already used by Map Studio;
- no longer depends on the renderer's generic WIC path for this reference image.

## Credentials

When a CARTO key is already stored and the input field is left empty, the editor reuses it without needlessly deleting and re-saving the credential.

## Diagnostics

If reference loading still fails, the status bar now reports the exact stage, such as:

- CARTO reference download/conversion;
- credential save;
- overlay geometry creation;
- viewport texture handoff.

## Carried forward

Test 10.21 CARTO key integration, the OSM area-picker fallback, navigation improvements and previous caches remain included.
