# OMSI Map Studio v0.2.0-alpha.5-test.10.108-native

## Test 10.108 — keyless free Open-Meteo/Copernicus elevation

This alpha fixes the Open-Meteo/Copernicus elevation flow so the public free endpoint can be used without requiring an API key.

### Free mode by default

When **Open-Meteo / Copernicus GLO-90** is selected:

- with no saved key, Map Studio uses `https://api.open-meteo.com/v1/elevation`;
- no `apikey` parameter is sent;
- the resulting elevation surface still drives the same terrain, road, junction, bridge, tunnel and scene datum;
- the UI clearly states that the free mode does not require a key.

### Optional commercial key

If an Open-Meteo key is saved in Windows Credential Manager:

- Map Studio uses `https://customer-api.open-meteo.com/v1/elevation`;
- the key is sent only to the customer endpoint;
- the Create real map field is now labeled **Optional commercial Open-Meteo key**.

### Unified behavior

The fix applies to both the one-click **Create + reconstruct** pipeline and the per-tile elevation path in `OmsiNativeSession`, so simple map creation and full reconstruction no longer behave differently.

### Validation

Regression coverage explicitly checks:

- public endpoint usage when the key is null;
- absence of `apikey=` in free mode;
- customer endpoint preservation when a key exists;
- georeferenced surface creation and batching up to 100 coordinates.
