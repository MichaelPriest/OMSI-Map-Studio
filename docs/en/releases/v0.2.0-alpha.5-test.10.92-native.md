# OMSI Map Studio v0.2.0-alpha.5-test.10.92-native

## Test 10.92 — one-call real-world scenery pipeline

This preview joins the unified Overpass capture from Test 10.90 with the coordinated reconstruction session from Test 10.91.

### Core API

The new `MapStudioRealWorldScenePipeline` receives:

- OMSI root;
- map directory;
- geographic bounds;
- real-world map anchor;
- OMSI asset library;
- additional street-level imagery evidence when available.

It executes:

`bounds -> Overpass scene -> unified XML -> coordinated reconstruction -> result`

### Progress

The pipeline exposes UI-ready stages:

1. `DownloadingOpenStreetMap`;
2. `ReconstructingScene`;
3. `Completed`.

This lets the editor loading HUD bind directly to the pipeline without duplicating orchestration logic in WinUI.

### Safety

If the Overpass download fails, map modification never starts.

Once reconstruction begins, the session snapshot/rollback from Test 10.91 remains active.

### Tests

- one call downloading XML and reconstructing building + tree + street light;
- progress events emitted in the correct order;
- final tile containing all generated objects;
- Overpass failure leaving tile bytes unchanged.
