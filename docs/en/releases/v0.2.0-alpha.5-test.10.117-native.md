# OMSI Map Studio v0.2.0-alpha.5-test.10.117-native

## Test 10.117 — official OSM fallback after Overpass failure

Real test evidence showed public Overpass servers returning HTTP 504, HTTP 429 and request timeouts for the same area. Test 10.117 changes the strategy to reduce repeated heavy requests and let generation continue without depending on three identical Overpass retries.

### New download strategy

- primary chunks are reduced to roughly 300 m, matching the physical OMSI tile scale;
- each block tries only one rotated Overpass server at a time;
- the Overpass attempt budget is 12 seconds;
- when it fails, that small block falls back to the official `https://api.openstreetmap.org/api/0.6/map` endpoint;
- the official fallback receives only the bbox for that small block and returns complete OSM XML;
- the same existing road, building, vegetation, furniture and infrastructure filters process that XML;
- if the official fallback also reports excessive area/data, subdivision recovery remains available;
- HTTP 429 marks that Overpass endpoint unavailable for the current recovery branch to avoid immediate repetition;
- tests and integrations that construct the client with custom endpoints and no direct fallback keep the previous behavior.

Physical tile coverage, zero-placement rejection, rollback, animated loading, progress and cancellation remain enabled.
