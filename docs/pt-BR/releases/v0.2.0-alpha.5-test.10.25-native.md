# OMSI Map Studio v0.2.0-alpha.5-test.10.25-native

Build **ALPHA 5 TEST 10.25 — diagnóstico exato e isolamento do download CARTO**.

## Problema observado

Em alguns ambientes, **Mapa > Referência de mapa sobre o terreno...** ainda podia falhar durante `LoadCartoReferenceAsync` com:

`NullReferenceException: Object reference not set to an instance of an object.`

A Test 10.24 já havia protegido georreferência antiga, resposta sem conteúdo e o caminho WIC/PNG, mas o erro ainda podia ocorrer antes do envio da textura ao viewport.

## Correções da Test 10.25

- o download CARTO usa agora um **HttpClient dedicado** para a operação de referência;
- o caminho principal usa `GetByteArrayAsync`, reduzindo dependência de objetos intermediários de `HttpResponseMessage.Content`;
- se ocorrer `NullReferenceException` durante o download, é executado um **segundo caminho HTTP com handler novo**;
- o cache foi movido para `carto-keyed-v2`, evitando reutilizar referência problemática de builds anteriores;
- cada subetapa é identificada:
  - `georeference-load`;
  - `georeference-validation`;
  - `mercator-position`;
  - `cache-path`;
  - `cache-check`;
  - `request-uri`;
  - `http-download`;
  - `http-download-fallback`;
  - `png-validation`;
  - `cache-write`;
  - `reference-metadata`;
- qualquer erro CARTO gera log completo em:
  `%LocalAppData%\OMSI Map Studio\logs\carto-reference.log`;
- a barra de status agora informa o caminho desse diagnóstico quando a referência CARTO falha.

## Mantido

Continuam incluídos:

- decoder PNG próprio do Map Studio;
- fallback WIC protegido;
- chave CARTO no Windows Credential Manager;
- fallback OSM no seletor de área;
- referência visual sem participar do picking;
- melhorias de navegação, streaming e caches anteriores.
