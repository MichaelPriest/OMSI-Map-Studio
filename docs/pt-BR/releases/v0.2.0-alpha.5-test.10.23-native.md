# OMSI Map Studio v0.2.0-alpha.5-test.10.23-native

Build **ALPHA 5 TEST 10.23 — correção definitiva da referência CARTO sobre o terreno**.

## Problema corrigido

Corrige o erro observado ao usar **Mapa > Referência de mapa sobre o terreno...** com CARTO:

`NullReferenceException: Object reference not set to an instance of an object.`

A Test 10.22 anterior ainda tentava converter o PNG CARTO para TGA usando `Windows.Graphics.Imaging`; essa conversão podia retornar objetos nulos em algumas máquinas.

## Novo caminho

A Test 10.23 remove a conversão WinRT/TGA do fluxo CARTO:

- o PNG baixado da CARTO tem a assinatura validada;
- o arquivo PNG validado é entregue diretamente ao renderer;
- o renderer usa um decoder PNG próprio do Map Studio antes do WIC;
- o caminho não depende mais de `BitmapDecoder`/WinRT para a referência CARTO;
- WIC permanece apenas como fallback para outros formatos.

## Testes

Foi adicionado teste de regressão para:

- decodificar PNG RGBA sem WIC;
- rejeitar payload que não seja PNG;
- impedir o retorno da conversão `EnsureReferenceTgaAsync` ao fluxo CARTO.
