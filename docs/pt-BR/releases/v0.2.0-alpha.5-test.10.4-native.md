# OMSI Map Studio v0.2.0-alpha.5-test.10.4-native

Build **ALPHA 5 TEST 10.4 — correção de congelamento do modo Mapa**.

Esta build substitui a Test 10.3 para atacar o congelamento ao abrir **Projeto > Mapa**.

## Correções

- clicar em **Mapa** não executa mais `Viewport.RestoreSceneView()`;
- trocar para Mapa não cancela/reinicializa a cena 3D;
- a agregação e ordenação dos tiles agora roda fora do thread da interface;
- atualizações antigas da lista de tiles são canceladas quando uma nova busca/troca ocorre;
- o último caminho antigo **Mapa > Gerenciador de tiles...** foi removido;
- todas as entradas de Mapa/Tiles agora abrem o painel inline;
- o antigo `ContentDialog` não é mais acionado por nenhum botão/menu da interface;
- erros ao carregar a lista inline são registrados em `startup.log`.

## Layout preservado

- Projeto: **Cena / Assets / Mapa / Transporte**;
- navegação pelo mapa **← ↑ ↓ →** continua fora de Projeto, na barra superior;
- o grip de arrastar painéis/barras permanece;
- Tiles/Mapa permanece dentro de Projeto.

## Validação

O workflow falha se:
- algum XAML voltar a chamar `OnTileManagerClick`;
- o botão Mapa voltar a executar `RestoreSceneView()`;
- a agregação de tiles voltar para o thread da UI;
- o botão global Tiles reaparecer.

PR #3 permanece **DRAFT** e sem merge.
