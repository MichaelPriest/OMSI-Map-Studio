# OMSI Map Studio v0.2.0-alpha.5-test.10.8-native

Build **ALPHA 5 TEST 10.8 - correção do construtor de splines, seleção fácil, IA visível e manual PDF**.

## Correção crítica - Construir spline

Foi corrigido o fluxo principal de criação de ruas por arrasto.

Antes:
- o clique inicial ativava o ponto de partida;
- a prévia acompanhava o mouse;
- ao soltar o botão, o estado de arrasto era limpo sem finalizar a spline.

Agora:
1. selecione uma SLI;
2. clique **Construir spline**;
3. pressione no ponto inicial;
4. arraste vendo a prévia;
5. solte no ponto final;
6. a spline é finalizada e enviada para inserção.

O editor também passa a informar explicitamente quando falta mapa, asset selecionado ou quando a SLI é inválida.

SLIs válidas que não possuem um perfil gráfico renderizável podem usar uma prévia-guia simples durante a construção, em vez de falhar silenciosamente.

## Seleção fácil

- área de picking de objetos e splines ampliada;
- hover com tolerância maior;
- busca de candidatos em uma região circular maior ao redor do cursor;
- quando há itens sobrepostos, clicar novamente praticamente no mesmo ponto alterna entre eles;
- o status informa a posição, por exemplo: `1/3 sobrepostos`;
- faixa de seleção simplificada para Todos, Objetos, Ruas/splines e Terreno/tile.

## IA conectada ao mapa

A conexão não fica mais escondida somente na configuração.

Agora existem:
- botão **IA: conectar** na barra superior;
- **IA > Conectar / testar IA no mapa...**;
- indicação do perfil ativo;
- teste direto do perfil que será usado pelas ferramentas do mapa;
- credencial continua protegida no Windows Credential Manager.

Fluxo:
1. clique **IA: conectar**;
2. escolha/preset o provedor;
3. informe modelo e API key/token;
4. marque o perfil como ativo;
5. teste;
6. salve;
7. clique novamente no botão de IA para validar a conexão ativa no mapa.
