# OMSI Map Studio v0.2.0-alpha.5-test.10.17-native

Build **ALPHA 5 TEST 10.17 — cache derivado de assets e rebuilds mais leves**.

## Cache derivado de assets

O renderer nativo agora reutiliza dados já analisados dos assets OMSI enquanto os arquivos de origem continuam iguais:

- metadata de objetos `.sco`;
- definições de splines `.sli`;
- geometria binária `.o3d`;
- geometria DirectX texto `.x`.

O cache usa fingerprint de arquivo com existência, tamanho e data de modificação. Se o arquivo for alterado externamente, removido ou criado depois, a entrada deixa de ser válida automaticamente.

## Memória controlada

O cache é limitado por LRU para evitar crescimento indefinido:

- metadata SCO: até 512 entradas;
- definições SLI: até 512 entradas;
- geometrias O3D/X: até 1024 entradas.

O objetivo é reduzir parsing repetido em mapas grandes sem manter todos os assets carregados para sempre.

## Rebuilds, previews e posicionamento

Os loaders de scenery e splines agora permanecem vivos durante toda a sessão do `NativeViewportRuntime`.

Isso permite reaproveitar o cache entre:

- rebuilds de cena durante streaming;
- retorno para regiões já visitadas;
- previews da Biblioteca;
- posicionamento repetido de SCO/SLI;
- atualização da cena após operações de edição.

Nenhum formato de mapa foi alterado e o Inspector continua opcional.
