# OMSI Map Studio v0.2.0-alpha.5-test.10.96-native

## Test 10.96 — índice automático de assets no pipeline de mapa real

O pipeline completo agora pode ser chamado sem a interface preparar manualmente uma lista de assets.

### Novo fluxo

`RunAutoIndexedAsync` executa:

1. atualiza o índice persistente da instalação OMSI;
2. carrega apenas scenery objects para a reconstrução;
3. baixa o cenário/vias pelo Overpass;
4. gera vias, junctions e cenário real;
5. mantém os rollbacks transacionais já existentes.

### Cache persistente

O índice é salvo em:

`.mapstudio/cache/assets.sqlite`

Arquivos não alterados são reutilizados nas próximas execuções, evitando reprocessamento desnecessário.

### Progresso

Foi adicionada a etapa `IndexingAssets` ao progresso do pipeline, além de suporte opcional ao progresso detalhado do próprio indexador.

### Testes

- indexa dois scenery objects e um spline;
- retorna apenas os scenery objects necessários ao pipeline;
- cria o banco persistente dentro de `.mapstudio/cache`;
- segunda execução reaproveita os três arquivos como inalterados.
