# OMSI Map Studio v0.2.0-alpha.5-test.10.48-native

Sincronização bidirecional entre viewport e programas de semáforo.

## Mapa → programa

- clicar em um objeto de semáforo enquanto o módulo Tráfego está ativo procura o programa correspondente;
- a associação usa ObjectId e Tile X/Y reais;
- o programa correspondente é selecionado e rolado para a área visível da lista;
- a sincronização evita ciclos quando lista e viewport já apontam para o mesmo programa.

## Programa → mapa

Mantém o comportamento da Test 10.47: selecionar o programa continua selecionando e enquadrando o objeto real correspondente no viewport.
