# OMSI Map Studio v0.2.0-alpha.5-test.10.119-native

## Test 10.119 — filtro de vias dirigíveis e proteção contra splines “espaguete”

A Test 10.119 responde ao teste real da 10.118 em que o download OSM funcionou, porém uma área de apenas 2 tiles resultou em 704 splines e uma malha visual excessivamente carregada.

### Correções principais

- a camada **Vias** não consulta mais qualquer `highway=*`;
- a query OSM foi restrita a classes viárias motorizáveis relevantes ao OMSI:
  - motorway / trunk;
  - primary / secondary / tertiary;
  - links correspondentes;
  - unclassified / residential / living_street;
  - service;
  - road;
  - busway / bus_guideway;
- `footway`, `path`, `steps`, `cycleway` e `track` não viram mais splines de rua automaticamente;
- `service=parking_aisle`, `service=driveway`, `service=drive-through` e `service=emergency_access` são excluídos da reconstrução viária;
- ways com `area=yes` não são interpretados como eixo de rua;
- acessos explicitamente negados a veículos são descartados;
- exceção preservada para corredor/acesso com `bus=yes|designated|permissive`, importante para OMSI;
- o importador repete a filtragem mesmo quando o fallback oficial OSM devolve todo o bbox.

### Proteção geométrica nova

Antes de gravar cada spline, o gerador reconstrói matematicamente seu endpoint a partir de:

`posição inicial + rotação + comprimento`

e compara com o endpoint projetado do OSM.

Se a divergência ultrapassar 2 cm, a geração é abortada e o rollback transacional é acionado. Assim, um erro futuro de rotação, coordenada local ou serialização não deve mais deixar splines disparadas pelo mapa.

### Testes

Foram adicionadas regressões para:

- rejeitar caminhos não motorizados;
- rejeitar estacionamento e driveways como ruas;
- manter corredores exclusivos de ônibus;
- rejeitar proibição explícita a veículos;
- confirmar continuidade física entre splines consecutivas;
- manter todos os testes anteriores sem enfraquecimento.

> Para validar visualmente a Test 10.119, use de preferência um mapa novo ou restaure o backup anterior, pois a geração concluída pela 10.118 já escreveu as 704 splines no mapa testado.
