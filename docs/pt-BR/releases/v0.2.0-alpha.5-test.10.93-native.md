# OMSI Map Studio v0.2.0-alpha.5-test.10.93-native

## Test 10.93 — vias no pipeline completo de mapa real

Esta preview fecha a maior lacuna do pipeline unificado: o XML OSM já continha vias, mas até o Test 10.92 apenas o cenário era materializado pelo Core.

### Vias em lote

O novo `MapStudioRoadBatchReconstructionRunner` executa:

`OSM highway -> projeção -> perfil Road Kit -> grafo -> splines OMSI -> tiles`

Ele preserva:

- número de faixas;
- mão única;
- largura;
- faixas direcionais;
- `layer`;
- ponte;
- túnel;
- topologia OSM como fonte autoritativa.

O perfil físico é escolhido pelo catálogo padrão do Map Studio e variantes de ponte/túnel usam os assets estruturais correspondentes.

### Writer de splines em lote

`OmsiTileSplineInserter.AppendMany` permite inserir todas as splines destinadas a um tile em uma única serialização, mantendo IDs globais sem colisão.

### Pipeline completo

O novo `MapStudioRealWorldMapPipeline` executa em uma chamada:

`bounds -> Overpass unificado -> vias -> cenário -> resultado`

Estágios de progresso:

1. download OSM;
2. geração de vias;
3. reconstrução de cenário;
4. concluído.

Um snapshot externo protege a sessão inteira: se o cenário falhar depois das vias, os tiles retornam ao estado anterior ao início da operação.

### Limite atual

Junction assets e conformação detalhada de elevação ainda continuam no gerador avançado existente e serão incorporados ao pipeline Core nos próximos testes.
