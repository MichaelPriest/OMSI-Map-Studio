# OMSI Map Studio v0.2.0-alpha.5-test.10.112-native

## Test 10.112 — build final para validar coordenadas e timeout OSM

Esta build substitui a 10.111 para teste real. A 10.111 sofreu uma corrida de publicação entre dois workflows: o tag foi criado por um SHA intermediário e os assets foram posteriormente atualizados pelo SHA final. A 10.112 é publicada de forma limpa e inclui uma proteção para impedir que isso volte a acontecer.

### Correções prioritárias incluídas

- removido o deadline global de 120 segundos da importação OpenStreetMap;
- cada tentativa de endpoint continua com timeout próprio de 20 segundos;
- chunks OSM usam alvo de aproximadamente 750 m;
- no máximo duas chamadas HTTP Overpass ficam ativas simultaneamente;
- os quatro subchunks de recuperação podem avançar em paralelo sob esse mesmo limite global;
- fallback entre endpoints permanece ativo;
- cancelamento do usuário continua propagado para requests e pipeline;
- progresso por chunk é exibido no estágio OpenStreetMap;
- rollback existente permanece preservado.

### Auditoria de coordenadas

- latitude/longitude -> projeção world X/Z;
- world -> tile pelo grid OMSI de 300 m;
- world -> local somente na persistência;
- renderer local -> world somando a origem do tile uma única vez;
- objetos terrain-relative usam offset vertical zero e recebem DEM uma vez;
- splines usam o campo vertical OMSI sem segunda soma de DEM;
- prédios e infraestrutura gerados usam geometria local ao centro do asset.

Há regressão multi-tile cobrindo tile negativo, central e positivo, além de rejeição de placement fora do bounding box físico.

### Integridade da release

O workflow agora recusa --clobber se uma tag existente apontar para SHA diferente do workflow atual. Isso evita release com tag e binários de commits diferentes.

As regressões e smokes anteriores continuam ativos; nenhum teste foi enfraquecido.
