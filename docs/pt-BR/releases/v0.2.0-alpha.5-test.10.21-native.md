# OMSI Map Studio v0.2.0-alpha.5-test.10.21-native

Build **ALPHA 5 TEST 10.21 — chave CARTO integrada ao criador de mapa real**.

## Correção do “API KEY REQUIRED”

O CARTO Basemaps passou a exigir uma API key nos tiles externos. A Test 10.21 mantém o CARTO e adiciona o fluxo correto de credencial.

No painel **Criar mapa real por área** agora existem:

- campo **Chave CARTO Basemaps**;
- botão **Salvar chave** / **Atualizar chave**;
- botão **Como obter**, que abre a página oficial da CARTO;
- armazenamento local no **Windows Credential Manager**;
- recarregamento automático do mapa depois de salvar a chave.

A URL CARTO usada pelo Leaflet e pela referência visual do terreno agora inclui `?key=` e usa o caminho oficial `/rastertiles/light_all/`.

## Fallback

Se nenhuma chave CARTO estiver salva, o seletor interativo usa temporariamente o OpenStreetMap para que a escolha da área continue funcionando sem o watermark “API KEY REQUIRED”.

A referência visual CARTO aplicada ao terreno continua exigindo a chave CARTO.

## Cache

A referência CARTO agora usa um novo namespace de cache `carto-keyed-v1`, evitando reaproveitar imagens antigas que possam conter o watermark da versão sem chave.

## Mantido

Também permanecem as melhorias de navegação da Test 10.20, caches de tiles/assets/texturas e o smoke test real do EXE.
