# OMSI Map Studio v0.2.0-alpha.3-native

Correção de inicialização da Native Preview após o erro:

`Cannot find a Resource with the Name/Key TabViewButtonBackground`

## Causa

O `App.xaml` nativo não carregava o dicionário padrão de recursos dos controles WinUI. A janela principal usa controles como `MenuBar`, `ListView`, `NumberBox` e outros que dependem desses recursos de tema. Sem `XamlControlsResources`, a criação de `MainWindow` falhava antes da interface aparecer.

## Correção

- `App.xaml` agora carrega `XamlControlsResources` de `Microsoft.UI.Xaml.Controls`;
- o workflow de release verifica explicitamente que esse recurso está presente antes de publicar;
- continua a verificação de `MapStudio.Native.pri` no diretório final de publish;
- o log de startup continua em `%LOCALAPPDATA%\OMSI Map Studio Native Preview\Logs\startup.log`.

## Incluído nesta build

Mantém os recursos já migrados da Native Preview, incluindo viewport Direct3D 11, seleção, gizmos, Explorer, Inspector, biblioteca, preview 3D, placement de objetos, construção sequencial de splines, fullscreen, atalhos e painéis redimensionáveis.

A Native Preview continua instalada separadamente da versão React/WebView2.

PR #3 permanece DRAFT e sem merge.
