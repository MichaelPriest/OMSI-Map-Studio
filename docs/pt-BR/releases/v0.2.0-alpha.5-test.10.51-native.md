# OMSI Map Studio v0.2.0-alpha.5-test.10.51-native

Fluxo de cruzamentos mais visual e direto, mantendo as sugestões reais já calculadas pelo renderer.

## Barra contextual de Cruzamentos

- **Detectar encontros** recalcula as sugestões existentes;
- **← Encontro** e **Encontro →** percorrem os encontros visíveis no filtro atual;
- **Focar** centraliza a câmera no encontro selecionado;
- **Usar alvo** reutiliza o mesmo fluxo real que antes exigia duplo clique na lista;
- **Biblioteca** continua disponível para navegação manual.

## Feedback no viewport

- um HUD mostra as duas splines envolvidas;
- exibe tile, coordenadas locais e rotação da sugestão;
- a seleção no Explorer e os botões anterior/próximo atualizam o mesmo foco;
- o HUD é limpo ao sair do módulo de Cruzamentos ou quando não existem sugestões.

## Alvo real de junction

`Usar alvo` mantém `_junctionPlacementTarget`, focaliza o ponto real e abre a biblioteca no grupo `OmsiAssetLibraryGroup.Junctions`. O posicionamento continua usando o pipeline real de SCO, sem mocks e sem criar um segundo sistema de cruzamentos.
