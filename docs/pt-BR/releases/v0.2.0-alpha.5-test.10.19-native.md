# OMSI Map Studio v0.2.0-alpha.5-test.10.19-native

Build **ALPHA 5 TEST 10.19 — cache de tiles para navegação 3×3 mais leve**.

## Reaproveitamento dos tiles sobrepostos

No modo de desempenho, ao sair de uma região 3×3 para a região vizinha, normalmente **6 dos 9 tiles continuam iguais**.

Antes desta Test, esses tiles eram lidos novamente do disco. Agora o conteúdo completo do tile pode ser reutilizado pelo cache quando os arquivos de origem continuam inalterados.

## Invalidação segura

O fingerprint do cache acompanha:

- arquivo `.map`;
- `.terrain`;
- `.water`;
- `.terrain_0.rdy`;
- máscaras `.dds` em `texture/map` pertencentes ao tile.

Se algum desses arquivos mudar, aparecer ou desaparecer, o tile deixa de ser reaproveitado e é relido normalmente.

## Memória limitada

O cache de conteúdo mantém até **32 tiles recentes** por sessão, com descarte LRU.

As rotinas de edição continuam fazendo leitura direta depois das gravações. O cache é usado no caminho de abertura/navegação por região para reduzir I/O repetido sem interferir no resultado imediato das edições.
