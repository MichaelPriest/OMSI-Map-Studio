# OMSI Map Studio v0.2.0-alpha.5-test.10.58-native

## Test 10.58 — preview visual do terreno seguindo a rua

Esta preview completa a etapa visual do fluxo **Terreno acompanha a via**.

- ao selecionar uma spline, o viewport mostra a faixa que será afetada antes de gravar;
- linha ciano central acompanha a geometria real reta ou curva da spline;
- linhas brancas mostram os limites da área principal sob a via;
- linhas ciano externas mostram o limite total incluindo a transição/feather;
- preview usa altura, gradiente inicial/final, raio e rotação reais da spline;
- offset vertical também aparece no preview;
- alterações de **meia largura**, **transição** e **offset vertical** atualizam a visualização imediatamente;
- preview se reprojeta ao fazer pan, orbit, zoom, resize ou mudança de DPI;
- nenhum arquivo `.terrain` é alterado até clicar **Seguir rua**;
- inclui teste do Core para conferir eixo, largura e feather em coordenadas mundiais.
