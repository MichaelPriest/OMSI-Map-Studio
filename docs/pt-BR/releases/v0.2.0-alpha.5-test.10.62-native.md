# OMSI Map Studio v0.2.0-alpha.5-test.10.62-native

## Test 10.62 — metadados OSM de ponte/túnel/camada no placement nativo

Esta preview corrige uma perda de informação importante entre o grafo OSM e a criação das splines.

- cada `NativeSplinePlacementRequest` agora preserva se o segmento de origem é **ponte**, **túnel** e qual é seu **layer**;
- o resultado do placement informa quantos requests são de ponte, túnel e camada diferente de zero;
- o gerador deixa de fundir dois segmentos em uma única curva quando seus estados de `bridge/tunnel/layer` não são compatíveis;
- o diagnóstico de geração automática passa a registrar `bridgeRequests`, `tunnelRequests` e `layeredRequests`;
- a altura ainda **não recebe um offset arbitrário fixo** nesta etapa: isso evita criar degraus falsos nas entradas de pontes e túneis;
- testes do Renderer validam a propagação real dos metadados e a proteção contra merge através de mudança de nível.

Esta é a base para a próxima etapa: selecionar automaticamente assets de ponte/túnel e calcular rampas/elevação sem deformar o terreno abaixo deles.
