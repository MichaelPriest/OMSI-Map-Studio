# OMSI Map Studio v0.2.0-alpha.5-test.10.117-native

## Test 10.117 — fallback OSM oficial após falha do Overpass

A captura real mostrou os servidores públicos Overpass retornando HTTP 504, HTTP 429 e timeout para a mesma área. A Test 10.117 muda a estratégia para reduzir repetição e permitir que a geração continue sem depender de três tentativas pesadas iguais.

### Nova estratégia de download

- chunks primários passam a aproximadamente 300 m, alinhados à escala física dos tiles OMSI;
- cada bloco tenta somente um servidor Overpass por vez, escolhido por rotação;
- a tentativa Overpass usa orçamento de 12 segundos;
- se a tentativa falhar, o mesmo bloco usa como fallback o endpoint oficial `https://api.openstreetmap.org/api/0.6/map`;
- o fallback oficial recebe somente o bbox pequeno daquele bloco e devolve OSM XML completo;
- esse XML passa pelos mesmos filtros existentes de vias, prédios, vegetação, mobiliário e infraestrutura;
- se o fallback oficial também indicar área/dados excessivos, a recuperação por subdivisão continua disponível;
- HTTP 429 marca aquele Overpass como indisponível para a ramificação atual para evitar repetição imediata;
- testes e integrações que instanciam o cliente com endpoints próprios e sem fallback preservam o comportamento anterior.

Continuam ativos: cobertura física dos tiles, rejeição de sucesso vazio, rollback, loading animado, progresso e cancelamento.
