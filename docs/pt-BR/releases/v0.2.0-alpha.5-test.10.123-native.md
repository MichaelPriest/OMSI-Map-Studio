# OMSI Map Studio v0.2.0-alpha.5-test.10.123-native

## Test 10.123 — tela de carregamento garantida antes das operações pesadas

A Test 10.123 corrige uma regressão visual em que a tela de carregamento ainda existia no código, mas podia não chegar a ser desenhada antes do início de uma operação pesada.

### Tela de carregamento

A tela **não foi removida**. Ela continua contendo:

- overlay sobre o editor;
- ProgressRing animado;
- título e etapa atual;
- detalhe da operação;
- barra de progresso;
- porcentagem quando conhecida;
- botão **Cancelar geração** no pipeline de mapa real.

Agora o editor entrega explicitamente um frame ao WinUI logo depois de ativar o overlay e antes de iniciar trabalho pesado. Isso é aplicado a:

- criação e reconstrução de mapa real;
- abertura de mapa;
- troca entre mapa completo e região;
- navegação de tiles que exige recarga;
- atualização da biblioteca;
- inicialização do Workspace;
- duplicação em lote.

### Mapa real

Durante a reconstrução, a tela continua recebendo o progresso do ViewModel e deve exibir mudanças como:

`Construindo mapa real → OpenStreetMap → Vias → bloco X/Y → servidor → tentativa`

e depois elevação, prédios, vegetação, mobiliário, aplicação e conclusão/rollback.
