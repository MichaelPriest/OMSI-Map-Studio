# OMSI Map Studio v0.2.0-alpha.5-test.10.79-native

## Test 10.79 — Real World Reconstruction: planner de cenário com confiança

Esta preview inicia o pipeline de reconstrução completa do mundo real.

### Objetivo

Combinar dados geográficos, imagens aéreas, imagens ao nível da rua e imagens fornecidas pelo usuário para reconstruir:

- prédios e casas;
- muros e cercas;
- postes e iluminação pública;
- árvores;
- placas;
- abrigos de ônibus;
- guard rails;
- calçadas;
- entradas de garagem;
- estacionamentos;
- outros elementos de cenário.

### Primeira etapa implementada

Foi adicionado o `MapStudioSceneReconstructionPlanBuilder`.

Cada elemento reconstruído mantém:

- tipo do elemento;
- fonte de cada evidência;
- referência da fonte;
- confiança individual;
- confiança fusionada;
- dimensões conhecidas;
- vínculo com footprint de prédio quando aplicável;
- decisão automática de geração/revisão.

Fontes modeladas:

- OSM;
- imagem aérea;
- imagem ao nível da rua;
- imagem fornecida pelo usuário;
- modelo digital de elevação.

O sistema usa fontes independentes para aumentar a confiança. Elementos acima de **0,82** podem ser gerados automaticamente; resultados entre **0,55 e 0,82** entram para revisão; abaixo disso não são tratados como dados confiáveis.

### Imagens de rua

O pipeline foi projetado para aceitar provedores cuja licença permita processamento e derivação, como imagens próprias ou integrações compatíveis. Google Street View não será usado para gerar automaticamente assets derivados.
