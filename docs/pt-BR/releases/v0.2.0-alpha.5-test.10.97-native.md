# OMSI Map Studio v0.2.0-alpha.5-test.10.97-native

## Test 10.97 — mobiliário urbano real ampliado

O pipeline de reconstrução real agora reconhece também bancos públicos, lixeiras, bollards/balizadores e hidrantes a partir do OpenStreetMap.

Foram adicionados tipos próprios no planner, seleção de assets OMSI por categoria e tokens, reconhecimento de hidrantes na biblioteca e cobertura na consulta Overpass unificada.

Tags suportadas nesta etapa:

- `amenity=bench`;
- `amenity=waste_basket`;
- `barrier=bollard`;
- `emergency=fire_hydrant`.

Esses elementos seguem o mesmo fluxo transacional já existente: confiança, asset real da instalação, ID global, agrupamento por tile, backup e rollback.
