# OMSI Map Studio v0.2.0-alpha.5-test.10.59-native

## Test 10.59 — conexões internas por faixa nas junctions

Esta preview faz os caminhos internos dos cruzamentos respeitarem as faixas reais das vias conectadas.

- cada braço calcula centros de faixa separados para tráfego entrando e saindo;
- vias de mão única distribuem suas faixas em torno do eixo da própria via;
- vias de mão dupla mantêm inbound/outbound em lados opostos;
- movimentos entre braços fazem pareamento proporcional quando as quantidades de faixas são diferentes;
- conversões de múltiplas faixas deixam de compartilhar exatamente o mesmo eixo;
- a Bézier quadrática passa a usar a interseção das tangentes reais das faixas, preservando alinhamento na entrada e na saída;
- regras existentes de one-way, inbound/outbound, largura de faixa e segmentação suave continuam válidas;
- teste real valida duas faixas distintas numa conversão de 90 graus.

Isso prepara o Road Kit para cruzamentos mais próximos de um editor viário moderno, com ônibus e tráfego percorrendo trajetórias separadas por faixa.
