# OMSI Map Studio v0.2.0-alpha.5-test.10.10-native

Build **ALPHA 5 TEST 10.10 — ghost visual, IA selecionável, mapa OSM/Google e Auto conectar**.

## Mover e girar com o item visível

Ao mover ou girar um item, o viewport agora exibe um **ghost preenchido da geometria real selecionada** acompanhando o mouse.

- o item original permanece na posição inicial durante a prévia;
- o ghost acompanha Mover e Girar em tempo real;
- soltar o mouse aplica a transformação;
- funciona para objetos e splines;
- Inspector não é necessário.

## Perfil de IA

A barra superior agora possui um seletor **Perfil de IA**.

- escolha diretamente o perfil que ficará ativo;
- a escolha é salva imediatamente;
- o botão **IA** testa o perfil ativo;
- não é mais necessário entrar novamente no diálogo apenas para trocar o perfil.

## Referência de mapa

Em **Mapa → Referência de mapa sobre o terreno...**:

- **OpenStreetMap** é o provedor padrão e não exige chave;
- o tile necessário é baixado sob demanda;
- cache local mínimo de 7 dias;
- User-Agent identifica o OMSI Map Studio;
- atribuição **© OpenStreetMap contributors** permanece visível no viewport;
- **Google Maps** continua disponível via Maps Static API;
- a chave Google pode ser salva no Windows Credential Manager;
- a chave salva também pode ser reutilizada pelo Google Elevation.

O Map Studio não inclui uma chave Google privada embutida.

## Auto conectar ruas / splines

Novo botão **Auto conectar** na barra de Ruas.

Para a spline selecionada:

- procura endpoints próximos usando a distância de snap;
- preenche Previous/Next ausentes;
- detecta IDs de vizinhos que não existem mais;
- substitui links quebrados por conexões válidas;
- atualiza o vínculo recíproco;
- preserva conexões válidas;
- cria backup antes de gravar.

A inserção de novas splines também passa a considerar links quebrados como reparáveis.
