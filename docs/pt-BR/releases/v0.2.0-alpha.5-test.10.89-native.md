# OMSI Map Studio v0.2.0-alpha.5-test.10.89-native

## Test 10.89 — mobiliário urbano OSM em lote com assets reais

Esta preview conecta os pontos de mobiliário urbano detectados no OpenStreetMap ao writer transacional de scenery.

### Tipos suportados

- iluminação pública / postes de luz;
- postes e torres de utilidade/energia;
- placas de trânsito;
- pontos e abrigos de ônibus.

### Seleção de assets

O novo `MapStudioStreetFurnitureAssetSuggester` restringe a busca às categorias corretas da biblioteca OMSI e exige tokens compatíveis com o tipo de objeto.

Isso evita, por exemplo, usar um banco, cerca ou outro scenery genérico quando o OSM pede um poste de iluminação.

Metadados como `ref`, operador, nome e `shelter_type` aumentam a pontuação de assets mais específicos.

### Colocação

Os itens com confiança suficiente são:

`OSM -> classificação -> confiança -> asset OMSI -> projeção -> writer em lote -> tile`

IDs são reservados globalmente, vários itens no mesmo tile são gravados de uma vez e cada tile recebe backup antes da substituição.
