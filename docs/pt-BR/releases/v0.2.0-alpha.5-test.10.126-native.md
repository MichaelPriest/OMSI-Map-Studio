# OMSI Map Studio v0.2.0-alpha.5-test.10.126-native

## Test 10.126 — auditoria profunda das ferramentas manuais

Esta build continua a auditoria iniciada na 10.124 e corrige a diferença entre **handler implementado** e **ferramenta realmente alcançável pela interface visível**.

### Rotas manuais realmente visíveis

A auditoria identificou que a antiga `MapToolPalette` permanece oculta por projeto. Por isso, a acessibilidade agora é verificada na superfície atual do editor:

- **Seleção → Validar mapa**: novo acesso visível para Validation;
- **Objetos → Infraestrutura**: abre Utilities;
- **Ruas → Mais → Criador de túnel**: abre o gerador real de túnel;
- **Transporte → Paradas e terminais**: abre Transit Assets.

Os botões da paleta legada continuam ocultos e não são mais usados como evidência de acessibilidade.

### Classificação de assets em português

A Biblioteca agora reconhece nomes em português que antes podiam cair em **Outros**:

- transporte: `ponto`, `parada`, `abrigo`, `garagem`, `estacao`;
- infraestrutura: `energia`, `agua`, `saneamento`, `esgoto`, `infraestrutura`;
- túneis: `tunel`.

Também foram adicionados casos de regressão para **Pontos / abrigos**, **Água / saneamento** e **Túneis**.

### Persistência confirmada no fluxo completo

A auditoria verificou início → interação → gravação → reload para os fluxos principais sob revisão:

- Transit Assets/Utilities → inserção SCO no `.map`, backup transacional e reload do tile;
- spline/túnel posicionado → inserção real no `.map` e reload;
- gerador de túnel → `.sli` real + texturas + backup + leitura por `OmsiSplineDefinitionReader`;
- cruzamentos → alvo geométrico → posicionamento SCO → commit real;
- Track → `.ttr` + backup + reload;
- StationLink → `StnLinks.cfg` + backup + reload;
- programas de semáforo → `.sco` + backup + reload;
- paths SCO/SLI → patch real + backup + reload;
- Validation analisa dependências, TTData, links e estrutura; os reparos continuam passando pelos escritores reais.

### Proteção contra regressão

Native Windows CI e Native Preview Release agora verificam as **rotas visíveis reais**, além dos handlers, writers e readers de persistência.
