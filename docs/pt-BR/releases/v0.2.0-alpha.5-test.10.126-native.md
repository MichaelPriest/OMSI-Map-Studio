# OMSI Map Studio v0.2.0-alpha.5-test.10.126-native

## Test 10.126 — auditoria profunda das ferramentas manuais

Esta build continua a auditoria iniciada na 10.124 e corrige pontos que ainda podiam fazer uma ferramenta existir no código, mas ficar escondida ou parecer vazia na Biblioteca.

### Ferramentas manuais agora diretamente acessíveis

Os botões principais abaixo deixaram de ficar permanentemente `Collapsed`:

- **Túneis**;
- **Paradas / Transit Assets**;
- **Infraestrutura / Utilities**.

Os caminhos alternativos existentes continuam funcionando, mas agora as três ferramentas também podem ser abertas diretamente pela barra principal.

### Classificação de assets em português

A Biblioteca agora reconhece nomes em português que antes podiam cair em **Outros**:

- transporte: `ponto`, `parada`, `abrigo`, `garagem`, `estacao`;
- infraestrutura: `energia`, `agua`, `saneamento`, `esgoto`, `infraestrutura`;
- túneis: `tunel`.

Também foram adicionados casos de regressão para subcategorias como **Pontos / abrigos**, **Água / saneamento** e **Túneis**.

### Persistência confirmada no fluxo completo

A auditoria verificou início → interação → gravação → reload para os fluxos principais que ainda estavam sob revisão:

- objetos de Transit Assets/Utilities → `.map` por `OmsiTileObjectInserter`, escrita transacional e reload do tile;
- splines/túneis posicionados → `.map` por `OmsiTileSplineInserter`, escrita transacional e reload;
- gerador de túnel → arquivo `.sli` real, texturas, backup e leitura por `OmsiSplineDefinitionReader`;
- cruzamentos → alvo geométrico → posicionamento SCO → commit real no tile;
- Track → `.ttr` + backup + reload;
- StationLink → `StnLinks.cfg` + backup + reload;
- programa de semáforo → `.sco` + backup + reload;
- paths SCO/SLI → patch real do asset + backup + reload;
- Validation permanece ferramenta de análise; reparos continuam passando pelos escritores reais.

### Proteção contra regressão

Native Windows CI e Native Preview Release agora falham se Túneis, Transit Assets, Utilities ou Validation voltarem a ficar permanentemente ocultos, ou se os marcadores de persistência/reload desaparecerem.
