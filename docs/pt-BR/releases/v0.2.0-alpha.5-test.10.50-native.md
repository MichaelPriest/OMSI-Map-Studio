# OMSI Map Studio v0.2.0-alpha.5-test.10.50-native

Edição de paths ainda mais direta no próprio viewport.

## Path no mapa

- clicar em um nó real de path continua selecionando o SCO/SLI e focando o índice correspondente;
- um HUD compacto no topo do viewport mostra índice, tipo, direção e largura do path;
- o HUD também identifica se o nó clicado é o início ou o fim;
- navegar com **← Path** e **Path →** atualiza o mesmo foco visual;
- ao ocultar os paths, o HUD é limpo para não manter estado antigo.

## Duplo clique para editar

- duplo clique em um nó de path faz hit-test no nó real visível;
- a seleção do owner e o índice focado são sincronizados antes da edição;
- o evento do viewport reutiliza diretamente `OnEditSceneryPathClick`;
- objetos SCO continuam usando `SceneryPathEditorDialog`;
- splines SLI continuam usando `SplinePathEditorDialog`;
- salvamento, backup e recarregamento permanecem no fluxo real já existente.

Não foi criado editor paralelo nem dado mockado.
