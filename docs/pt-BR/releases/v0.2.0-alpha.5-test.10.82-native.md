# OMSI Map Studio v0.2.0-alpha.5-test.10.82-native

## Test 10.82 — mobiliário urbano OSM no Real World Reconstruction

Esta preview amplia o pipeline de reconstrução para elementos pontuais do cenário urbano.

### Implementado

Novo importador OSM para:

- postes de energia;
- postes/luminárias públicas;
- placas de trânsito;
- pontos e abrigos de ônibus.

Tags reconhecidas incluem combinações explícitas de:

- `highway=street_lamp`;
- `power=pole` / `power=tower`;
- `traffic_sign=*` / `highway=traffic_sign`;
- `highway=bus_stop`;
- `public_transport=platform`;
- `amenity=shelter`;
- `shelter=yes`.

Cada item mantém ID, coordenadas, nome, operador, referência e tipo de abrigo quando disponível.

### Confiança

O adaptador converte os elementos para o mesmo planner do Test 10.79:

- `UtilityPole`;
- `StreetLight`;
- `TrafficSign`;
- `BusShelter`.

Uma única evidência OSM explícita pode ficar em revisão quando ainda não há confirmação visual. Evidência independente de imagem ao nível da rua aumenta a confiança e pode liberar geração automática.

### Testes

- reconhecimento dos quatro tipos suportados;
- mapeamento para categorias do planner;
- mobiliário OSM isolado sujeito a revisão;
- fusão OSM + imagem de rua elevando confiança para geração automática.
