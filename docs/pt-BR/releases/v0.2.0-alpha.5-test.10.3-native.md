# OMSI Map Studio v0.2.0-alpha.5-test.10.3-native

Build **ALPHA 5 TEST 10.3 — Mapa inline + correção do atalho de movimentação**.

Esta build substitui a Test 10.2 para validar especificamente o problema relatado no botão **Mapa** e a organização correta do painel **Projeto**.

## Correção do botão Mapa

- **Mapa** voltou para o painel **Projeto**;
- o botão Mapa não abre mais o Gerenciador de Tiles em um `ContentDialog`;
- Mapa agora abre um painel interno próprio, evitando o caminho de UI que continuava falhando em runtime;
- o painel mostra os tiles do mapa, coordenadas, estado carregado/fora da região e referências duplicadas;
- duplo clique ou **Focar** navega para o tile selecionado;
- criar/excluir tile continuam disponíveis no modo Mapa.

## Correção do layout solicitado

- **Tiles permanece dentro de Projeto**;
- o antigo botão global **Tiles** foi removido da barra superior;
- o conjunto de movimentação rápida **← ↑ ↓ →** saiu de dentro de Projeto;
- a navegação rápida entre tiles agora fica na barra global superior;
- Projeto volta a ter quatro áreas: **Cena / Assets / Mapa / Transporte**.

## Mantido da Test 10.2

- proteção contra exceções do Gerenciador de Tiles;
- tratamento de coordenadas duplicadas;
- tema claro/escuro/alto contraste;
- painéis minimizáveis e translúcidos;
- biblioteca otimizada;
- Paths OMSI;
- Timetable/Route Studio avançado.

## Validar primeiro

1. Abrir o aplicativo.
2. Abrir/criar um mapa.
3. Clicar em **Mapa** dentro de Projeto e confirmar que o aplicativo não fecha.
4. Selecionar e focar tiles no painel Mapa.
5. Confirmar que **← ↑ ↓ →** não aparecem mais dentro de Projeto.
6. Confirmar que a navegação rápida aparece na barra superior.
7. Alternar Cena / Assets / Mapa / Transporte várias vezes.

PR #3 permanece **DRAFT** e **sem merge**.
