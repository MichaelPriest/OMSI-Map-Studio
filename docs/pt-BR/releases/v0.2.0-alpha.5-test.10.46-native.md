# OMSI Map Studio v0.2.0-alpha.5-test.10.46-native

Terceira etapa do workspace modular, agora focada em tráfego e edição de paths diretamente no fluxo do viewport.

## Tráfego no contexto do módulo

- Path anterior e próximo diretamente na barra contextual;
- foco do path usa a seleção real do objeto/spline;
- Isolar alterna a geometria de paths para a seleção/foco atual;
- Editar path abre o editor real de [path] do SCO ou SLI;
- + Path reutiliza o fluxo real de inclusão de path;
- Semáforo abre o editor real do programa de traffic lights selecionado;
- clique nos nós de path no viewport continua sincronizando o índice focado.

## Objetivo

Reduzir a dependência das janelas laterais durante a edição e aproximar o fluxo de um editor 3D: selecionar no mapa, focar o path, isolar, editar e validar sem sair do viewport.
