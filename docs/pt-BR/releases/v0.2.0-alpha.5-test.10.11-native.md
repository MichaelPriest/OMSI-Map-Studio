# OMSI Map Studio v0.2.0-alpha.5-test.10.11-native

Build **ALPHA 5 TEST 10.11 — movimento natural, multi-seleção, janelas flutuantes e criador de mapa real por área**.

## Movimento direto

O modo **Mover** foi alterado para acompanhar a posição real do cursor no plano do item.

- selecione o item;
- ative **Mover**;
- arraste o próprio objeto/spline;
- o ghost acompanha o cursor na direção puxada;
- solte para aplicar;
- Inspector não é necessário.

O pan do mapa também passa a funcionar como **agarrar e puxar o chão**, reduzindo a sensação de direção invertida em câmeras inclinadas.

## Multi-seleção

- **Ctrl+clique** adiciona ou remove objetos/splines da seleção;
- a última seleção continua como item primário para Mover/Girar;
- itens adicionais ficam destacados;
- Delete/Excluir pode remover vários itens com uma única confirmação;
- o diálogo informa quantos objetos e splines serão excluídos.

## Roda do botão direito

Todas as ações da roda contextual agora recebem ícone + texto:

Mover, Girar, Duplicar, Excluir, Focar, Inspector, Curvar, Dividir, Paralela, Elevar, Nivelar, Baixar, Substituir, Espelhar e Fluxo.

## Projeto mais compacto

- **Ações do projeto** virou card recolhível;
- Mapa/Tiles pode ser recolhido/expandido;
- Tile X/Y foi removido do card Projeto;
- novo atalho **Tile XY** abre uma janela interna;
- a janela Tile X/Y pode ser movida e redimensionada dentro do editor.

## Criar mapa real por área

Novo fluxo **Mapa > Criar mapa real por área...**.

A janela é móvel e redimensionável e funciona como seleção de área de mapas em celular:

1. escolha OpenStreetMap ou Google Maps;
2. mova/zoome o mapa por baixo do retângulo fixo;
3. o editor calcula norte/sul/leste/oeste;
4. mostra tamanho aproximado;
5. calcula a grade necessária de tiles OMSI de 300 m;
6. cria automaticamente a área selecionada.

OpenStreetMap funciona sem chave para navegação interativa e dados vetoriais.

Google Maps usa exclusivamente a API key salva pelo usuário no Windows Credential Manager. Nenhuma chave Google é incluída no projeto.

### Opções

- gerar vias OpenStreetMap automaticamente;
- aplicar Google Elevation quando houver chave;
- manter referência visual do mapa sobre o terreno;
- abrir modo avançado por coordenadas.

A elevação Google fica desativada por padrão porque pode gerar cobrança da conta Google do usuário.

Nesta Alpha o seletor limita a criação a **400 tiles** por operação para evitar travamentos acidentais.

## Vias automáticas OSM

Quando ativado:

- consulta a área selecionada via Overpass;
- lê ways com `highway`;
- projeta as coordenadas para o mapa OMSI;
- escolhe perfis procedurais;
- gera preview do grafo;
- inicia automaticamente a geração de splines e junctions.

Não é realizado download em massa/offline dos tiles públicos do OpenStreetMap.
