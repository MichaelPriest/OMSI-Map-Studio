# OMSI Map Studio v0.2.0-alpha.5-test.10.53-native

## Test 10.53 — terreno acompanha a spline/rua

Esta preview adiciona o fluxo inverso ao comando “Ajustar via ao terreno”: agora o **terreno pode acompanhar a via selecionada**.

- usa a spline OMSI real selecionada;
- respeita comprimento, rotação, raio/curva e gradientes inicial/final;
- remodela os arquivos `.terrain` reais nos tiles atravessados;
- permite configurar meia largura da via;
- permite configurar a faixa lateral de transição/suavização;
- permite offset vertical do terreno em relação à spline;
- funciona através de limites entre tiles;
- grava com o mecanismo de backup seguro já existente;
- recarrega o viewport após a persistência;
- inclui testes determinísticos para elevação/gradiente e influência de curva.

O comando aparece no Inspector da spline e também diretamente na barra contextual de **Ruas** como **Terreno ↕ via**.
