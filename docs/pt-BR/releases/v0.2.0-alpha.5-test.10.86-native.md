# OMSI Map Studio v0.2.0-alpha.5-test.10.86-native

## Test 10.86 — reconstrução de infraestrutura em lote

Esta preview transforma o pipeline de infraestrutura real em uma operação única e segura para múltiplos elementos.

### Fluxo de um clique

O novo runner executa em sequência:

`OSM -> importação -> confiança -> seleção automática -> projeção -> O3D/SCO -> agrupamento por tile -> gravação OMSI`

Apenas elementos que atingem a confiança de geração automática são materializados. Itens que ainda precisam de confirmação permanecem no resultado como revisão.

### Eficiência

- o `global.cfg` é aberto uma vez;
- cada tile é lido uma vez;
- o maior ID de objetos/splines é calculado para o mapa inteiro;
- IDs novos são reservados sequencialmente sem colisão;
- múltiplos objetos destinados ao mesmo tile usam `AppendMany`;
- cada tile alterado é escrito apenas uma vez.

### Segurança

- backups são criados antes de qualquer alteração de tile;
- todos os arquivos temporários são preparados antes da substituição;
- falha durante a gravação restaura os tiles a partir dos backups;
- elementos fora da malha existente são ignorados e reportados;
- geometrias degeneradas são reportadas separadamente;
- itens de baixa confiança permanecem em revisão e não são gerados.

### Testes

- calçada + estacionamento automáticos no mesmo tile;
- cerca de baixa confiança permanecendo em revisão;
- ID novo calculado considerando outro tile do mapa;
- apenas um backup/escrita para dois objetos no mesmo tile;
- assets O3D/SCO realmente existentes;
- tile não alvo preservado;
- elemento automático fora da malha reportado sem alterar o mapa.
