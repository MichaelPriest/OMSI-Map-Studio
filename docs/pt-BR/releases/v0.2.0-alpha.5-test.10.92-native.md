# OMSI Map Studio v0.2.0-alpha.5-test.10.92-native

## Test 10.92 — pipeline de cenário real em uma chamada

Esta preview junta a captura Overpass do Test 10.90 com a sessão coordenada do Test 10.91.

### API do Core

O novo `MapStudioRealWorldScenePipeline` recebe:

- raiz OMSI;
- diretório do mapa;
- limites geográficos;
- âncora real do mapa;
- biblioteca de assets OMSI;
- evidências adicionais de imagem de rua, quando disponíveis.

E executa:

`bounds -> Overpass scene -> XML unificado -> reconstrução coordenada -> resultado`

### Progresso

O pipeline expõe estágios para a interface:

1. `DownloadingOpenStreetMap`;
2. `ReconstructingScene`;
3. `Completed`.

Isso permite ligar diretamente o HUD/overlay de carregamento do editor sem duplicar lógica na WinUI.

### Segurança

Se o download Overpass falhar, nenhuma modificação de mapa é iniciada.

Depois que a reconstrução começa, continua valendo o snapshot/rollback de sessão do Test 10.91.

### Testes

- uma única chamada baixando XML e reconstruindo prédio + árvore + poste de luz;
- eventos de progresso na ordem correta;
- tile final com todos os objetos;
- falha Overpass sem nenhuma alteração nos bytes do tile.
