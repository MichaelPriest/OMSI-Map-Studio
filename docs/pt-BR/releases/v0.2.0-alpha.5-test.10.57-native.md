# OMSI Map Studio v0.2.0-alpha.5-test.10.57-native

## Test 10.57 — trajetórias internas suaves nas junctions

Esta preview melhora o tráfego dentro dos cruzamentos procedurais.

- movimentos retos continuam usando um único `[path]`;
- conversões passam a usar vários `[path]` conectados;
- os segmentos seguem uma Bézier quadrática com o centro real da junction como ponto de controle;
- a tangente de entrada acompanha a via chegando ao cruzamento;
- a tangente de saída acompanha a via de destino;
- a quantidade de segmentos cresce conforme o ângulo da conversão, limitada para evitar excesso de paths;
- continua usando apenas sintaxe `[path]` já suportada pelo parser OMSI do projeto;
- mantém largura de path baseada nas larguras de faixa das vias conectadas;
- preserva regras de inbound/outbound e vias de mão única;
- adiciona teste real que valida continuidade entre os subtrechos de uma conversão de 90 graus.

Com isso, ônibus e tráfego deixam de cortar conversões por uma diagonal única dentro da junction.
