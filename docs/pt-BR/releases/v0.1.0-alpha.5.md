# OMSI Map Studio v0.1.0-alpha.5

Prerelease de validação focada nas duas falhas mais críticas observadas após a Alpha.4: **viewport piscando/reinicializando** e **seleção pouco confiável no mapa**.

## Correções principais

- o Babylon `Engine` permanece ligado ao canvas durante atualizações normais do React;
- reconstruções estruturais de `Scene` usam troca atômica: a cena anterior continua renderizando até a substituta estar pronta;
- ações de câmera — perspectiva, topo, enquadrar, focar e centralizar tile — não recriam mais a cena completa;
- destaque do tile ativo e overlay de seleção foram desacoplados da reconstrução estrutural;
- a seleção é confirmada ao soltar o botão esquerdo, evitando uma atualização do React no meio do mesmo clique;
- objetos e splines visíveis usam picking real da malha;
- assets sem malha clicável usam tolerância em espaço de tela para seleção mais previsível em diferentes níveis de zoom;
- selecionar um item não troca automaticamente o filtro nem desarma **Mover**/**Rotacionar**;
- clique rápido repetido no mesmo item continua centralizando/focando;
- **Mover** e **Rotacionar** usam uma camada de edição separada: trocar o item selecionado não reconstrói o mapa inteiro;
- a visualização-base do item é ocultada enquanto a cópia editável real recebe o gizmo e volta ao sair da edição;
- Snap continua usando os valores reais configurados;
- o fallback duplicado antigo de seleção no `pointerup` foi removido;
- superfícies reais de spline, objetos O3D, árvores e marcadores de fallback continuam selecionáveis.

## Comportamento esperado

O fluxo fica mais próximo do editor clássico do OMSI: escolher uma ferramenta, clicar diretamente no item do mapa, manter a ferramenta ativa e editar o elemento selecionado sem o cenário apagar ou piscar durante seleção, streaming ou abertura do Inspector.

## Validação automática

O HEAD anterior à preparação desta release passou por:

- **129 testes do Core**;
- build **TypeScript/Vite**;
- build do host desktop **.NET 10**.

A Alpha.5 deve ser usada principalmente para validar visualmente seleção, foco, Mover/Rotacionar, Snap, troca rápida entre itens, streaming de texturas/geometrias e ausência de piscadas/tela preta no viewport.
