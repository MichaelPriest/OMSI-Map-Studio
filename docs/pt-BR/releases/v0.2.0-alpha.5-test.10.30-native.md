# OMSI Map Studio v0.2.0-alpha.5-test.10.30-native

Prévia nativa focada na edição avançada de curva/raio diretamente no viewport.

## Alça visual de curvatura

O comando **Editar curva** agora usa uma alça amarela real em vez de fazer a curva seguir qualquer movimento do mouse.

- alça amarela posicionada no offset lateral da curva;
- clique na alça para iniciar a edição;
- arraste lateralmente para aumentar/reduzir a curvatura;
- solte para aplicar;
- o movimento ao longo do eixo da rua é ignorado: a alça controla apenas a sagitta/offset lateral;
- o raio é recalculado continuamente;
- o status mostra raio e offset durante o arrasto;
- com Snap ligado, o offset usa o mesmo passo de 0,25 m do movimento;
- arrastar a alça para o centro endireita o trecho;
- arrastar para o outro lado inverte o sentido da curva;
- usa o mesmo caminho real de transform edit/undo/redo já existente.
