# OMSI Map Studio v0.2.0-alpha.5-test.10.55-native

## Test 10.55 — Custom Shape para elevação e nivelamento do terreno

Esta preview amplia a **Custom Shape** do módulo Terreno para editar também a malha `.terrain` real do OMSI.

- o mesmo polígono capturado no viewport agora pode **nivelar**, **elevar** ou **abaixar** o terreno;
- mantém o preenchimento de groundtex já existente;
- suporta polígonos côncavos sem preencher recortes internos indevidos;
- atravessa múltiplos tiles OMSI em uma única operação;
- usa coordenadas mundiais para manter a continuidade nas bordas compartilhadas entre tiles;
- aplica feather interno na borda da forma usando `raio × suavização`;
- grava os arquivos `.terrain` reais com o mecanismo de backup/transação segura;
- recarrega os tiles alterados no viewport;
- inclui regressões do Core para forma côncava e continuidade entre tiles adjacentes.

Fluxo no painel **Terreno > Custom Shape**:

`Desenhar forma` → `Nivelar forma` / `Elevar forma` / `Abaixar forma` / `Pintar forma`.
