# OMSI Map Studio v0.1.0-alpha.1

Primeira prerelease testável do projeto.

## Incluído

- seleção de instalação real do OMSI 2;
- descoberta de mapas e tiles;
- leitura preservativa de arquivos OMSI;
- objetos reais de arquivos `.map`;
- seleção de objetos no viewport;
- metadados reais de `.sco`;
- detecção e inventário de meshes `.o3d`;
- preview geométrico de O3D não criptografado;
- interface React/TypeScript/Babylon.js dentro do host desktop;
- pacote Windows x64 self-contained.

## Importante

Esta alpha é **somente leitura**. Salvar, criar ou modificar mapas ainda está desabilitado.

Consulte `docs/pt-BR/TESTING.md` para limitações conhecidas e roteiro de teste.
