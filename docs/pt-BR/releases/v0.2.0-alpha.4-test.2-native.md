# OMSI Map Studio v0.2.0-alpha.4-test.2-native

Build **TEST 2** da arquitetura nativa WinUI 3 + Direct3D 11.

Esta versão é focada na correção do terreno que ficou invisível na Alpha.4 Test 1.

## Correção principal

Na Test 1, o `.terrain` era lido e os triângulos eram enviados para a GPU, mas o passe nativo ainda usava o rasterizer padrão do Direct3D 11 com back-face culling.

A versão React já utilizava terreno double-sided (`backFaceCulling = false`). Dependendo do winding efetivo da malha/câmera, a face visível do terreno nativo podia ser descartada. Com o céu OMSI ativo isso parecia uma textura de nuvens aplicada ao chão, quando na verdade o céu estava sendo visto através da grade.

A Test 2 usa um rasterizer dedicado com `CullNone` somente no passe de terreno e restaura o estado padrão imediatamente depois.

## O que validar primeiro

1. Abra o mesmo mapa em que o terreno aparecia como céu/nuvens.
2. Confirme que a superfície do terreno cobre o fundo e acompanha as elevações do `.terrain`.
3. Confirme que a textura base `[groundtex]`, detail texture e camadas pintadas continuam visíveis.
4. Teste alternar **Terreno** com a tecla `T`.
5. Teste vista superior e perspectiva.
