# OMSI Map Studio v0.1.0-alpha.3

Terceira prerelease testável, ainda somente leitura.

## Destaques

- interface redesenhada com base no conceito aprovado;
- fluxo **Abrir OMSI → Abrir mapa**;
- streaming por tile ativo e região 3×3 para mapas grandes;
- cache de tiles durante a sessão;
- superfície-base neutra do editor;
- eixos reais de splines usando posição, rotação, comprimento, raio e gradientes;
- seleção e inspeção direta de splines;
- leitor seguro de `.sli` restrito à pasta `Splines`;
- leitura de texturas declaradas e perfis `[profile]` / `[profilepnt]`;
- extrusão do perfil real da spline selecionada com material neutro;
- seleção e preview O3D de objetos;
- materiais O3D embutidos por triângulo.

## Importante

Salvar, criar e modificar mapas continuam desabilitados. Texturas de spline e terreno real ainda não são renderizados.

Consulte `docs/pt-BR/TESTING.md` para o roteiro de validação.
