# OMSI Map Studio v0.2.0-alpha.5-test.10.20-native

Build **ALPHA 5 TEST 10.20 — navegação visível primeiro no modo 3×3**.

## Tile vizinho aparece antes

Ao navegar um tile por vez no modo desempenho, o destino normalmente já pertence ao 3×3 que está no viewport.

Nesta Test o editor aproveita isso diretamente:

- se o tile alvo já está carregado, a câmera foca nele imediatamente;
- em seguida o Map Studio completa o novo entorno 3×3;
- o cache de tiles da Test 10.19 reaproveita os tiles sobrepostos, evitando reler o que não mudou.

Isso reduz a sensação de que o editor “para” antes de mover para a próxima área.

## Saltos maiores

Quando o usuário escolhe um tile fora do snapshot atual, o carregamento passa por duas etapas:

1. o tile central é carregado e renderizado primeiro;
2. depois são carregados os tiles vizinhos necessários para completar o 3×3.

A segunda renderização preserva a navegação/câmera já posicionada no mesmo mapa.
