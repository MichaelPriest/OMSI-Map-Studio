# OMSI Map Studio v0.2.0-alpha.5-test.10.100-native

## Test 10.100 — Google Elevation integrado ao pipeline Core

O backend de elevação Google já existia no host nativo para edição manual de um tile. Agora o download de DEM foi promovido para o Core e pode alimentar diretamente o pipeline completo de mapa real.

### Cliente de elevação

`MapStudioGoogleElevationSurfaceClient`:

- recebe bounds sul/oeste/norte/leste;
- cria uma grade configurável;
- envia coordenadas em lotes de até 64 pontos;
- valida HTTP, status da API e quantidade de resultados;
- produz diretamente uma `MapStudioGeoreferencedElevationSurface`;
- usa a menor altitude retornada como datum local por padrão;
- expõe progresso por quantidade de amostras.

### Pipeline automático

Novo fluxo:

`RunAutoIndexedWithGoogleElevationAsync`

Executa:

1. indexação dos assets OMSI;
2. download da grade Google Elevation;
3. download OSM unificado;
4. aplicação do terrain real;
5. vias e gradientes;
6. junctions;
7. prédios, vegetação, infraestrutura e mobiliário.

A nova etapa de progresso é `DownloadingElevation`.
