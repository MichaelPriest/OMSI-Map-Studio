# OMSI Map Studio v0.2.0-alpha.5-test.10.85-native

## Test 10.85 — colocação automática da infraestrutura no tile OMSI

Esta preview fecha o caminho entre reconstrução real, geração física do asset e gravação no mapa OMSI.

### Implementado

- seleção automática do tile a partir do centro mundial do asset;
- conversão de coordenadas mundiais para coordenadas locais do tile OMSI;
- leitura do catálogo de tiles diretamente do `global.cfg`;
- varredura dos objetos e splines de todos os tiles para reservar ID global sem colisão;
- inserção com o `OmsiTileObjectInserter` já usado pelo editor;
- caminho do SCO normalizado a partir da raiz OMSI;
- backup automático do tile antes da alteração;
- gravação por arquivo temporário + substituição para evitar tile parcialmente escrito;
- erro explícito quando a geometria cair fora dos tiles existentes.

### Fluxo agora

`OSM -> importação -> confiança -> projeção -> O3D/SCO -> tile correto -> [object]`

A infraestrutura reconstruída deixa de ser apenas um asset disponível e passa a poder ser gravada diretamente no mapa.
