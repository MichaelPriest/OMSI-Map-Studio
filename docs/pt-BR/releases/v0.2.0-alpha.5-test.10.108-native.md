# OMSI Map Studio v0.2.0-alpha.5-test.10.108-native

## Test 10.108 — Open-Meteo/Copernicus gratuito sem chave

Esta alpha corrige o fluxo de elevação Open-Meteo/Copernicus para permitir o uso do endpoint público gratuito sem exigir API key.

### Modo gratuito por padrão

Ao escolher **Open-Meteo / Copernicus GLO-90**:

- sem chave salva, o Map Studio usa `https://api.open-meteo.com/v1/elevation`;
- nenhuma `apikey` é enviada;
- a elevação continua sendo aplicada ao mesmo datum usado por terreno, vias, junctions, pontes, túneis e cenário;
- a interface informa claramente que o modo gratuito não exige chave.

### Chave comercial opcional

Se houver uma chave Open-Meteo salva no Windows Credential Manager:

- o Map Studio usa `https://customer-api.open-meteo.com/v1/elevation`;
- a chave é enviada apenas ao endpoint customer;
- o campo no Criar mapa real agora é identificado como **Chave Open-Meteo comercial (opcional)**.

### Fluxo completo e compatibilidade

A correção foi aplicada tanto ao pipeline unificado **Criar + reconstruir** quanto ao caminho de elevação por tile do `OmsiNativeSession`, evitando comportamentos diferentes entre reconstrução completa e criação simples.

### Validação

Foi adicionada regressão que verifica explicitamente:

- endpoint público quando a chave é nula;
- ausência de `apikey=` no modo gratuito;
- manutenção do endpoint customer quando existe chave;
- grade georreferenciada e batching de até 100 coordenadas.
