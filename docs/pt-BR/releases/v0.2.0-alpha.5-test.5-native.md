# OMSI Map Studio v0.2.0-alpha.5-test.5-native

Build **ALPHA 5 TEST 5 — O3D Assembly Fix** da arquitetura WinUI 3 + Direct3D 11.

Esta é uma **prerelease de validação** da branch `feature/native-winui-d3d11`. O PR #3 permanece **DRAFT** e **sem merge**.

## Correção principal desta Test 5

A captura da Test 4 mostrou que vários modelos estavam com partes desmontadas: telhados separados das casas, painéis/vegetação muito altos e alguns meshes aparentando rotação incorreta.

A causa foi identificada no renderer nativo: os vértices O3D já chegam no sistema runtime **Y-up**, mas a Test 4 voltou a converter Y/Z no renderer. Isso aplicava a conversão de eixos duas vezes em objetos e nos transforms internos dos meshes.

A Test 5:

- restaura os eixos nativos Y-up dos O3D;
- mantém a ordem original dos triângulos;
- restaura normals sem troca de eixo;
- preserva transforms `new_pos`, `rot_x`, `rot_y`, `rot_z` e `scale` nos eixos do modelo;
- aplica a mesma regra aos previews 3D da Biblioteca;
- mantém separadamente a correção de orientação V das texturas para Direct3D;
- mantém as novas interfaces e as animações de carregamento.
