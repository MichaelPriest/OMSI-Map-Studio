# OMSI Map Studio v0.2.0-alpha.5-test.10.101-native

## Test 10.101 — ponte nativa para geração real automática

O pipeline completo de mapa real agora possui uma camada nativa pronta para ser chamada pela interface WinUI.

### Credencial segura

`NativeRealWorldMapGenerationService` reutiliza a chave Google já armazenada por `NativeMapCredentialStore` no Windows PasswordVault.

A chave não é duplicada em arquivos, JSON ou configurações do projeto.

### Modo automático

`RunBestAvailableAsync`:

- usa Google Elevation automaticamente quando existe chave salva;
- executa asset indexing, DEM, OSM, terrain, vias, gradientes, junctions e cenário;
- se não houver chave Google, continua com o pipeline completo sem DEM em vez de bloquear a criação do mapa.

O resultado informa explicitamente se a sessão usou:

- `Google`;
- `None`.

### Modo obrigatório

`RunWithSavedGoogleElevationAsync` exige uma chave já cadastrada e retorna `googleMapsApiKeyRequired` quando ela não existe.

Isso permite à UI oferecer tanto um fluxo automático tolerante quanto uma ação explícita que exige relevo real.
