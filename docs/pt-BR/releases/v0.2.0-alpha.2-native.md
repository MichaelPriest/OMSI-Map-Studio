# OMSI Map Studio v0.2.0-alpha.2-native

Preview nativa corrigida para o problema em que a primeira Native Preview podia instalar corretamente e fechar imediatamente ao iniciar.

## Correção de inicialização

A primeira preview foi publicada por `dotnet publish` como WinUI 3 não empacotado/self-contained. O pacote continha o Windows App SDK, mas o arquivo de recursos da própria aplicação, `MapStudio.Native.pri`, não entrou no diretório de publish.

Esta versão:

- força o PRI do projeto para a lista de arquivos publicados;
- habilita o caminho de tooling necessário ao Windows App SDK;
- falha o workflow se `MapStudio.Native.pri` não existir no pacote final;
- adiciona log de inicialização em `%LOCALAPPDATA%\OMSI Map Studio Native Preview\Logs\startup.log`;
- tenta mostrar uma mensagem nativa se o XAML/MainWindow falhar antes da interface aparecer.

## Também inclui

Além do conteúdo da alpha.1-native, esta build inclui os avanços já presentes no branch:

- construção sequencial de splines com vínculos OMSI;
- fullscreen nativo;
- atalhos do editor;
- painéis Explorer e Inspector redimensionáveis.

## Instalação

A Native Preview continua instalada separadamente da versão React/WebView2. A versão React não é removida nem substituída.

PR #3 permanece DRAFT e sem merge.
