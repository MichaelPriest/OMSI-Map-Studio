# OMSI Map Studio v0.2.0-alpha.5-test.10.95-native

## Test 10.95 — rollback transacional de assets gerados

Esta preview fecha uma lacuna do pipeline de mapa real: uma falha tardia agora restaura não só os tiles, mas também os assets físicos gerados durante a sessão.

### Protegido no rollback

- `Splines/MapStudio_RoadKit`
- `Sceneryobjects/MapStudio_Junctions`
- `Sceneryobjects/MapStudio_Buildings`
- `Sceneryobjects/MapStudio_Infrastructure`

Roots que já existiam são copiados antes da reconstrução e restaurados exatamente. Roots criados apenas pela sessão que falhou são removidos.

O rollback dos tiles e o rollback dos assets são tentados independentemente; se qualquer um falhar, as exceções são agregadas sem esconder a falha original.

### Testes

- restaura conteúdo anterior de asset existente;
- remove asset novo criado dentro de root existente;
- remove root de junction criado apenas durante a sessão;
- remove roots novos de prédios e infraestrutura.
