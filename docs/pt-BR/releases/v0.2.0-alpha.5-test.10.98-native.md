# OMSI Map Studio v0.2.0-alpha.5-test.10.98-native

## Test 10.98 — elevação real unificada no pipeline de mapa

Esta preview elimina o pressuposto vertical de `Y = 0` do pipeline Core de reconstrução real.

### Superfície DEM georreferenciada

Foi adicionada uma superfície de elevação que recebe:

- grade de alturas;
- limites sul/oeste/norte/leste;
- datum/base vertical opcional.

A amostragem é bilinear. Por padrão, a menor altitude da grade vira `0 m` no mapa, preservando o relevo relativo sem deslocar o mundo inteiro para altitudes absolutas muito altas.

### Terreno OMSI

O novo batch de elevação:

- abre cada `.map.terrain`;
- preserva a resolução original do tile;
- reamostra o DEM para todas as amostras;
- usa o padrão OMSI 60×60 / 61×61 normalmente;
- grava por arquivo temporário;
- cria backup por terrain;
- faz rollback se uma gravação falhar.

### Mesmo Y para todo o cenário

A mesma superfície é usada para posicionar:

- splines de vias;
- junctions;
- infraestrutura;
- prédios;
- árvores/arbustos;
- mobiliário urbano.

Assim, ao aplicar relevo real, os objetos deixam de ficar presos em `Y=0`.

### Pipeline transacional

Foi adicionada a etapa `ApplyingElevation` antes da geração de vias.

O snapshot da sessão completa agora inclui também os arquivos `.map.terrain`. Se roads ou cenário falharem depois da elevação, terreno e tile config retornam ao estado anterior.
