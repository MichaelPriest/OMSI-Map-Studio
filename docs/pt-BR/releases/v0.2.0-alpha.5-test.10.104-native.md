# OMSI Map Studio v0.2.0-alpha.5-test.10.104-native

## Test 10.104 — painel WinUI da geração automática de mapa real

A geração real agora possui um controle visual reutilizável para a interface nativa.

### Painel

`RealWorldGenerationPanel` apresenta:

- estágio atual;
- mensagem de status;
- quantidade de arquivos/candidatos da biblioteca OMSI;
- progresso de Google Elevation;
- botão Cancelar;
- resumo final;
- caminho do backup da sessão.

### Integração

O painel usa diretamente `RealWorldGenerationViewModel` do Test 10.103.

Ele expõe métodos simples:

- `StartAsync`;
- `Cancel`;
- `Reset`.

Assim o `MainWindow` poderá apenas inserir o controle no fluxo de criação real, sem duplicar o pipeline ou a lógica de progresso.

### Thread de UI

Mudanças do ViewModel são encaminhadas pelo `DispatcherQueue` quando chegam fora da thread WinUI.

Isso permite que progresso do asset index, download de elevação e geração de cenário atualizem o painel com segurança.
