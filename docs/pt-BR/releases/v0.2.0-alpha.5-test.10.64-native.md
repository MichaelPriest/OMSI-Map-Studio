# OMSI Map Studio v0.2.0-alpha.5-test.10.64-native

## Test 10.64 — perfil vertical contínuo para pontes e túneis

Esta preview melhora a elevação das splines estruturais sem inventar um offset fixo.

- sequências contíguas marcadas como **bridge** ou **tunnel** são tratadas como um único run estrutural;
- o terreno é amostrado somente nas duas cabeceiras reais do run;
- vértices e segmentos internos recebem altura interpolada pela distância acumulada;
- pontes sobre vales deixam de descer até o terreno em cada nó intermediário;
- túneis atravessando morros deixam de subir até a superfície em cada nó intermediário;
- segmentos aparados junto a junctions continuam na mesma linha de elevação;
- curvas compostas preservam continuidade vertical;
- vias de acesso encontram a estrutura na altura real das cabeceiras, sem degrau artificial;
- nenhum arquivo `.terrain` é alterado por esse cálculo;
- teste do Renderer mantém um vale real no terrain e confirma que o deck permanece na cota das cabeceiras.

A próxima etapa pode inferir clearance quando o OSM fornece apenas `layer` em terreno plano.
