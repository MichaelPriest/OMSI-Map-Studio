# OMSI Map Studio v0.1.0-alpha.2

Segunda prerelease testável.

## Principal correção

A abertura da pasta raiz do OMSI foi otimizada.

Antes, o programa lia todos os arquivos de tile de todos os mapas antes de liberar a interface.

Agora:

- a abertura inicial lê apenas os `global.cfg`;
- o layout dos tiles aparece imediatamente a partir das referências do mapa;
- arquivos `.map` são lidos somente para o mapa selecionado;
- cada tile selecionado é lido uma única vez para estatísticas e objetos;
- leituras de tiles usam concorrência limitada;
- mapas já carregados são mantidos em cache no React ao alternar entre eles.

## Mantido da alpha.1

- seleção de objetos;
- metadados `.sco`;
- preview geométrico de O3D não criptografado;
- pacote Windows x64 self-contained;
- modo somente leitura.

## Importante

Salvar e criar mapas continuam desabilitados nesta alpha.
