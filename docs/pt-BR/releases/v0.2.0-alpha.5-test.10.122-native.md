# OMSI Map Studio v0.2.0-alpha.5-test.10.122-native

## Test 10.122 — F11 sem rótulo flutuante e caminho do OMSI persistente

A Test 10.122 incorpora a 10.121 e corrige dois problemas de uso recorrentes da interface nativa.

### F11 / tela cheia

- o atalho **F11 continua funcionando** para entrar e sair do modo tela cheia;
- o Grid raiz agora oculta a apresentação visual automática dos `KeyboardAccelerator`;
- com isso, o texto `F11` não deve mais aparecer como rótulo/dica flutuante próximo ao cursor;
- os demais atalhos continuam registrados normalmente.

### Caminho da instalação do OMSI

Depois da primeira seleção válida da instalação:

- o caminho raiz do OMSI 2 é salvo em configuração persistente do usuário;
- o arquivo fica em `%LOCALAPPDATA%\OMSI Map Studio\settings\user-settings.json`;
- a gravação é atômica para evitar deixar configuração parcialmente escrita;
- ao usar **Abrir OMSI** novamente, o editor apresenta o caminho salvo;
- é possível escolher **Usar caminho salvo**, **Escolher outra pasta** ou cancelar;
- se a pasta salva deixar de existir ou não contiver `maps`, ela é ignorada e o seletor normal é aberto;
- escolher outra instalação válida atualiza o caminho persistido.

A falha ao salvar preferências não invalida uma instalação OMSI que já foi aberta com sucesso; nesse caso a interface informa o problema.
