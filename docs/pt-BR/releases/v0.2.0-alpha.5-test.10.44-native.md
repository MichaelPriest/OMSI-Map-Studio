# OMSI Map Studio v0.2.0-alpha.5-test.10.44-native

Terceira etapa do fluxo modular inspirado em editores modernos: Coleções da Biblioteca agora podem funcionar como presets mistos de vegetação.

## Presets de vegetação

- o módulo Vegetação ganhou seletor de Preset baseado nas Coleções já existentes;
- somente arquivos SCO realmente classificados como Vegetação entram no preset;
- Pincel/área e Linha podem distribuir múltiplos assets da coleção;
- a distribuição é estável e alterna os assets do preset ao longo dos pontos;
- presets com um único asset continuam funcionando sem tratamento especial;
- collections continuam sendo o sistema único de organização, sem criar um banco paralelo de presets.

## Inserção eficiente

Quando um preset misto é usado, o editor agrupa as posições por caminho SCO e usa `InsertSceneryObjectMultiBatchAsync`. Assim múltiplas espécies são persistidas em um único fluxo de inserção, com as mesmas validações, tiles e backup do editor nativo.

## UX

O status informa quantidade total inserida e quantos assets distintos do preset foram realmente usados.
