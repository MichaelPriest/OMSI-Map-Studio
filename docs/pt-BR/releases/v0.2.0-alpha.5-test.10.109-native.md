# OMSI Map Studio v0.2.0-alpha.5-test.10.109-native

## Test 10.109 — recorte físico do cenário ao mapa criado

Esta alpha corrige os grandes elementos e vias que podiam aparecer fora dos tiles do mapa real após a reconstrução automática.

### Correção observada no teste real

O problema aparecia principalmente em elementos OSM extensos como:

- estacionamentos;
- calçadas;
- muros e cercas;
- guard rails;
- vias que atravessavam a área selecionada com nós externos.

O batch de infraestrutura validava o **centro** do elemento, mas podia gerar a malha inteira mesmo quando a maior parte da geometria ficava fora do mapa. Isso permitia grandes polígonos e ribbons fora dos tiles.

### Novo recorte de infraestrutura

Antes de gerar o O3D:

- áreas são recortadas ao retângulo físico dos tiles criados;
- linhas são recortadas nos limites do mapa;
- o centro é recalculado depois do recorte;
- elementos sem geometria restante são classificados como fora do mapa;
- é aplicado pequeno inset de borda para impedir placements exatamente no limite de 300 m caírem no tile vizinho.

### Novo recorte das vias

As vias OSM agora são recortadas **antes de montar o road graph**.

Isso permite:

- manter corretamente uma via que cruza o mapa mesmo se seus nós originais estiverem fora da área;
- impedir segmentos externos de influenciarem junctions e estrutura física;
- garantir que splines geradas permaneçam na extensão dos tiles existentes.

### Regressões

Foram adicionados testes para:

- estacionamento maior que o mapa;
- calçada/linha atravessando o mapa;
- via com os dois nós fora da área mas atravessando um tile;
- coordenadas finais sempre limitadas à extensão criada.
