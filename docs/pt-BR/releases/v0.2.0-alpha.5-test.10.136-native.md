# OMSI Map Studio v0.2.0-alpha.5-test.10.136-native

## Test 10.136 — equivalentes stock para placas brasileiras R-1 e R-2

A Test 10.136 continua a reconstrução de sinalização da 10.135 e adiciona uma compatibilidade semântica controlada para mapas brasileiros.

O OpenStreetMap brasileiro relaciona:

- `R-1` a **Parada Obrigatória / STOP**;
- `R-2` a **Dê a Preferência / GIVE WAY**.

Como as famílias stock do OMSI original usam a sinalização europeia/alemã, o Map Studio passa a permitir equivalentes somente quando a forma e o significado são diretamente compatíveis:

- `BR:R-1` → asset STOP / família `206`;
- `BR:R-2` → asset GIVE WAY / família `205`.

### Segurança da correspondência

A equivalência é deliberadamente restrita. Outros códigos brasileiros continuam sem conversão automática.

Exemplo:

- `BR:R-3` não é convertido para nenhuma `VZ_*` alemã;
- códigos sem equivalência conhecida continuam sem asset e ficam para revisão/fallback;
- assets customizados cujo nome já contenha a referência brasileira explícita continuam elegíveis normalmente.

Isso evita que uma placa brasileira receba um sinal visualmente incorreto apenas porque ambos pertencem à categoria genérica de sinalização.

### Round-trip

A regressão de integração cria simultaneamente:

- um nó `traffic_sign=BR:R-1`;
- um nó `traffic_sign=BR:R-2`;
- assets locais `VZ_206.sco` e `VZ_205.sco`.

O runner deve posicionar os dois objetos no tile OMSI e não registrar nenhum deles como asset ausente.

### Regressões preservadas

A 10.136 também mantém:

- rejeição de `BR:R-3`;
- seleção segura `DE:206` e `DE:274-30`;
- direção absoluta e relativa pela way;
- proteção contra orientação ambígua;
- cache OSM v3;
- todos os gates anteriores 10.121–10.135.
