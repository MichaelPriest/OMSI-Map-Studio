# OMSI Map Studio v0.2.0-alpha.5-test.10.121-native

## Test 10.121 — biblioteca OMSI na reconstrução real

A Test 10.121 inicia o reaproveitamento seguro dos próprios assets instalados do OMSI durante a reconstrução de mapas reais.

### Ruas OMSI instaladas

- o catálogo real agora indexa **Splines + Sceneryobjects**;
- splines de rua instaladas são medidas pelo perfil físico da própria `.sli`;
- só são consideradas candidatas que possuam paths de tráfego OMSI;
- largura, quantidade de paths, presença de caminho de pedestre e indícios de mão única/divisão entram no score;
- para vias comuns no nível do solo, o editor pode preferir uma spline OMSI compatível;
- se não existir candidata suficientemente compatível, continua usando o **MapStudio Road Kit**;
- pontes e túneis continuam no Road Kit nesta etapa para evitar variantes incompatíveis.

### Cruzamentos, semáforos e faixas

A biblioteca instalada passa a reconhecer separadamente:

- cruzamentos/interseções/rotatórias;
- semáforos, incluindo nomes como traffic light, Ampel e Signalgeber;
- faixas de pedestres / zebra crossing / Zebrastreifen;
- splines de ruas.

O progresso da geração mostra quantos desses assets foram reconhecidos.

### OpenStreetMap

A camada Mobiliário passa a baixar também:

- `highway=traffic_signals`;
- `highway=crossing`;
- nós com tag `crossing=*`.

O cache OSM foi versionado para que a camada antiga seja renovada e não esconda esses novos elementos.

Semáforo passa a ser um tipo próprio do pipeline e pode casar com um `.sco` instalado. Travessias são identificadas separadamente; quando não há direção confiável, permanecem conservadoras para evitar uma faixa colocada com rotação aleatória.

### Próxima etapa

Cruzamentos `.sco` já são catalogados, mas ainda não são inseridos automaticamente sem validação dos pontos de conexão. Quando tivermos os assets de referência, podemos analisar seus encaixes e gerar um kit original do Map Studio com geometrias, semáforos e faixas compatíveis.
