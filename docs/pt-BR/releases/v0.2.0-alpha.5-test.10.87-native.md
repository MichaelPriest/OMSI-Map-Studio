# OMSI Map Studio v0.2.0-alpha.5-test.10.87-native

## Test 10.87 — prédios OSM em lote no mapa OMSI

Esta preview leva o mesmo fluxo automático e transacional do Test 10.86 para prédios reais.

### Escrita de scenery compartilhada

Foi criado um writer genérico para assets de cenário gerados pelo Map Studio:

- lê o mapa e os tiles uma única vez;
- encontra o maior ID usado entre objetos, anexos e splines;
- escolhe automaticamente o tile pelas coordenadas mundiais;
- converte para coordenadas locais OMSI;
- agrupa vários objetos por tile com `AppendMany`;
- cria um backup por tile alterado;
- usa gravação temporária e rollback em caso de falha.

Esse componente poderá ser reutilizado por prédios, vegetação, mobiliário urbano e outros assets gerados.

### Reconstrução de prédios

Novo runner de lote:

`OSM building -> footprint -> projeção -> confiança -> O3D/SCO -> scenery batch writer`

Prédios com evidência OSM forte são gerados e inseridos automaticamente. Prédios genéricos com evidência insuficiente permanecem em revisão.

### Testes

- prédio com níveis, altura, telhado e endereço sendo gerado automaticamente;
- prédio `building=yes` simples permanecendo em revisão;
- ID global considerando outro tile;
- geração real do SCO/O3D;
- um único tile alterado;
- tile não alvo preservado;
- writer genérico agrupando dois objetos em uma única escrita.
