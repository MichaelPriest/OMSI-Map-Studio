## Startup smoke test

O executável nativo agora possui um modo interno `--startup-smoke-test`, usado somente para validação automática.

Antes de criar ZIP, instalador ou publicar a prerelease, o workflow:

1. executa o `MapStudio.Native.exe` self-contained publicado;
2. constrói o `App` e a `MainWindow`;
3. ativa a janela WinUI;
4. exige o marcador `STARTUP_SMOKE_TEST_PASSED` no `startup.log`;
5. falha se houver `FATAL stage=`;
6. exige encerramento normal dentro do limite do teste.

Isso evita publicar uma nova Preview que apenas compila, mas falha imediatamente ao abrir por problema de XAML, recursos PRI, inicialização WinUI ou construção da janela principal.
