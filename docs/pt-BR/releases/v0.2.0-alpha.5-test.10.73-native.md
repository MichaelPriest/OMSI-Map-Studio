# OMSI Map Studio v0.2.0-alpha.5-test.10.73-native

## Test 10.73 — pilares automáticos adaptativos para pontes

Esta preview adiciona suporte estrutural automático às pontes geradas pelo fluxo procedural/OSM.

- trechos resolvidos como ponte, inclusive quando o OSM fornece apenas \`layer > 0\`, agora podem receber pilares automaticamente;
- pilares são distribuídos por **run estrutural contínuo**, usando os links reais entre splines em vez de reiniciar o espaçamento a cada segmento;
- vão alvo de aproximadamente **30 m**, com afastamento das cabeceiras para evitar pilares colados às rampas;
- a posição acompanha retas e curvas reais da spline;
- a altura é calculada pela diferença entre a face inferior do deck e o **terreno real** em cada ponto;
- clearances muito baixos não recebem pilar artificial;
- alturas são quantizadas em passos de **0,25 m** para reutilizar assets e reduzir explosão de variantes;
- a largura da travessa superior acompanha a largura física do perfil do Road Kit;
- cada variante é um **SCO/O3D real** gerado pelo Map Studio, com textura procedural \`ms_bridge_concrete.bmp\`;
- o mesmo asset é reutilizado quando altura/largura coincidirem;
- falha na geração/inserção de um pilar não desfaz as splines de rua já persistidas;
- túneis não recebem pilares;
- nenhuma alteração é feita em arquivos \`.terrain\`;
- testes Core e Renderer validam geometria O3D, reuso de asset, inferência por layer, distribuição e preservação do terreno.

Próximos passos estruturais: aprimorar pilares em junctions elevadas, adicionar portais de túnel e fechar visualmente as transições estrada ↔ ponte/túnel.

Validação desta revisão: Core, Renderer e build WinUI devem permanecer verdes antes da publicação da preview.
