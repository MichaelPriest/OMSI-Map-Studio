# OMSI Map Studio v0.2.0-alpha.5-test.10.103-native

## Test 10.103 — ViewModel da geração automática de mapa real

O controller de sessão do Test 10.102 agora possui uma camada de ViewModel apropriada para binding WinUI.

### Estado para a interface

`RealWorldGenerationViewModel` implementa `INotifyPropertyChanged` e expõe:

- `State`;
- `Stage`;
- `StatusText`;
- `IsBusy`;
- `CanStart`;
- `CanCancel`.

Isso permite ligar botões, HUD de carregamento e status sem duplicar regras de concorrência no XAML/code-behind.

### Progresso

A interface recebe propriedades prontas para exibição:

- arquivos indexados;
- candidatos de assets;
- amostras de elevação concluídas/total;
- progresso de elevação normalizado de 0 a 1;
- texto de progresso.

### Resultado

O resumo final inclui vias, junctions, objetos de cenário, revisões e total de elementos colocados.

O ViewModel também expõe `StartAsync`, `Cancel` e `Reset`, mantendo o fluxo de rollback do controller/pipeline.
