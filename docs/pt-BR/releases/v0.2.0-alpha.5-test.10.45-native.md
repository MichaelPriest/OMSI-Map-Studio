# OMSI Map Studio v0.2.0-alpha.5-test.10.45-native

Primeira implementação funcional de Custom Shapes no editor nativo.

## Custom Shape de vegetação

- o módulo Vegetação ganhou o comando `Forma`;
- cada clique no terreno adiciona um vértice usando o picking real do viewport;
- com três ou mais vértices, a forma é fechada visualmente no preview;
- o espaçamento do preenchimento pode ser configurado em metros;
- `Preencher forma` distribui vegetação apenas dentro do polígono, inclusive formas côncavas;
- o preenchimento respeita os tiles do mapa e limita o lote a 256 posições;
- se houver um Preset/Coleção de vegetação ativo, a forma usa os múltiplos assets da coleção;
- sem preset, usa o SCO de vegetação atualmente selecionado;
- a persistência usa batch ou multi-batch nativo com backup.

## Preview

O contorno reutiliza temporariamente o pipeline D3D11 de preview procedural para que os vértices e o fechamento da forma sejam visíveis durante a edição. Ao concluir ou limpar, o preview anterior de vias procedurais é restaurado quando existir.

## Base geométrica

Foi criado `MapStudioWorldPolygonScatterer`, com point-in-polygon, suporte a polígonos côncavos, normalização de vértices duplicados e limite explícito de pontos.
