# OMSI Map Studio v0.2.0-alpha.5-test.10.88-native

## Test 10.88 — vegetação OSM em lote com assets reais do OMSI

Esta preview conecta árvores e arbustos pontuais do OpenStreetMap ao pipeline transacional de scenery.

### Seleção de assets

O runner reutiliza a biblioteca/indexação OMSI:

- filtra apenas scenery objects classificados como vegetação;
- usa espécie, gênero e tipo de folhagem para escolher o asset mais compatível;
- mantém fallback por tipo genérico de árvore/arbusto;
- não inventa um asset quando a instalação não contém uma opção válida;
- índice desatualizado apontando para arquivo inexistente é reportado como asset ausente.

### Confiança

Somente vegetação que atinge o limiar de geração automática é colocada no mapa.

Árvores OSM detalhadas por espécie/gênero podem ser geradas automaticamente. Pontos genéricos e arbustos com evidência insuficiente continuam em revisão.

### Colocação

- projeção geográfica para coordenadas mundiais;
- rotação determinística por ID para reduzir repetição visual;
- ID global sem colisão;
- agrupamento por tile;
- backup e rollback pelo writer genérico do Test 10.87.

### Testes

- árvore Tipuana com metadata escolhendo asset Tipuana real;
- ID global considerando outro tile;
- árvore genérica permanecendo em revisão;
- arbusto permanecendo em revisão quando a evidência não atinge o limiar;
- asset ausente reportado sem alterar o mapa.
