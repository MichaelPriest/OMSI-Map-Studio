# OMSI Map Studio v0.2.0-alpha.5-test.10.31-native

Prévia nativa focada em **unir trechos visualmente** no editor.

## Unir trechos

A barra de Ruas agora possui o comando **Unir**:

1. selecione a spline de origem;
2. clique em **Unir**;
3. clique diretamente na spline destino;
4. o editor resolve a ligação e insere o trecho intermediário com os vínculos reais.

O fluxo usa o mesmo solver seguro do **Complete to**:

- exige o fim da origem livre (`Next = -1`);
- exige o início do destino livre (`Previous = -1`);
- preserva a mesma SLI nesta etapa para manter paths compatíveis;
- cria ligação reta quando as tangentes já estão alinhadas;
- cria uma curva circular tangente quando existe solução segura;
- recusa geometria impossível em vez de gravar uma conexão incorreta;
- o modo visual usa raio máximo de 200 m;
- o **Complete to** avançado continua disponível para escolher outro raio manualmente;
- inserção real atualiza `Previous/Next`, cria backup e passa pelo mesmo histórico de construção.
