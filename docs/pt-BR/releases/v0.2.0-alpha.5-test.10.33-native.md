# OMSI Map Studio v0.2.0-alpha.5-test.10.33-native

Prévia nativa focada em **finalização limpa da criação automática de mapa real** e **identificação visível da versão do aplicativo**.

## Criação automática de mapa real

Corrigido o comportamento que, após gerar ruas e cruzamentos automaticamente, abria a Biblioteca e podia trocar o viewport para a prévia 3D de um asset.

Agora:

- **Abrir Biblioteca após criar** vem desmarcado por padrão;
- ao usar **Gerar ruas + cruzamentos automaticamente**, o editor termina diretamente na cena do mapa;
- se uma Biblioteca flutuante estiver aberta e não tiver sido solicitada para o pós-criação, ela é fechada;
- o viewport sai de qualquer prévia 3D de asset e restaura a cena do mapa;
- a ferramenta volta para **Seleção**, filtrada para **splines/ruas**;
- a câmera volta para vista superior e enquadra o mapa;
- a Biblioteca ainda pode ser aberta manualmente ou explicitamente marcada para abrir após criar.
