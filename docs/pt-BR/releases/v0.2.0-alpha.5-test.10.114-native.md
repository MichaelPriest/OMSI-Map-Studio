# OMSI Map Studio v0.2.0-alpha.5-test.10.114-native

## Test 10.114 — download OSM sem aparente congelamento

Esta build corrige a cadeia que podia fazer o download OpenStreetMap parecer travado por vários minutos quando servidores públicos estavam lentos ou inacessíveis.

### O que mudou

- chunks primários reduzidos de aproximadamente 750 m para 500 m;
- conexão TCP/TLS ganha limite próprio de 8 segundos;
- a request continua com limite por tentativa de 20 segundos;
- respostas são iniciadas com ResponseHeadersRead para não esperar o corpo inteiro antes de devolver controle ao pipeline;
- o progresso passa a mostrar imediatamente o bloco, endpoint e número da tentativa ativa;
- endpoints que falham por transporte/timeout ficam marcados como indisponíveis para os subchunks daquele bloco;
- a recuperação por subdivisão não repete servidores de transporte que já falharam;
- subdivisão só é tentada quando houve resposta que pode melhorar com consulta menor, como 408/429/5xx selecionados;
- se nenhum endpoint saudável restar, o bloco falha imediatamente em vez de multiplicar novos timeouts;
- limite de duas chamadas simultâneas, cancelamento do usuário e rollback continuam ativos.

### Interface

O assistente em quatro etapas da Test 10.113 permanece: Área, Fontes, Reconstrução e Progresso. Durante o download, a página Progresso agora mostra qual servidor está sendo consultado, evitando a impressão de congelamento.
