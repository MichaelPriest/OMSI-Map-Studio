# OMSI Map Studio v0.2.0-alpha.5-test.10.63-native

## Test 10.63 — assets automáticos de ponte e túnel no Road Kit

Esta preview transforma os metadados de `bridge/tunnel` do Test 10.62 em splines estruturais reais.

- cada perfil viário padrão dirigível agora possui variante **base**, **bridge** e **tunnel**;
- o Road Kit passa de 10 para 28 splines geradas;
- a variante de ponte adiciona estrutura inferior e guardas laterais ao perfil;
- a variante de túnel adiciona paredes laterais e cobertura;
- as superfícies estruturais reutilizam o material cinza já gerado pelo Road Kit;
- o placement OSM seleciona automaticamente `*_bridge.sli` ou `*_tunnel.sli`;
- splines externas/customizadas permanecem inalteradas;
- paths de tráfego/pedestres do perfil base são preservados;
- Road Kit atualizado para **1.3.0**;
- os testes abrem as variantes com o reader real do OMSI e validam a troca automática no Renderer.

A elevação vertical e as rampas de acesso continuam separadas desta etapa para não introduzir offsets arbitrários.
