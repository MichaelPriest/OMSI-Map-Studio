# OMSI Map Studio v0.2.0-alpha.5-test.10.18-native

Build **ALPHA 5 TEST 10.18 — warm cache GPU limitado para reduzir recarga de texturas**.

## Menos recarga ao trocar de região

Até a Test 10.17, o renderer descartava imediatamente da GPU toda textura que deixava de ser usada pela região atual. Ao voltar para uma área recém-visitada, essas texturas precisavam ser decodificadas e enviadas novamente para a GPU.

A Test 10.18 mantém temporariamente as texturas antigas mais recentes para reduzir esse trabalho repetido.

## Limite de memória

A retenção não é ilimitada. O warm cache mantém no máximo:

- **64 texturas antigas**; ou
- **128 MiB estimados de memória GPU**;

o que for atingido primeiro.

Quando o limite é excedido, as texturas menos recentemente usadas são liberadas por LRU. As texturas exigidas pela cena atual continuam protegidas.

## Mantido da Test 10.17

Também permanecem:

- cache derivado de SCO, SLI, O3D e X por fingerprint;
- loaders persistentes durante a sessão do viewport;
- interface compacta;
- CARTO/OpenStreetMap;
