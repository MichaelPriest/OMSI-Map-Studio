# OMSI Map Studio v0.2.0-alpha.5-test.10.94-native

## Test 10.94 — junctions físicos no pipeline de vias reais

O Test 10.93 passou a gerar as vias OSM no Core. Esta preview materializa também os cruzamentos detectados pelo mesmo grafo.

### Geração

Para cada junction real com pelo menos três braços viários:

- os segmentos conectados viram braços do junction;
- ângulo é calculado a partir da geometria OSM;
- largura usa o maior valor entre metadata OSM e largura física do perfil Road Kit;
- quantidade de faixas e mão única são preservadas;
- vias de pedestres não criam braços rodoviários;
- junctions inteiramente em ponte/túnel preservam o tipo estrutural.

O asset é criado por `MapStudioJunctionAssetGenerator`, incluindo geometria, marcações e paths internos, e depois inserido pelo writer transacional de scenery.

### Segurança

Se a geração/colocação de qualquer junction falhar depois das splines terem sido gravadas, os tiles das vias são restaurados pelos backups do batch.

### Pipeline completo

`MapStudioRealWorldMapPipeline.PlacedElementCount` agora contabiliza:

- splines de vias;
- junctions físicos;
- objetos do cenário reconstruído.

### Teste

Um cruzamento OSM de duas vias compartilhando o mesmo nó precisa produzir:

- junction candidate;
- asset SCO/O3D real;
- objeto colocado no tile;
- splines preservadas no mesmo mapa.
