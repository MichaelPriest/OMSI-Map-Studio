# OMSI Map Studio v0.2.0-alpha.5-test.10.115-native

## Test 10.115 — OSM cobre os tiles físicos + carregamento animado

Esta build corrige o caso em que o mapa terminava somente com os tiles.

### Causa corrigida

A reconstrução OSM usava o retângulo geográfico desenhado pelo usuário, mas os tiles OMSI criados sempre ocupam blocos físicos de 300 × 300 m. Em seleções muito estreitas, era possível criar um ou mais tiles completos e consultar apenas uma faixa geográfica de poucos metros. Isso podia retornar poucos ou nenhum elemento útil, deixando apenas os tiles.

Agora a consulta OpenStreetMap usa a união entre a seleção e a cobertura geográfica real de todos os tiles criados. Assim vias, cruzamentos, prédios, vegetação, mobiliário e infraestrutura são consultados para toda a área física do mapa.

### Sucesso vazio não é mais aceito

- se o OSM retornar zero elementos, a geração falha explicitamente;
- se houver dados OSM, mas nenhuma via/junction/estrutura/objeto for realmente colocado, a geração também falha;
- a mensagem de erro inclui nós, ways, relações, vias ignoradas, segmentos fora do mapa, referências ausentes e itens para revisão;
- o rollback continua preservado;
- uma geração com zero placements nunca mais é marcada como Completed.

### Carregamento e animações

- overlay de carregamento permanece visível durante toda a reconstrução;
- ProgressRing animado;
- barra indeterminada durante downloads e determinada quando existe progresso conhecido;
- etapa atual e percentual na tela;
- progresso de criação dos tiles;
- mensagens do pipeline em tempo real;
- botão Cancelar geração no próprio overlay;
- ProgressRing também na página Progresso do assistente.
