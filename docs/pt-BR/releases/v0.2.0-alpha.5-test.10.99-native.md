# OMSI Map Studio v0.2.0-alpha.5-test.10.99-native

## Test 10.99 — gradiente real das vias pelo DEM

O Test 10.98 passou a colocar as splines na altura correta, mas um segmento ainda podia permanecer plano entre dois pontos com cotas diferentes.

Esta preview usa o próprio campo de gradiente do OMSI para acompanhar o relevo.

### Cálculo

Para cada segmento de via:

1. amostra a altura DEM no início;
2. amostra a altura DEM no final;
3. calcula a inclinação percentual: `(alturaFinal - alturaInicial) / comprimento * 100`;
4. grava o mesmo valor em `GradientStart` e `GradientEnd`, produzindo uma rampa constante entre os extremos.

### Coordenadas OMSI

O runner preserva explicitamente a ordem nativa `X, Z, Y`, além da altura inicial e do gradiente.

O teste de round-trip introduzido no 10.98 continua verificando que Z local não é confundido com Y.

### Resultado

Ruas em subida ou descida passam a acompanhar o DEM entre os nós, em vez de usar apenas a cota do início do segmento.

Junctions continuam posicionados pela altitude do próprio nó.
