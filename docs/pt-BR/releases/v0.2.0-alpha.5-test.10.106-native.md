# OMSI Map Studio v0.2.0-alpha.5-test.10.106-native

## Test 10.106 — fachadas e telhados OSM mais fiéis

A reconstrução de prédios do **Real World Reconstruction** passa a aproveitar metadados de aparência do OpenStreetMap para gerar assets OMSI menos genéricos.

### Aparência por prédio

O pipeline agora preserva, inclusive em multipolygons/relations:

- `building:material`;
- `building:colour` e `building:color`;
- `roof:material`;
- `roof:colour` e `roof:color`.

Esses dados seguem do importador OSM para o footprint projetado e chegam ao gerador do asset.

### Texturas geradas

Cada prédio continua usando uma pasta própria em `Sceneryobjects`, mas as texturas `ms_osm_facade.bmp` e `ms_osm_roof.bmp` agora são geradas conforme os dados do prédio.

Há tratamento visual para materiais como tijolo, concreto, vidro, pedra, madeira, metal, telha e ardósia, além de cores hexadecimais e nomes comuns. Quando o OSM não informa aparência, o gerador usa paletas coerentes com o tipo do prédio.

O manifesto `mapstudio-osm-building.txt` também registra os quatro campos de aparência para diagnóstico e rastreabilidade.

### Validação

Foram adicionados testes reais, sem mocks, cobrindo:

- importação dos tags em ways;
- importação dos tags em relations/multipolygons;
- propagação dos metadados pelo projector;
- geração de pixels determinísticos de fachada e telhado;
- persistência dos dados no manifesto do asset.
