# OMSI Map Studio v0.2.0-alpha.5-test.10.81-native

## Test 10.81 — vegetação real no pipeline de reconstrução

Esta preview conecta a vegetação OSM já suportada pelo editor ao pipeline **Real World Reconstruction**.

### Implementado

- árvores pontuais do OSM entram no planner de cenário;
- arbustos permanecem como categoria própria e não são convertidos em árvores;
- fileiras de árvores entram como elementos lineares;
- hedges/cercas vivas entram como elemento de cerca;
- confiança aumenta quando existem:
  - espécie;
  - gênero;
  - tipo de folha;
  - geometria linear com múltiplos pontos;
- evidência forte pode atravessar o limiar de geração automática;
- evidência incompleta permanece sujeita ao limiar de revisão do planner;
- cada candidato preserva o ID OSM e notas de quais metadados sustentaram a decisão.

### Segurança

Nenhum objeto é inventado quando não existe evidência suficiente. A reconstrução continua usando o mesmo sistema de confiança do Test 10.79.

### Testes

Foram adicionadas regressões para:

- árvore com espécie conhecida;
- arbusto preservado como arbusto;
- hedge convertido em cerca;
- fileira de árvores com confiança suficiente para geração automática.
