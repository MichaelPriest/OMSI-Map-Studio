# OMSI Map Studio v0.2.0-alpha.5-test.10.135-native

## Test 10.135 — placas stock OMSI por evidência OSM explícita

A Test 10.135 amplia a reconstrução automática de sinalização sem inventar placas. O Map Studio passa a buscar sinais prioritários explicitamente mapeados no OpenStreetMap e só seleciona um asset stock quando o código/semântica realmente combina com o arquivo instalado.

### OpenStreetMap

A camada de mobiliário agora inclui:

- `traffic_sign=*`;
- `highway=traffic_sign`;
- `highway=stop`;
- `highway=give_way`.

O schema do cache OSM sobe para `osm-layers-v3`, invalidando corretamente os chunks antigos que não continham STOP/GIVE_WAY. O marcador histórico `osm-layers-v2` permanece preservado para compatibilidade dos gates anteriores, mas não é o schema ativo.

### Seleção stock segura

Para uma placa explícita, o suggester exige correspondência real:

- `stop` pode selecionar família STOP/`206`;
- `give_way`/yield pode selecionar família `205`;
- `DE:206` exige `206` no asset;
- `DE:274-30` exige os tokens `274` e `30`;
- códigos desconhecidos, como `BR:R-1`, não caem em uma `VZ_*` arbitrária.

Se existir um asset custom realmente correspondente ao código completo, ele continua elegível.

### Direção da placa

Direções numéricas e cardinais continuam suportadas. Agora também são resolvidas:

- `direction=forward/backward`;
- `stop:direction=forward/backward`;
- `give_way:direction=forward/backward`.

A direção relativa é convertida para rumo absoluto pela geometria da way `highway=*` que contém o nó.

Quando o nó pertence a múltiplas ways e os rumos não concordam dentro da tolerância de 25 graus, a direção fica deliberadamente sem resolver e a placa permanece para revisão. Não é usada rotação pseudoaleatória.

### Auto geração conservadora

Uma placa OSM só atinge confiança automática quando possui:

1. referência/código explícito compatível;
2. direção resolvida.

Caso contrário ela permanece em revisão.

### Regressões

Os testes cobrem:

- seletores Overpass STOP/GIVE_WAY;
- cache OSM v3;
- importer de `stop`, `give_way` e `traffic_sign`;
- `stop:direction` e `give_way:direction`;
- way leste-oeste: forward ~90°, backward ~270°;
- nó pertencente a duas ways incompatíveis permanece sem direção;
- STOP → `VZ_206`;
- GIVE_WAY → `VZ_205`;
- `DE:274-30` → asset correspondente;
- rejeição de código incompatível;
- round-trip real de STOP stock no `tile_0_0.map`.
