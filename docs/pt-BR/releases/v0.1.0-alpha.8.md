# OMSI Map Studio v0.1.0-alpha.8

Prerelease de teste focada em uma nova correção estrutural do **seletor do viewport**.

## Seletor

A Alpha.8 adiciona uma segunda rota de seleção independente do raycast de triângulos do Babylon:

- as caixas reais das malhas OMSI são projetadas diretamente para coordenadas CSS do viewport;
- o cursor é testado contra a área visual projetada da malha;
- isso elimina diferenças entre DPI do Windows, WebView2 e resolução interna do framebuffer;
- objetos podem ser selecionados pela fachada, telhado, poste, árvore ou outra parte visível;
- para splines, o eixo real é projetado para a tela e a distância do cursor aos segmentos é calculada em pixels;
- o raycast real continua sendo a primeira prioridade;
- o fallback por volume visual e o fallback geométrico continuam disponíveis para assets incompletos/protegidos;
- a seleção agora é confirmada no **pressionamento do botão esquerdo**, com captura do ponteiro;
- o item em hover permanece azul e o selecionado vermelho;
- clicar no vazio continua limpando a seleção.

## Explorer/Bibliotecas

Mantém as melhorias da Alpha.7:

- autoajuste por conteúdo e resolução;
- redimensionamento manual;
- tamanho salvo localmente;
- duplo clique na alça para restaurar o modo automático;
- tipografia ampliada.
