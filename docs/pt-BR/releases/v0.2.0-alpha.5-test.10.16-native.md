# OMSI Map Studio v0.2.0-alpha.5-test.10.16-native

Build **ALPHA 5 TEST 10.16 — interface compacta, mapa real sem 403, credencial IA direta e fluxo de itens**.

## Interface mais compacta

A interface nativa foi reduzida para liberar mais área útil do viewport:

- ferramentas principais menores;
- toolbar mais baixa;
- botões de modos mais compactos;
- barra inferior menor;
- janela do Assistente de IA menor;
- Biblioteca menor;
- Criar mapa real por área menor;
- cards da Biblioteca reduzidos.

A prioridade é deixar o mapa ocupar mais tela sem retirar funcionalidades.

## Mapa real: correção do 403

O seletor de área não usa mais diretamente os tiles raster públicos de `tile.openstreetmap.org`, que estavam retornando **403 Access blocked** no WebView.

O basemap interativo agora usa **CARTO com dados OpenStreetMap**, sem chave, com atribuição apropriada.

A referência visual projetada sobre o terreno também foi movida para o mesmo basemap CARTO/OSM e usa cache separado.

Os dados vetoriais de ruas continuam sendo obtidos do OpenStreetMap/Overpass.

## Assistente de IA

O painel flutuante agora possui diretamente:

- campo **Token / API key**;
- botão **Salvar**;
- botão **Limpar**.

A chave é salva no Windows Credential Manager para o perfil ativo. Não é necessário entrar no diálogo Provedores apenas para trocar a credencial.

## Itens no mapa

O fluxo de Criar mapa real agora mostra explicitamente:

- **+ Pasta de itens**;
- **Abrir Biblioteca**;
- opção **Abrir Biblioteca após criar** ativada por padrão.

Ao concluir o mapa, a Biblioteca pode abrir automaticamente. Selecione um SCO/SLI e use **+ Posicionar no mapa** para inserir no viewport.
