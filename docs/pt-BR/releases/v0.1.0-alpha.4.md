# OMSI Map Studio v0.1.0-alpha.4

Quarta prerelease testável do OMSI Map Studio, com foco em interface de edição, seleção visual, biblioteca de assets e fluxo de trabalho em tela cheia.

## Destaques

- nova linguagem visual do editor inspirada em ferramentas modernas de construção de cidades, mantendo identidade própria do Map Studio;
- pacote SVG original do Map Studio aplicado à navegação, ferramentas, biblioteca, Inspector, viewport e diagnósticos;
- modo tela cheia reorganizado com categorias, ferramentas compactas e painéis móveis;
- Explorer e Inspector redesenhados para ocupar menos viewport e destacar melhor o item ativo;
- Biblioteca de `.sco` e `.sli` com cartões visuais, miniaturas reais geradas pelo próprio editor, favoritos, recentes, mais usados e coleções;
- prévia 3D real destacada para assets;
- Inspector com abas visuais de propriedades, transformação, geometria, materiais, traçado e perfil;
- ações de copiar, excluir, salvar, nivelar, editar vínculos, descartar e pré-visualizar padronizadas;
- seleção de objetos e splines com outline ativo mais claro e hover visualmente distinto;
- marcador compacto no viewport mostrando item selecionado, ferramenta atual e estado do Snap;
- gizmos Babylon levemente ampliados para facilitar a captura dos eixos sem alterar a matemática das transformações;
- grade de tiles, spline ativa e tile ativo com hierarquia visual mais clara;
- controles desktop compactos para câmera, Snap e camadas;
- diagnóstico técnico da seleção recolhível para não cobrir a área de edição;
- streaming automático, Asset Index local, ferramentas de construção e edição preservativa continuam integrados ao mesmo estado real do host C#.

## Segurança e dados reais

A Alpha.4 mantém o princípio de não usar mocks/fakes em produção. Assets, geometria, texturas, splines, terreno, seleção, previews e persistência continuam baseados no conteúdo real carregado do OMSI.

As gravações preservativas continuam usando validação do elemento, backup e substituição segura do arquivo quando suportado.

## Validação

Antes da preparação desta versão, o CI passou por:

- testes do Core;
- instalação das dependências da UI;
- build TypeScript/Vite;
- build do host desktop .NET 10.

Consulte `docs/pt-BR/TESTING.md` para o roteiro de validação funcional dentro do OMSI.
