# OMSI Map Studio v0.2.0-alpha.5-test.10.91-native

## Test 10.91 — sessão completa de reconstrução real com rollback

Esta preview adiciona o coordenador que une os runners de cenário em uma única sessão.

### Pipeline coordenado

O novo `MapStudioRealWorldSceneReconstructionRunner` executa, sobre o mesmo XML e a mesma âncora geográfica:

1. infraestrutura urbana;
2. prédios;
3. vegetação;
4. mobiliário urbano com evidência adicional quando disponível.

Cada etapa reutiliza os geradores e writers já testados nas previews anteriores.

### Snapshot da sessão

Antes da primeira alteração:

- todos os tiles referenciados pelo `global.cfg` são copiados para um snapshot de sessão;
- o snapshot fica em `.mapstudio/backups/real-world-scene-session`;
- se qualquer etapa posterior falhar ou for cancelada, todos os tiles são restaurados;
- assets já gerados podem permanecer no disco, mas o mapa volta ao estado anterior.

Isso evita um mapa parcialmente reconstruído quando, por exemplo, prédios foram gravados e a seleção de um asset de mobiliário falha depois.

### Testes

- prédio + árvore + iluminação pública reconstruídos na mesma sessão;
- IDs globais avançando corretamente entre categorias;
- snapshot de sessão criado;
- falha deliberada em mobiliário depois de um prédio já ter sido gravado;
- restauração byte a byte do tile original após a falha.
