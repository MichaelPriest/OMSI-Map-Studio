# OMSI Map Studio v0.2.0-alpha.5-test.10.47-native

Aprimoramento do módulo Tráfego para conectar a lista de programas de semáforo diretamente ao viewport.

## Localização visual

- ao selecionar um programa de semáforo no modo Tráfego, o objeto real correspondente é selecionado e enquadrado no viewport;
- novo botão Localizar permite repetir o foco manualmente;
- a resolução usa ObjectId + Tile X/Y reais do programa carregado;
- o foco reutiliza o mesmo picking/Explorer real do editor, sem criar representação paralela.

## Fluxo

O usuário pode agora selecionar um programa, localizar o controlador no mapa, inspecionar os paths ao redor e abrir o editor do semáforo sem perder o contexto visual.
