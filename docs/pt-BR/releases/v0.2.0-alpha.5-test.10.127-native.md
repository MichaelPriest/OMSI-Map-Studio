# OMSI Map Studio v0.2.0-alpha.5-test.10.127-native

## Test 10.127 — auditoria completa das ferramentas manuais

A 10.127 publica o estado final da auditoria iniciada na 10.124. A 10.126 foi gerada por um HEAD intermediário enquanto a auditoria ainda detectava a diferença entre botões da paleta legada e rotas realmente visíveis. Esta build incorpora a correção final sem sobrescrever a tag anterior.

### Rotas visíveis confirmadas

- **Seleção → Validar mapa** agora dá acesso real à Validation pela interface atual.
- **Objetos → Infraestrutura** abre Utilities.
- **Ruas → Mais → Criador de túnel** abre o gerador real de túnel.
- **Transporte → Paradas e terminais** abre Transit Assets.
- A antiga `MapToolPalette` permanece oculta por projeto e não é mais usada pelo CI como evidência de acessibilidade.

### Auditoria dos controles condicionais

Foram revistos os controles `Collapsed` e inicialmente desabilitados. Os controles restantes são contextuais de forma intencional: edição de Track/Trip/Stop/StationLink/Line, programas de semáforo, reparo de Validation, camadas de terreno e comandos do gerador procedural são habilitados apenas quando existe contexto válido.

A seleção de faixa/path do Route Studio usa o `ComboBox` visível; o `TransportPathIndexBox` oculto funciona apenas como estado sincronizado para a gravação.

### Persistência e reload

Foram confirmados os fluxos início → interação → gravação → reload:

- objetos Transit/Utilities e cruzamentos → `.map` com escrita transacional e reload;
- splines/túneis posicionados → `.map` com reload;
- gerador de túnel → `.sli`, texturas, backup e leitura de volta;
- programas de semáforo → `.sco`, backup e reload;
- paths SCO/SLI → patch real, backup e reload;
- Track → `.ttr`, backup e reload;
- StationLink → `StnLinks.cfg`, backup e reload;
- Trip/Line/BusStop → TTData real e recarga do catálogo.

O gate da 10.127 verifica as rotas realmente visíveis, handlers, writers/readers e cobertura de round-trip para túnel, Track e semáforo. A auditoria automática também encontrou 229 handlers `Click` e nenhum handler manual vazio/no-op.
