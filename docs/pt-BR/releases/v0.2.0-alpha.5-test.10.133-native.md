# OMSI Map Studio v0.2.0-alpha.5-test.10.133-native

## Test 10.133 — índice OMSI persistente sem revarredura automática

A biblioteca de assets já era armazenada em SQLite, mas a geração automática ainda executava uma varredura completa de `Sceneryobjects`, `Splines` e `Texture` a cada execução. A Test 10.133 passa a reutilizar diretamente o índice persistente quando ele já existe e foi concluído com sucesso.

### Novo comportamento

- primeira utilização: cria `.mapstudio/cache/assets.sqlite` e indexa a instalação;
- execuções seguintes: carrega o SQLite pronto sem percorrer novamente todos os arquivos;
- geração de mapa real informa `Índice OMSI em cache reutilizado`;
- o botão `↻ Reindexar biblioteca` continua disponível para atualização manual completa;
- importação explícita de assets no Workspace continua atualizando o índice;
- índice ausente, inválido ou sem refresh concluído continua acionando a indexação normal.

### Refresh forçado

`MapStudioRealWorldAssetCatalogLoader.LoadAsync(..., forceRefresh: true)` força a leitura física novamente. Assim, addons ou assets instalados depois da primeira indexação podem ser incorporados quando o usuário solicitar atualização.

### Regressão

O teste agora confirma que:

1. a primeira carga cria e preenche o SQLite;
2. a segunda carga usa `ReusedExistingIndex=true`;
3. a segunda carga examina exatamente `0` arquivos;
4. um asset adicionado depois não aparece enquanto o cache é reutilizado;
5. `forceRefresh=true` encontra o novo asset e atualiza o catálogo.
