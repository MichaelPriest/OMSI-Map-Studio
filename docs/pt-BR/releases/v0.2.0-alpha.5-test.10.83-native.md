# OMSI Map Studio v0.2.0-alpha.5-test.10.83-native

## Test 10.83 — infraestrutura urbana OSM no Real World Reconstruction

Esta preview amplia a reconstrução automática do cenário real para elementos lineares e áreas urbanas que complementam ruas, prédios, vegetação e mobiliário.

### Implementado

Novo importador OSM para:

- muros (`barrier=wall`);
- cercas (`barrier=fence`);
- guard-rails (`barrier=guard_rail`);
- calçadas mapeadas separadamente (`highway=footway` + `footway=sidewalk`);
- acessos de imóveis/garagens (`highway=service` + `service=driveway`);
- estacionamentos em área fechada (`amenity=parking`).

O importador preserva:

- geometria geográfica dos nós do `way`;
- nome;
- material/superfície;
- largura quando informada;
- indicação de área fechada.

### Segurança da reconstrução

Estacionamentos só são aceitos como área quando o `way` está realmente fechado. Geometrias incompletas ou referências de nós insuficientes não entram no plano de geração.

### Confiança

Os elementos são convertidos para as categorias já existentes do planner:

- `Wall`;
- `Fence`;
- `GuardRail`;
- `Sidewalk`;
- `Driveway`;
- `Parking`.

Itens OSM pouco detalhados permanecem para revisão. Informações independentes de imagem aérea ou de rua continuam podendo elevar a confiança e liberar geração automática.

### Testes

- reconhecimento dos seis tipos suportados;
- preservação de largura, superfície e área;
- rejeição de estacionamento com geometria aberta;
- mapeamento completo para o planner;
- cerca simples permanecendo em revisão;
- estacionamento bem documentado liberado para geração;
- fusão OSM + imagem aérea elevando confiança da calçada.
