# OMSI Map Studio v0.2.0-alpha.5-test.10.139-native

## Test 10.139 — OMSI stock first na reconstrução automática

A Test 10.139 corrige o problema em que o Map Studio indexava os assets originais do OMSI, mas ainda acabava usando assets gerados em partes importantes da reconstrução.

### Vias: original OMSI vira prioridade real

A seleção de splines passa a seguir esta ordem:

1. spline original OMSI com correspondência física estrita;
2. spline original OMSI mais próxima dentro de uma tolerância ampliada;
3. addon instalado compatível;
4. Road Kit do Map Studio como último fallback.

Isso evita que uma rua comum caia no Road Kit apenas porque a largura OSM não coincide perfeitamente com a largura nominal da spline stock.

A regressão cobre um caso de via `service` com largura de 7 m onde a melhor spline original disponível é uma `Splines\Marcel\str_2spur_11m...`. O tile final deve usar a spline original e contabilizar zero fallback Road Kit.

### Road Kit só quando realmente necessário

O Road Kit deixou de ser instalado/atualizado em toda reconstrução.

Se todos os segmentos forem resolvidos com splines instaladas:

- a pasta `MapStudio_RoadKit` não é criada/alterada;
- `RoadKitFallbackSplineCount` permanece zero;
- o resultado do runner informa que nenhum spline de fallback foi instalado.

Ele continua disponível para situações em que realmente não existe asset OMSI utilizável ou quando uma variante estrutural específica ainda exige fallback.

### Prédios: objetos originais antes do procedural

O runner de prédios agora recebe a biblioteca OMSI indexada.

Para cada prédio automático ele tenta primeiro objetos classificados como `BuildingObject` do OMSI original, incluindo famílias como:

- `Sceneryobjects\Buildings_MC\...`;
- `Sceneryobjects\Buildings_RUE\...`;
- `Sceneryobjects\Buildings_DDR_RUE\...`;
- `Sceneryobjects\Buildings_JHY\...`.

O objeto stock é escolhido de forma determinística e alinhado ao eixo principal do footprint OSM.

Somente quando nenhum prédio original utilizável existe o sistema chama `MapStudioFootprintBuildingAssetGenerator`.

### Verificação no mapa

Há regressão que relê o `tile_0_0.map` e exige que um prédio stock apareça como:

`Sceneryobjects\Buildings_MC\bw_50s_01.sco`

e que:

- `InstalledOmsiBuildingCount = 1`;
- `ProceduralBuildingCount = 0`;
- o caminho não contenha `MapStudio_Buildings`.

### Diagnóstico visível

A conclusão da reconstrução passa a mostrar separadamente:

- splines stock OMSI;
- fallbacks Road Kit;
- prédios stock OMSI;
- prédios procedurais.

Assim fica possível conferir diretamente se o mapa está realmente usando a instalação original.
