# OMSI Map Studio v0.2.0-alpha.5-test.10.42-native

Prévia nativa com a primeira etapa da reorganização visual inspirada no fluxo dos editores 3D modernos e no nEditor 1.0, sem copiar identidade ou código externo.

## Workspace modular

- nova barra vertical compacta sobre o lado esquerdo do viewport;
- acesso direto a Seleção, Objetos, Ruas, Terreno, Vegetação, Cruzamentos, Tráfego e Transporte;
- o módulo ativo acompanha automaticamente a ferramenta real já existente;
- ferramentas especializadas continuam usando a barra contextual inferior;
- painéis Projeto e Inspector ficaram visualmente mais compactos para priorizar o viewport.

## Visual

- tema escuro passou do azul profundo para uma base neutra grafite;
- azul permanece apenas como cor de ação/seleção;
- superfícies, bordas e contrastes foram ajustados para uma aparência de editor 3D profissional;
- tema claro também recebeu tons neutros e menos saturados;
- nenhuma funcionalidade do editor foi removida.

## Compatibilidade

A arquitetura permanece WinUI 3 + Direct3D 11. Biblioteca, favoritos, thumbnails, IA, Road Kit, OSM, geração automática, terreno, tráfego, Route Studio e Inspector continuam usando as implementações nativas atuais.
