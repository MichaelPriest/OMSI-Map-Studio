# OMSI Map Studio v0.2.0-alpha.5-test.10.90-native

## Test 10.90 — captura Overpass unificada do cenário real

Esta preview cria a fonte OSM única necessária para o fluxo completo de “Criar mapa real”.

### Uma captura para o cenário

O novo `MapStudioOverpassSceneClient` consulta, na mesma área:

- vias;
- prédios e relações de prédios;
- árvores e arbustos;
- fileiras de árvores, sebes e áreas de vegetação;
- iluminação pública;
- postes/torres de utilidade;
- placas;
- pontos/abrigos de ônibus;
- muros, cercas e guard-rails;
- calçadas explicitamente mapeadas;
- driveways;
- estacionamentos.

O XML retornado pode alimentar os importadores já existentes de vias, prédios, vegetação, mobiliário e infraestrutura.

### Robustez

O downloader mantém as mesmas proteções já usadas na importação de vias:

- múltiplos endpoints HTTPS Overpass;
- fallback automático entre servidores;
- divisão de áreas grandes;
- recuperação limitada por subdivisão 2x2;
- limite global de tempo;
- rejeição de resultado incompleto;
- deduplicação de nodes, ways e relations entre chunks.

### Testes

- fallback para segundo endpoint;

- deduplicação entre chunks;
