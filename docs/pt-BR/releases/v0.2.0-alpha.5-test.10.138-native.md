# OMSI Map Studio v0.2.0-alpha.5-test.10.138-native

## Test 10.138 — endurecimento da correspondência R-19 / limite de velocidade

A Test 10.138 preserva a geração de placas explícitas de velocidade introduzida na 10.137 e endurece duas comparações para impedir falsos positivos.

### Código brasileiro exato

Somente estes formatos são tratados como R-19:

- `BR:R-19`;
- `BR:R-19[<velocidade>]`.

Um código que apenas começa com os mesmos caracteres, como `BR:R-190`, não é reinterpretado como placa de velocidade máxima.

### Família do asset exata

A seleção da família alemã `274` também passa a exigir token numérico exato.

Assim:

- `VZ_274_50.sco` pode atender `maxspeed 50`;
- `VZ_1274_50.sco` não pode ser confundido com a família `274`;
- o valor exibido continua precisando coincidir exatamente.

As famílias textuais reconhecidas (`tempo`, `speed`, `geschw`, `maxspeed`) e assets R-19 explícitos continuam elegíveis.

### Regressões

O gate da Test 10.138 preserva:

- parsing `traffic_sign=maxspeed`;
- `BR:R-19[30]`;
- `BR:R-190` não canonicalizado;
- `maxspeed=implicit` em revisão;
- correspondência exata de `VZ_274_30`;
- rejeição de `VZ_1274_50` como família 274;
- round-trip `VZ_274_50` no tile;
- R-1/R-2 e todos os gates anteriores.
