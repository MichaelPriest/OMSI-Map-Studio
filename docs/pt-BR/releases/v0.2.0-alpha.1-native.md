# OMSI Map Studio v0.2.0-alpha.1-native

Primeira prerelease pública de teste da nova arquitetura **WinUI 3 + Direct3D 11**.

Ela é instalada separadamente como **OMSI Map Studio Native Preview** e não substitui a versão React/WebView2 existente.

## O que já pode ser testado

- abertura da instalação real do OMSI e de mapas;
- viewport Direct3D 11 nativo;
- câmera perspectiva, órbita, pan e zoom;
- terreno OMSI com elevação;
- objetos SCO/O3D reais;
- splines com perfil SLI real;
- depth buffer e ID Buffer;
- hover azul e seleção vermelha;
- picking em pixels físicos/DPI;
- gizmos nativos de mover e rotacionar;
- snap de movimento e rotação;
- Inspector nativo editável;
- Undo/Redo de transformações;
- salvamento transacional com backup;
- Explorer nativo;
- biblioteca de assets baseada no índice SQLite;
- preview 3D de SCO/O3D e SLI;
- posicionamento de objetos SCO no terreno;
- construção de splines retas e curvas;
- snap nas extremidades de splines;
- construção sequencial e vínculo entre segmentos.

## Limitações desta preview

Ainda não é substituta completa do editor React nem do editor original do OMSI. Entre os recursos que ainda serão migrados estão edição avançada de terreno, texturas/materiais completos, exclusão/cópia avançada, ferramentas procedurais, geodados/mapa real, Map Health e várias funções operacionais do OMSI.

Use preferencialmente cópias de mapas durante os testes. As gravações implementadas usam backup seguro, mas esta ainda é uma build alpha.
