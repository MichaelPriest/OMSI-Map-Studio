# OMSI Map Studio v0.1.0-alpha.4-test.1

Build de correção rápida baseada na Alpha.4 para validar o problema de mapa piscando.

## Correção principal

- estabiliza o callback de troca do tile ativo passado ao viewport;
- callbacks de seleção, colocação e transformação passam a ser lidos por refs atualizadas, sem fazer parte das dependências que recriam a cena Babylon;
- arraste de gizmos e atualizações do App deixam de reinicializar o viewport apenas porque a identidade de um callback mudou;
- mantém picking, streaming, seleção, Snap, transformações e persistência preservativa existentes.

## Validação automática

- 129 testes do Core aprovados;
- TypeScript/Vite aprovado;
- host desktop .NET 10 aprovado.

Esta build existe especificamente para validar visualmente se o mapa deixou de piscar durante carregamento e edição.
