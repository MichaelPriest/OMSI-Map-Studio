# OMSI Map Studio v0.2.0-alpha.5-test.10.9-native

Build **ALPHA 5 TEST 10.9 — manipulação direta no mapa, giro estilo editor e ícones de ferramentas**.

## Regra de interação

O Inspector passa a ser tratado explicitamente como **opcional**.

Nenhuma função principal deve depender dele. As operações principais precisam funcionar diretamente no viewport, barras rápidas ou roda contextual.

## Girar diretamente no mapa

O modo **Girar** foi melhorado para ficar mais próximo do fluxo do editor padrão:

1. selecione o objeto ou spline;
2. clique **Girar** ou pressione **E**;
3. arraste o próprio item selecionado;
4. veja a rotação em tempo real;
5. solte para aplicar.

O anel do gizmo continua disponível para controle visual.

Para objetos, a rotação direta atua no eixo vertical principal. O histórico atual continua sendo usado para undo/redo.

## Mover sem Inspector

O comando **Mover** agora também funciona arrastando o próprio objeto ou spline selecionado diretamente no viewport.

- arraste o próprio item para mover livremente no plano do mapa;
- use os eixos do gizmo para ajuste preciso;
- use o eixo vertical do gizmo para alterar altura;
- Snap continua disponível;
- Inspector não é necessário.

Atalho: **W**.

## Correção do texto F11 perto do cursor

- o botão textual `F11` da barra principal foi substituído por ícone de tela cheia;
- tooltips de arrastar painéis não exibem mais `F11`;
- o botão de saída do Creator Focus usa ícone/texto **Sair**;
- F11 continua funcionando somente como atalho de teclado e indicação de menu, sem precisar aparecer perto do ponteiro.
