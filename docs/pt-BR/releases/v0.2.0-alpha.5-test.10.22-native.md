# OMSI Map Studio v0.2.0-alpha.5-test.10.22-native

Build **ALPHA 5 TEST 10.22 — correção da referência CARTO sobre o terreno**.

## Correção principal

Corrige a falha ao usar **Mapa > Referência de mapa sobre o terreno...** com CARTO, que podia terminar em:

`Object reference not set to an instance of an object.`

A imagem CARTO baixada em PNG agora:

- tem assinatura PNG validada antes de entrar no cache;
- é enviada ao renderer diretamente como PNG;
- usa um decoder PNG próprio do Map Studio antes do WIC;
- deixa de depender da conversão WinRT PNG → TGA que provocava o `NullReferenceException`;
- mantém o WIC apenas como fallback para outros formatos.

## Credenciais

Quando a chave CARTO já está salva e o campo fica vazio, o editor reutiliza a chave sem apagá-la/regravá-la desnecessariamente.

## Diagnóstico

Se a referência ainda falhar, a barra de status passa a informar a etapa exata, por exemplo:

- download/conversão da referência CARTO;
- salvamento da chave;
- montagem da textura;
- envio da textura para o viewport.

## Mantido

Permanecem a integração de chave CARTO da Test 10.21, o fallback OSM no seletor de área, as melhorias de navegação e os caches anteriores.
