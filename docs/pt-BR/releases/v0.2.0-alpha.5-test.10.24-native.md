# OMSI Map Studio v0.2.0-alpha.5-test.10.24-native

Build **ALPHA 5 TEST 10.24 — correção adicional do NullReference na referência CARTO**.

## Problema observado

Mesmo após a Test 10.23, em alguns mapas a opção **Mapa > Referência de mapa sobre o terreno...** ainda podia falhar com:

`NullReferenceException: Object reference not set to an instance of an object.`

O diagnóstico por etapa mostrou que a falha ainda ocorria dentro de `LoadCartoReferenceAsync`, antes do envio da textura ao viewport.

## Correções

A Test 10.24 adiciona proteção em três pontos:

- georreferências antigas/incompletas com `mapType` ausente agora são normalizadas automaticamente para `roadmap`;
- `ValidateGeoreference` não chama mais `.Trim()` em `MapType` nulo;
- resposta CARTO sem conteúdo gera erro controlado em vez de `NullReferenceException`;
- decoder WIC agora verifica decoder/frame/converter nulos antes de usar os objetos;
- `NullReferenceException` vindo do fallback WIC é contido e não derruba o fluxo.

## Compatibilidade

Mapas criados por versões anteriores continuam abrindo. A normalização é feita em memória e preserva a georreferência existente.
