# OMSI Map Studio v0.2.0-alpha.5-test.10.111-native

## Test 10.111 — timeout OSM por request e regressão multi-tile

Esta alpha prioriza os dois defeitos encontrados no teste real, sem adicionar recursos novos.

### Importação OpenStreetMap sem prazo global de 120 segundos

O limite global de 2 minutos foi removido do download de cenário OSM.

Agora:

- cada tentativa de endpoint continua limitada a 20 segundos;
- a reconstrução completa não é mais cancelada artificialmente aos 120 segundos;
- chunks primários usam alvo de aproximadamente 750 m em vez de 1.500 m, reduzindo consultas densas;
- até dois chunks primários podem avançar simultaneamente;
- fallback entre endpoints e recuperação por subdivisão continuam ativos;
- o token de cancelamento do usuário continua interrompendo requests e pipeline;
- o progresso do estágio OpenStreetMap mostra blocos concluídos e tentativas acumuladas.

O rollback existente foi preservado.

### Coordenadas e placement

A auditoria confirmou a correção da Test 10.110:

- projeção geográfica produz coordenadas world X/Z;
- seleção do tile ocorre a partir dessas coordenadas;
- a gravação converte world para local exatamente uma vez;
- o renderer recompõe world somando a origem do tile exatamente uma vez;
- objetos relativos ao terreno usam offset vertical zero e recebem o terreno uma única vez;
- splines usam o campo vertical OMSI correto sem nova soma de DEM no renderer;
- prédios e infraestrutura gerada usam malha local ao centro, sem dupla translação.

Foi adicionada uma regressão multi-tile com tiles negativos, centrais e positivos. Ela reconstrói as coordenadas world a partir do arquivo OMSI e garante que todos os placements persistidos permaneçam dentro do retângulo físico dos tiles; um placement fora da área é rejeitado.

### Testes

Além dos smokes existentes, esta versão adiciona regressões para:

- execução concorrente limitada de chunks OSM;
- progresso por chunk;
- ausência do deadline global de reconstrução;
- placements multi-tile dentro do bounding box físico.

As regressões da Test 10.109/10.110 para clipping, eixos OMSI e cobertura DEM permanecem ativas.
